Текущий итог проверки Heavy на `Qwen2.5-Omni-3B`: модель полностью помещается
на GPU, видит маленькое изображение и быстро начинает правильный русский

## Версионная отметка сценария

Реализация первого полноценного сценария `Анализ изображений` открыла ветку
`0.1.0-dev`; принятый подсценарий литературного описания и исправления
контрольной сводки и трёх независимых областей зафиксированы в `0.1.1-dev`.
Отдельная диагностика visual runtime ведётся в `0.1.2-dev` вне закрытого ТЗ:
простой prompt и снятие лимита ответа не исправили распознавание, поэтому
следующим шагом требуется контроль через оригинальный runtime модели.
В `0.1.3-dev` реализация перевода Среднего комплекта на `chatllm.cpp v24`
завершена после дифференциального контроля `2/2` против `0/2` у прежнего
  visual-тракта. Продуктовый runtime прошёл реальный loopback API-тест; старые
  файлы сохранены для отката. В `0.1.4-dev` ядро получило независимую от языка
  роль литературного редактора издательства: цель, язык результата и форма
  ответа теперь заданы раздельно, без названия программы и происхождения
  черновика. Сквозная проверка нового prompt завершена успешно 25 августа
  2026 года; ТЗ принято и перенесено в архив.
