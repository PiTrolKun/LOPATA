8-Bit Dungeon Tileset/Sprites — Free

A downloadable asset pack

Download NowName your own price

This tileset and sprite pack is inspired by my days programming in BASIC on my Commodore 64 computer. Many of the games I created for that used 'custom characters' which were basically re-designed font character sets using 8x8 sprites. I expect at some point I'll create a little demo game using these, but in the mean time feel free to download and use them in any project you like.

This pack includes a fully animated, old school, main player character.

File Formats:

  • Vector (EPS and SVG)
  • PNG (with transparent backgrounds)
  • A sprite sheet and XML file is included

These are Creative Commons Zero (CC0) and may be used in personal and commercial projects.
