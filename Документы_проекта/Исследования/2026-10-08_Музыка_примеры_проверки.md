# Примеры YuE2 и Suno — проверки

08.10.2026, 0.4.12-dev. [ТЗ](../../ТЗ/Архив/2026-10-08_Музыка_Примеры_и_облачное_сравнение.md).

## Материалы

Файлы пользователя скопированы в `Assets/MusicExamples` без перекодирования.
Точные SHA256/размеры — в каталоге `Content/MusicExamples.json` и REESTR.
Наш: 206.198667 секунды, MP3 320; Suno: 193.104 секунды, MP3 около 192.
Жанр doom metal. Пользователь подтвердил промпт Suno; «ЛАПАТА» в локальных
словах намеренно помогает произношению. Оригиналы не изменены.

## Фактические проверки

- 5/5 `MusicExamplesTests`: хеши обоих поставляемых MP3, реальное чтение тегов,
  восстановление всех чисел модели, фактических seed, пожеланий, формата,
  длительности и положения круга. Неполные/несовместимые данные отклоняются.
- Перенос не меняет папку результата, ID/историю проекта и не создаёт запрос.
  Во время работы проекта перенос запрещён. Новая настоящая генерация не запускалась.
- Сохранение исходного MP3 сравнивается побайтно: теги и звук не изменены.
- Оба реальных MP3 декодированы существующим аудиокомплектом и открыты WPF;
  длительность, play/pause/seek, очистка источника проверены с громкостью 0.
- Внешние окна RU/EN и тёмная/светлая тема: полный набор значений нашего MP3;
  у Suno только два поля, без кнопки переноса. Карточки других вариантов —
  заглушки. Снимки `_tmp/music-examples/ui` проверены визуально.
- Общий прогон: 1390 тестов, 1315 успешно, 75 специальных opt-in пропущены,
  0 сбоев. `_tmp/music-examples/tests/all.trx`.
- Приложение/тесты собраны; новых предупреждений нет. Сохраняются четыре
  прежних предупреждения тестов ImageReference/ImageUtilityIntegration.
- `dotnet publish --no-build --no-restore` выполнен в отдельный `_tmp` комплект:
  оба MP3 присутствуют, размеры/SHA256 совпадают с каталогом. Это проверка
  состава, не публикация. Штатный safe-start открыл отвечающую 0.4.12-dev.
  UI Automation настоящего приложения подтвердил два плеера и шесть кнопок;
  отдельно открыто окно нашего примера, кнопка переноса доступна.
  Проверен снимок `_tmp/music-examples/ui/live-local.png`.
- UTF-8 scanner: 25 текстовых файлов, ошибок нет. Новые 40 ключей RU/EN
  совпадают; справка «?» и навигационный тег примеров дополнены. Diff-check
  не обнаружил проблем; обычные уведомления Git о CRLF/LF не являются ошибкой.
- При повторном safe-start штатное CloseMainWindow свернуло старый процесс
  в трей: MSB3027/MSB3021 означали блокировку apphost, не ошибку исходников.
  Завершён только точный Debug-процесс AIHub; сборка/проверки/safe-start
  повторены без блокировки. Логи `build-unlocked`, `examples-unlocked`,
  `safe-start-unlocked` в `_tmp/music-examples` сохраняют финальный результат.

## Границы

Облачные настройки не реконструируются. Показанный текст берётся из исходных
тегов, жанр Suno подтверждён пользователем. Технические сведения нашего MP3
читаются непосредственно из поставляемого файла, не из журнала заданий.
Размер исходной серии неизвестен: повтор настроек задаёт 1 вариант;
папка/аппаратный выбор/ID прежнего запуска не копируются. Совпадение нового
звучания не гарантируется переносом настроек. Исследовательская ветка карты
и новые модели не запускались. Полный установщик не пересобирался по правилу.
Приёмка, архивация и публикация этого ТЗ ещё не выполнены.
