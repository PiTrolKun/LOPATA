## Проверка

Windows 11 build 26200, Python 3.12.10. Отдельное окружение `venv`, системные Python-пакеты не изменялись. `pip check`: **No broken requirements found**.

| Режим | Фактическая проверка | Результат |
|---|---|---|
| lite | Настоящий HyMemoryClient, Chroma, SQLite cache/history, готовые writer/reader, memory_stats пустого пользователя, close | PASS, процесс завершён с кодом 0 |
| pro | То же, в отдельном процессе и отдельном каталоге данных | PASS, процесс завершён с кодом 0 |

Подробные результаты: `startup-lite.json`, `startup-pro.json`, соответствующие `.log`. В обоих случаях `total=0`, `closed=true`, сетевых попыток проверкой не зафиксировано. Инициализация заняла 2.680 и 0.953 секунды соответственно; это одиночные запуски с разным состоянием файлового кеша, **не сравнительный замер производительности**.

LLM и embeddings пока не настроены: используются неработающие локальные адреса для проверки конфигурации, ответы моделей не подменялись. Запись, извлечение, смысловой поиск, русский язык, исправление/удаление памяти, граф и работа с Gemma не проверены. Вывод относится только к запуску SDK и локальных хранилищ; он не подтверждает готовность сценария памяти или требования к RAM/VRAM.

Проверочный скрипт блокирует сетевые подключения Python; исключение — штатная локальная socketpair-пара Windows asyncio. Первая попытка блокировала и её: это ошибка ограничителя стенда, а не SDK. Исходный скрипт и вывод сохранены как `check_start.initial.py`, `startup-lite.initial.json/.log`. После исправления ограничителя оба запуска прошли без правок исходников SDK.

## Повтор запуска

Из PowerShell:

```powershell
& 'H:\AI_HUB\Тесты\HyMemoryStand_20261103\check-start.ps1' -Mode lite
& 'H:\AI_HUB\Тесты\HyMemoryStand_20261103\check-start.ps1' -Mode pro
```

Это короткая проверка запуска с последующим завершением, без сервера и интерфейса чата. Данные только в `data-lite` и `data-pro` внутри стенда; переписки ЛОПАТЫ не читались. Повтор перезаписывает итоговые JSON/логи соответствующего режима. Для дальнейших испытаний потребуется отдельно настроить локальные LLM и embedding-модель.

Программа не пересобиралась, версия 0.7.8-dev не менялась. Commit/push, архивирование ТЗ и публикация не выполнялись.
