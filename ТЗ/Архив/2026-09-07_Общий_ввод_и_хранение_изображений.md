## Ввод

Сохранить диалог выбора файла. Добавить перетаскивание файла/изображения/прямого HTTP(S)-URL на карточку изображения, подсветку и подсказку. Отдельной кнопки вставки нет. Ctrl+V на уровне активного главного окна только на шаге «Изображение», независимо от фокуса на карточке, принимает файл из Проводника, изображение/скриншот из буфера или прямую ссылку, включая URL без расширения. В полях текста вставка текста сохраняется. При нескольких файлах/изображениях сообщать об ограничении одного изображения, не выбирать первое. Данные браузера: сначала сам файл/пиксели, затем прямая ссылка; HTML не исполнять, не искать изображения внутри обычной веб-страницы. Для сетевого ввода ограничить время (30 с), объём (32 МиБ), перенаправления (5), принимать только HTTP(S), проверять фактическое декодирование и размеры (до 40 млн пикселей); повреждённый/неподдерживаемый ответ не заменяет прежний выбранный файл. Не передавать браузерные cookies/учётные данные. Буфер читается только по действию пользователя. Сетевое скачивание выполняется асинхронно; оно не относится к многогигабайтной загрузке моделей и не меняет её многопоточность.

## Копии и хранение

Отдельный сервис общего хранилища изображений на выбранном диске результатов: AI_HUB/Images/Saved, с местом Images/Generated для будущего сценария. Саму генерацию сейчас не добавлять. Временные файлы принадлежат приложению, хранятся отдельно. После проверки картинки из буфера/URL сообщить о временной копии и спросить через системный MessageBox Windows: «Сохранить изображение после завершения работы?» (Да — оставить, Нет — удалить после работы, Отмена — отменить импорт); отмена оставляет прежнее изображение. «Оставить» сохраняет отдельный файл в общей папке, связь с ним хранится в работе. Дубли сохранять с уникальными именами без дедупликации/перезаписи. Исходные локальные файлы не перемещать/не удалять. При смене диска старые абсолютные ссылки сохраняются, новые файлы используют текущее хранилище.

В общих настройках кнопка «Открыть папку изображений». Полный локальный путь показывается по наведению на миниатюру в верхней карточке. Если картинка удалена через Проводник или очищена, история/текст/экспорт доступны, явно сообщается об отсутствии файла; недоступная картинка не передаётся в анализ.

## Завершение и очистка

Копии с выбором удаления очищать при завершении работы, уходе из неё/смене работы и закрытии приложения. Автоматический повтор отдельной попытки не завершает сессию. После принудительного завершения процесса/отключения питания очистить остатки при следующем запуске. Учесть живой второй экземпляр приложения: файлы его работы не трогать. Удалять только принадлежащие механизму временные файлы; не обходить границы корня через подменённые пути/ссылки. Остатки при ошибке удаления повторно очищаются позднее. Постоянные копии не входят в очистку. Существующий внутренний backup не должен создавать вторую скрытую копию временного изображения или дублировать сохранённое управляемое изображение; текстовый backup сохраняется. Старые неуправляемые работы не мигрировать разрушительно.

## Согласованность

Один общий приём/проверка для всех источников, без копирования трёх pipeline. Пока импорт идёт, второе действие/анализ заблокированы. Отмена/навигация/закрытие не позволяют позднему ответу заменить другую работу. История только для чтения, completed и ContextBlocked сохраняют ограничения. Дополнительные поля происхождения/хранения обратно совместимы; старые файлы считаются пользовательскими, не кандидатами на очистку.
