# LoRA изображений: внедрение и проверка 05.11.2026

Версия 0.7.25-dev. ТЗ принято пользователем и закрыто 05.11.2026; поиск также подтверждён пользователем.

## Что подключено

Кнопка после размера выходного изображения открывает каталог, силу влияния,
общий выключатель, скачивание/удаление и поиск для текущей базовой модели.
Есть темы «Меньше цензуры» и «Улучшение отрисовки тела» и свободный запрос/ссылка.
Набор скачивается целиком либо частично по выбору пользователя. Скачивание не
означает автоматического включения всех файлов. Авторские условия подтверждаются
общим окном, проверка/скачивание/отмена/удаление используют управляемое хранилище.

Каталог: 22 исходных источника, 27 записей с файлами сборника; технически
поддержаны 10 Z-Image Turbo и 9 Krea 2 Turbo. Остальные источники сохранены
для будущих баз и уточнения назначения, без ложной совместимости Raw/Turbo.
Подтверждение совместимости заголовка не равнозначно проверке художественного
качества. Специализированный файл для анатомии не назначен произвольно.

## Автоматические и интерфейсные проверки

72 PASS, 2 SKIP, 0 FAIL в объединённом профильном запуске. Пропущены два старых
явно включаемых аудиобенчмарка; это не пропуски новых LoRA-проверок.
Дополнительный физический тест обеих моделей: PASS, шесть генераций.
Независимый PNG-читатель на стандартном Python: шесть файлов PASS, исходный запрос,
фактические LoRA/ревизия/SHA-256/вес, отсутствие внутренних путей, совпадение пикселей
до/после. Проверены отказ при неполном применении, быстрый/полный аудит,
переустановка и отсутствующие/повреждённые файлы; занятая LoRA защищена от удаления.

WPF-окно реально показано и отрисовано при ширине 760: RU/EN × тёмная/светлая
палитры. В диалоге набора проверены «выбрать всё» и снятие одного файла без загрузки.
Живой поиск фиксированных источников Z-Image/Krea и русское описание штатным ядром
проверены. Поиск по тематике/точной базе, чтение только заголовков и отбрасывание
чужой архитектуры проверены контролируемыми HTTP-ответами. Полный интернет-каталог
не объявляется исчерпывающе обследованным.

Сводка ядра первоначально описывала сюжет галереи. Исправлено: вход содержит
описание адаптера без widget/галереи, инструкция просит эффект для разных изображений;
повторная проверка вернула описание текстур, света, кисти и авторского ограничения
на имена художников. Пересказ ядра остаётся пересказом данных автора, не гарантией.
