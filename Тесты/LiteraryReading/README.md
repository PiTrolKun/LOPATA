## Что выяснилось при разработке

Первые варианты не прошли: роль писателя влияла на выбор действий, модель могла отвечать по непрочитанной истории; набросок далеко в начале запроса иногда игнорировался. План чтения вынесен в отдельный нейтральный запрос, а полный актуальный набросок расположен рядом с последним заданием, после старой беседы. Он включается один раз. Старые ответы не объявляются актуальным источником рукописи.

Ручной расчёт nextOffset моделью оказался ненадёжен: модель повторно читала начало и не доходила до конца. Теперь внутри выбранной части программа сама продвигается по фрагментам, с ограничением количества операций и бюджета. Модель выбирает источники. Результаты первоначальных неудачных вариантов сохранены рядом с финальными отчётами.

Поиск сначала ищет точное вхождение без учёта регистра; для одиночных русских слов допускается простой поиск без окончания с явной меткой approximate. Это не полноценная морфология и не RAG. Выдача имеет страницы и не теряет совпадения после восьмого результата.

Качество выводов не гарантируется: в одном промежуточном ответе Советник выдумал позицию цитаты «11-й знак», хотя источник был прочитан. Работоспособность чтения и точность передачи наброска не означают безошибочность литературной модели. Всё произведение не помещается автоматически в контекст; при лимите/ошибке программа сохраняет набросок и явно обозначает ограничение.
