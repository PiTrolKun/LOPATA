# Подробная диагностика ИИ1 и ИИ2

## Закрыто — 2026-09-09

Выполнено. Переключаемая подробная диагностика обеих ролей реализована и использовалась в последующих исследованиях и пользовательских тестах. При внедрении — 454 .NET-проверки, карточка RU/EN и обе темы, включение/отключение, лимит журнала и safe-start. Причина повторов исследовалась отдельным ТЗ; диагностика не обещает сама устранять их.

Основание закрытия: пользователь принял текущий этап и поручил убрать выполненные/отклонённые ТЗ из активности. Закрытие без публикации по прямому указанию; новый commit/push и установщик не выполняются. Текущая версия 0.1.81-dev, код этим закрытием не меняется. Дальнейшие улучшения требуют отдельного согласования.

## Исходное ТЗ и ход работ (исторические записи)

Статус: в работе. Дата: 2026-09-09.

Цель: собрать доказательства причины повторов и пустого ответа, не менять модель, промпты и параметры генерации.

Общая настройка подробной диагностики, изначально выключена. RU/EN, предупреждение о сохранении переписки и расходе диска, открытие папки. Настройка сохраняется; отключение прекращает подробную запись без перезапуска, старые журналы остаются. На данном этапе подключены только литературные ИИ1/ИИ2.

На запрос: уникальный ID, роль, версия программы/backend и модель, команды запуска, полный JSON запроса, HTTP статус, сырой SSE построчно с временем (включая reasoning, usage и finish), видимые фрагменты и финальный текст, исключения со стеком, отмена/таймаут, этапы подготовки и процесса. Ресурсы процесса раз в секунду: CPU, RAM, потоки, дескрипторы и системная память; сведения размещения GPU из журнала backend. Отсутствующие измерения не выдавать за ноль. Без дампов весов/всей памяти, без секретов окружения и автоматической отправки журналов. Ошибка записи не прерывает чат; сообщается в базовом логе. Ограничить один подробный журнал 128 МиБ с явной отметкой усечения, не удалять старые файлы автоматически.

Проверки: выключенный режим, запись сырого потока при ошибке/отмене, независимость двух ролей, отключение во время запроса, ограничение размера, RU/EN, build/test/scanner и штатный старт. Новые модельные эксперименты не требуются. Версия 0.1.75-dev. Backup: _backups/literary_diagnostics_20260909. Установщик и публикация не входят в этот этап.

Проверки 0.1.75-dev: 454 .NET теста успешны, включая выключенный режим, прекращение записи, разделение ролей, лимит, сырые данные при ошибке/отмене и реальные Windows-счётчики ресурсов. Карточка RU/EN проверена в обеих темах; штатный start прошёл, build без ошибок/предупреждений. В работающем окне через UI Automation проверено сохранение галочки off/on, оставлена включённой для пользователя. Новые запросы модели не запускались. Отчёт: Тесты/Literary_Diagnostics_20260909. ТЗ ожидает приёмки; без публикаций и установщика.
