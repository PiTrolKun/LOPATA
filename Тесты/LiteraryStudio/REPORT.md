## Что реализовано

- Основной интерфейс: глава слева, беседа и растущий вверх ввод справа, ниже действия, источники и маршрут. Плавающая панель главы с перетаскиванием и сворачиванием. Проверка опечаток в полях ввода.
- F1 — сохранённый линейный режим; F2 — прежние два чата. Горячие клавиши работают в литературном рабочем окне независимо от фокуса в редакторе. Общий черновик возвращается в основной интерфейс после закрытия вспомогательного окна.
- Действия Советника: обсудить, варианты, уточнить, проверить, найти, сформулировать. Переключение к Писателю подготавливает задание; при успешном ответе беседа Советника уходит из модельного контекста, но остаётся в файловом журнале. Сбой передачи не очищает диалог.
- Действия Писателя: продолжай, другой вариант, переделать, короче, детальнее, тон; комментарий, ручное копирование результата. Обязательный ввод сопровождается кратким миганием. Продолжение из редактора по умолчанию, из последнего завершённого ответа — по ПКМ. Новый запрос Писателя не содержит всей переписки Советника.
- Жанровые инструкции строятся по текущим параметрам произведения. Сохраняются ограничения одного абзаца, локального момента, темпа и текущего этапа.
- Цвета ролей и приглушение сообщений, которые не передаются модели. Пояснения о контексте на маленьких значках. «Вся история» показывает прежние очищенные сеансы. Сообщения Писателя имеют кнопку копирования всего текста.
- Цитаты выбранного текста с подписью источника, предпросмотром и удалением перед отправкой. Самостоятельно не становятся фактами подтверждённой рукописи.
- Круглые кнопки калибровки, RAG, желе и рабочих файлов. Извлечённый первоисточник можно редактировать с перестроением индекса; оригинальные вложения сохраняются. Доступны завершённые тексты и существующее ручное редактирование желе. Рабочие файлы: выбор папки глав либо текущего файла.
- Свободный чат в отдельном окне: только пользовательские сообщения и ответы, без системного промпта приложения или проектного контекста. Переписка остаётся в RAM. Общая модель обслуживает запросы последовательно, ожидающий запрос можно отменить независимо от текущего.
- Последним пунктом добавлены пользовательские варианты промптов через PromptPairStore и знакомые диалоги управления вариантами. Роль и мини-промпт настраиваются отдельно для каждого действия; штатные варианты доступны для возврата.

## Сохранность

Новая история и состояние: `<проект>/Dialogs/Studio/session.json`, атомарная запись с резервной копией и проверкой конкурирующих изменений. Старые файлы диалогов не мигрируются. Очистка начинает новый сеанс, сохраняя журнал предыдущего. При повторном открытии восстанавливаются ввод, роль, задание, ответ, источники, цитаты и выбранные варианты промптов.

Текст свободного чата не передаётся проектной диагностике. После его использования необработанные строки backend-журнала и сохранения KV-слота для этой runtime-сессии отключаются, чтобы не сохранить частную беседу через соседний механизм. Обычные проектные операции по-прежнему имеют собственную диагностику. Это защита от сохранения приложением, а не обещание отсутствия системного файла подкачки или дампов ОС.

При внешнем изменении главы чистый редактор перечитывает файл. Если локально уже есть несохранённый ввод, запись блокируется: обе версии сохраняются. Калибровка параметров не считается заменой проекта при неизменном ID. RAG-редактирование имеет журнал незавершённой записи и восстановление трёх согласованных файлов индекса; исходный материал не перезаписывается.

Backup до правок: `_backups/20260919_literary_studio_201641`. Для отката изменённых существующих файлов использовать сохранённые копии с теми же относительными путями; новые компоненты перечислены в Git как добавленные. Пользовательские проекты откату исходников не подвергать.
