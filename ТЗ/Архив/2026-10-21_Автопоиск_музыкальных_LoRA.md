# ТЗ — автоматический поиск музыкальных LoRA

Дата: 21.10.2026. Статус: выполнено и принято пользователем 21.10.2026 в 0.5.104-dev; архивировано. Исходная версия: 0.5.100-dev.
Продолжение [музыкальных LoRA](2026-10-20_Музыкальные_LoRA.md).

## Согласованные требования

1. Поиск из окна LoRA главной пары: YuE2 Studio/набор 002 и ACE XL Turbo.
   Остальные модели остаются с отключённой кнопкой и честной подсказкой.
2. Динамический поиск репозиториев по правилам совместимости, без огромного
   заранее заданного списка. Без фиксированного предела количества. Каждая находка появляется сразу;
   сомнительные исключать. Поиск многопоточный, с ограничением одновременных запросов.
3. Можно заполнить запрос пожеланиями песни, вручную изменить параметры
   (жанр, стиль, настроение, вокал, инструменты), искать название, автора или URL.
4. Проверять точную базу, поддержанный рецепт загрузки, заголовки Safetensors,
   пары и размеры тензоров, состав файлов, размер/SHA256, закреплённую ревизию,
   доступность публичного скачивания и опубликованные условия.
   Произвольный код репозитория не исполнять. Несовместимость точной ссылки
   объяснять. Автоматически файлы не скачивать и LoRA не включать.
5. Лайки/скачивания показывать с названием источника; неизвестное не равно нулю.
   Они только для пользователя: не влияют ни на отбор, ни на сортировку.
   Порядок определяется технической уверенностью и совпадением с запросом.
6. В поиске — описание автора. Ядро не запускается при поиске. Только после
   успешного скачивания из поиска ядро делает краткое человеческое описание
   по данным автора. Технические поля модель не определяет. Кэш по неизменной
   ревизии/файлам и языку; при недоступности ядра — явное шаблонное описание.
7. Подготовленные варианты отмечать «Проверено нами», новые — «Подходит по
   техническим параметрам», без обещания испытания генерации. Сохранять кэш
   поиска, происхождение, условия, точную ревизию и сведения для старых проектов.
8. Использовать штатный загрузчик, окно условий, проверку SHA256, блокировку
   используемых файлов, удаление и метаданные заданий. Новые варианты не меняют
   уже выбранные настройки проекта и не обновляют автоматически старые веса.
