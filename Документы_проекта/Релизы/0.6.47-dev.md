# 0.6.47-dev — импорт референсов подготовки видео

Первый согласованный подэтап 6Б: вопрос о готовых файлах, локальный импорт
PNG/JPEG/WebP/BMP/GIF, просмотр и явные связи с карточками визуального мира.
Для связи выбираются назначение и заметка с примером/проверкой опечаток.
Можно использовать один файл в нескольких карточках и несколько в одной.
Отвязка не удаляет изображение. Изменённая/удалённая карточка отмечается для
проверки; связи опираются на ID, а не имя или положение карточки.

Свои файлы копируются без перекодирования и изменения метаданных. Рабочий
архив и восстановление содержат точные оригинальные байты; refs хранят роль
вложения, связи, снимки значимых описаний и UI-выбор, без абсолютных путей.
Старые .lopataAIVid schema1 читаются. Обычный checksum streaming архива остаётся.
При переносе исходные файлы рядом с проектом не требуются.

Импорт имеет отмену и частичный результат: повреждённый файл не сбрасывает
корректные; неудачи перечисляются по именам. Предел — 64 файла на один импорт,
512 на проект, 128MiB/64Mpx на изображение. Известная InvalidDataException
в мастере обрабатывается как ошибка входного файла/архива, без падения окна.
Preview использует прежний Skia/FileMetadataPreview с EXIF-ориентацией и 512px;
default лимит прежних metadata callers остаётся 16MiB.

Можно явно продолжить без референсов, сохранив уже импортированное. «Далее»
предупреждает о несвязанных/требующих проверки изображениях. Ветка «Нужно создать»
честно указывает следующий подэтап: выбор режима и набор запросов. ИИ-рисование,
перенос Qwen, новые модели/скачивания и синтез видео в этот инкремент не входят.
Материалы _tmp/video-reference-import, отдельное рабочее ТЗ остаётся активным.
