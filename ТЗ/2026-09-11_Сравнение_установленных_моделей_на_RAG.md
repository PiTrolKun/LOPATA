# Сравнение установленных моделей на незнакомом первоисточнике

Статус: исследование завершено по команде пользователя 11.09.2026; оставшиеся серии отменены, весь запланированный набор не выполнен. Продолжение стенда приоритетов, без внедрения в приложение.

Задача: проверить, ограничен ли пропуск чтения и выдумывание исходных фактов Runeweaver или наблюдается у других установленных моделей. Использовать неизменный новый текст «Тихий шлюз Вейраны», те же три вопроса, четыре варианта и три повтора; отдельно шесть вопросов без источника. Сохранять реальные планы чтения, переданные выдержки, ответы, ошибки и конфигурацию каждого запуска.

Проверить всю установленную генеративную текстовую часть: Runeweaver, Qwen3-8B, Qwen3.8-4B, Qwen3.8-9B, Qwen3.8-27B Ridge, Qwen3.6-27B, Kimi-VL-A3B-Thinking-2506, SmolVLM2-2.2B и Qwen2.5-Omni-3B. Разные форматы одной модели не считать разными моделями. Embeddings, reranker, Florence и речевые компоненты не являются разговорными моделями и исключаются с объяснением.

Запускать по одной, с реальными установленными шаблонами. Общий контроль — без рассуждений там, где backend поддерживает отключение; фиксировать отличия и несовместимость, не выдавать технический отказ за плохое понимание. Не менять шаблоны/промпты приложения, пользовательский проект, библиотеку весов. Для особого backend не скрывать отличия поддержки JSON-схем. При невозможности сопоставимого запуска отдельно дать доступный прямой текстовый контроль и явно ограничить вывод.

Каждый сервер имеет свежий каталог, локальный динамический порт, журнал и ограничение ожидания. Использовать установленный runtime и автоматическое размещение по доступной памяти; не завершать чужие процессы. По завершении остановить только собственные процессы. Новые веса не скачивать. Отчёт должен различать чтение, правильность основных фактов, сохранение авторского решения и техническую совместимость. Не делать вывод об универсальном поведении всех моделей по этой выборке. Без публикации и установщика.

Результаты и границы: [отчёт](../Тесты/LiteraryPriorities/ZOO.md). Четыре полные серии, частичная Qwen3.6, предварительная ошибка SmolVLM2; Kimi, Omni и повтор Runeweaver отменены. Процессы остановлены. Влияние обучения RAG отдельно не измерялось.
