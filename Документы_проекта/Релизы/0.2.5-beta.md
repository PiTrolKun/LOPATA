# ЛОПАТА / LOPATA 0.2.5-beta

Быстрый импорт литературного проекта из DeepSeek: перенос переписки в книгу и рабочий проект ЛОПАТЫ с локальной обработкой.

- Поддерживаются официальный ZIP-экспорт и распакованный JSON DeepSeek. Можно выбрать беседы, проверить состав произведений и объединить варианты названия.
- Два прохода локального Qwen отделяют переписку и варианты текста. Сомнительные места отмечаются для проверки; их можно редактировать, удалять или исключать.
- Результат: общая книга DOCX, рабочие части проекта, RAG, предложения памяти «Желе» и XLSX с точными ответами модели, промежуточными шагами и ручными решениями.
- Сессия сохраняет готовые шаги: обработку можно остановить и продолжить. Новую сборку можно создать из сохранённой разметки без перезаписи прежней рукописи.
- Литературный сценарий использует импортированные данные. Факты памяти требуют отдельного подтверждения; непроверенные места не становятся достоверными источниками.
- Исправлены чтение RAG при отсутствии первоисточника, обработка исключённых частей и устаревшие строки состояния. Уточнены статусы готовности и обновление DOCX/XLSX после ручных решений.

Пользователь принял рабочий результат. Интерфейс ещё будет упрощаться; восстановленную книгу следует проверить на следы переписки, полноту и порядок сцен. Качество зависит от исходного чата и модели, гарантированная доля ошибок не заявляется.

Другие облачные источники, TXT, обратный импорт ЛОПАТЫ и два дополнительных режима пока недоступны. Это тестовая версия для Windows 11 x64, не стабильный релиз. Веса моделей не входят в установщик; необходимые компоненты подготавливаются через программу. Внутренняя версия остаётся 0.2.5-dev.
