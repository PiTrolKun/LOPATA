### Устойчивость публикации при обрывах GitHub

Две попытки публикации остановились до создания черновика из-за `unexpected EOF` при чтении метаданных прежнего выпуска. В `publish-installer.ps1` добавлены до трёх попыток только для запросов API чтения; создание, загрузка и открытие выпуска автоматически не повторяются. Метаданные каждого прежнего выпуска читаются один раз за запуск, но размер и SHA256 каждого переиспользуемого пакета по-прежнему проверяются отдельно. Тест с подменой GitHub проверяет временный сбой, исчерпание повторов и отсутствие повторной мутации. Новая правка относится только к инструменту публикации; проверенный установщик и подписанный патч остаются собранными из `92e5bceb22c557e252fa75a5a00b3781936bb2ea`, без пересборки или подмены исходного коммита. Backup: `_backups/20261010_music_050_publisher/files.json`.
