# Проверки 0.5.74-beta

Тип выпуска: файловое обновление; исходники текущей main. ТЗ метаданных
принято пользователем и архивировано. VERSION разработки остаётся 0.5.74-dev.
Публикация и серверные хеши будут подтверждены после фактического завершения.

- 99 профильных/смежных тестов: метаданные, навигация, лицензии, аудио и обложки.
- 72 теста Updates. Ошибок и пропусков в этих прогонах нет.
- UI: RU/EN, светлая/тёмная темы, ширины 760/1200; длинная строка и границы скролла.
- Отдельный визуальный проход страницы утилит в двух темах, тематический thumb подтверждён.
- Старые NU1902/NU1903, CS4014/MSTEST0040 тестового проекта сохранены; новых нет.
- Полный набор приложения при этом закрытии не перезапускался. Общий прогон 0.5.71
  ранее имел один таймаут Python-проверки; профиль метаданных не меняет эту цепочку.
- Unicode/emoji, неизменность полезного содержимого/истории, неизвестных полей,
  нескольких картинок, DOCX-частей, защита исходника при ошибках/отмене — файловые тесты.

ExifTool 13.59 Windows x64: 510 файлов, закреплённый SHA256 официального архива.
Сохранены первоначальные 155 записей каталога лицензий/Terms, добавлена одна;
оригинальные лицензионные тексты и архив лицензий Perl включены. RU/EN — 5559 ключей.
Источник перенесённой идеи не менялся: SHA256
53102B4637200998136A2AC059018CDCD848D9EB3D6E8561BC0249DF416B69D7.

Границы: PDF/видео и распознанные подписи только чтение; криптографической проверки
подписей нет. Многокартиночное аудио не допускает замены обложки. Lyrics только чтение.
Аудиозапись до 128 MiB, изображение/DOCX до 512 MiB; предпросмотр до 16 MiB/64 MP,
вывод инструмента до 32 MiB. Ошибка чтения не объявляется отсутствием данных.
Видео проверено H.264/VP9; поддержка кодеков ограничена штатным CaptureRuntime.
Тесты использовали искусственные файлы. Другие ПК, применение обновления и новая
сетевая установка этим прогоном не испытывались. Модели не вызывались.
Полный и миниустановщик не пересобирались. Частные файлы/настройки/веса не публикуются.

_tmp/metadata-scroll-20261017. Backup: _backups/20261017_133844_metadata_closure/files.json.

исходная идея и оригинальные LICENSE/Windows NOTICE ExifTool: у уведомления
