# ЛОПАТА 0.8.5-beta

В «Создание → Изображения → Простая генерация» добавлены Qwen-Image-2.1 Base GGUF Q4_K и Turbo INT8. Base ориентирована на детализацию, Turbo создаёт изображения за восемь шагов. Нажмите карточку модели, чтобы открыть подготовку. Веса скачиваются по вашей команде. ЛОПАТА автоматически подбирает размещение между видеопамятью и гибридом с оперативной памятью.

В обеих карточках доступны примеры с исходными промптами и замеры видеопамяти. Русские надписи на сгенерированном изображении могут содержать ошибки. Установленные модели можно удалить из карточек. Общие файлы сохраняются, пока их использует другая установленная или частично скачанная модель.

Подписанное файловое обновление доступно в разделе «Настройки → Обновления» на бета-канале.
