# ЛОПАТА 0.8.22-beta

- Сценарий «Шортсы» создаёт вертикальный MP4 1080 × 1920 из отрывка песни или по описанию. Длительность до 2:59. Для песни доступны шкала с пиками, выбор и прослушивание отрывка. В последнюю секунду можно плавно заглушить звук и затемнить видео.
- В «Проектах…» можно создать, сохранить, переименовать и открыть проект. Первый запуск сохраняет проект автоматически. История позволяет открыть MP4 и вернуть настройки выбранной попытки.
- Прежний черновик «Шортсов» переносится при первом открытии сценария.
