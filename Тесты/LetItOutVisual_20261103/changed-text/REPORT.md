# Визуал «Если накипело» — 0.7.6-dev

03.11.2026. Правка по отмеченному пользователем снимку реализована и проверена;
пользовательская приёмка ожидается.
Требования включены в раздел 0.5
[единого ТЗ](../../ТЗ/2026-11-02_Разгрузочный_разговор_Набросок.md).

- Под заголовком показано «ИИ (готов / загружается / отвечает / на паузе / …)».
  Имя модели и режим доступны по наведению. Полное объяснение состояния/ошибки
  сохранено в подсказке и Automation HelpText.
- Отправка — векторная стрелка вверх в кнопке 44×44. Доступное имя и подсказка
  локализованы. Клавиатурная отправка и обработчик кнопки прежние.
- Подсказка Enter / Shift+Enter прижата к нижнему внутреннему краю рамки ввода.
- Остановка вынесена из рамки в нижний правый угол области чата, над подвалом.
  Для чата снят внешний предел ширины страницы; переписка и поле ввода по-прежнему
  ограничены центральной колонкой. При выходе применяется прежняя ширина страницы.
- Нижние строки о готовности и хранении переписки убраны из видимой компоновки.
