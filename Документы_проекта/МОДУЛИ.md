# Модули ЛОПАТЫ

Сверено с исходниками 21 сентября 2026. «Реализовано» означает наличие рабочего контура, а не отсутствие ограничений моделей.

| Область | Текущее состояние | Где смотреть |
|---|---|---|
| Главное окно, темы, масштаб, язык | Реализовано, WPF, RU/EN | MainWindow, Localization |
| Хранилища моделей и результатов | Реализовано, пути и лимиты настраиваются | StorageSettingsStore |
| Паспорт ПК | Реализовано | ComputerPassportService |
| Библиотека установленных моделей | Реализовано | ManagedModelLibraryStore |
| Каталог кандидатов | Реализован независимый каталог и инструмент поиска; это не универсальная витрина всех моделей | ModelCatalog / gateway |
| Загрузка и подготовка | Реализованы докачка, проверки, лицензии и подготовка по сценарию | SegmentedModelFileDownloader, ComponentLicenseGate |
| Локальные backends | Реализованы адаптеры и управление runtime; универсальность ограничена поддерживаемыми компонентами | Services, Tools |
| Анализ изображений | Профильный сценарий, одиночный и групповой режимы | ImageAnalysisWorkspaceControl, ImageBatchControl |
| Работа над произведением | Профильный сценарий принят в 0.2.0 | LiteraryWorkspaceControl, LiteraryStudioControl |
| Быстрый импорт DeepSeek | Реализован в 0.2.3-dev, на приёмке; сессии, два прохода Qwen, группировка, DOCX/XLSX, сомнения, RAG и предложения памяти | LiteraryImportControl, Services/LiteraryImport, LiteraryChatRuntime.Import |
| Источники RAG произведения | Реализованы корпуса проекта/первоисточника и редактор | LiteraryRag*, QdrantRuntime.Literary |
| Память «Желе» | Реализован подтверждаемый контейнер SQLite, цитаты и редактор фактов | LiteraryJelly*, Jelly* |
| Маршрут и наборы промптов | Реализованы редакторы и сохранение пользовательских вариантов | LiteraryRouteDocument, LiteraryPromptSet* |
| Сеть и инструменты ядра | Реализованы управляемые вызовы, не свободный доступ модели к ПК | tool gateway / services |
| «Песочница» | Экспериментальный интеграционный сценарий | Uncertainty / executor |
| Дерево сессии и результаты | Реализованы для соответствующих executor-сессий; не общий механизм любого сценария | SessionKnowledgeTree, SessionTreeWindow |
| Речь и озвучивание | Доступность зависит от сценария и подготовленного компонента | Voice / speech services |
| Установщик и обновления | Публичная beta; автопоиск, скачивание и установка подтверждены пользователем | ApplicationUpdateService, ОБНОВЛЕНИЯ.md |

Общесистемная автономная память, сон произвольной модели и новые сценарии остаются направлениями исследования. Подробные компоненты и лицензии: [реестр](REESTR.md). Пользовательские операции: [руководство](РУКОВОДСТВО.md).
