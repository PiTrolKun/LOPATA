# Модель «Нейроконструктора» вне ЛОПАТЫ

Файл `.lopatanet` хранит выбранные модели и обученные связи между ними. Для первого шаблона входом служат картинка с четырьмя ячейками и текст просьбы. При обучении и при запуске исполнитель приводит всю картинку к размеру 256 × 256 без обрезки. Модель выбирает одну ячейку. Сборка со слухом также принимает две отдельные записи WAV. Пример голосовой команды — «выбери вторую реплику».

## Запуск

Установите Python 3.12 и совместимый PyTorch для своего компьютера. На стенде использовали Python 3.12, PyTorch 2.10.0 с CUDA 12.6, Transformers 5.3.0, NumPy 2.5.3 и Pillow 11.3.0. В активном окружении Python откройте папку с этим README и выполните:

```console
python -m pip install .
python -m lopata_neuro.cli check --model "Моя сборка.lopatanet"
```

В строке результата `matched` показывает число воспроизведённых ответов, `correct` — число правильно решённых заданий. Если `matched` равно 12, модель повторила все сохранённые ответы, включая свои ошибки. Для установки на компьютер без сети заранее подготовьте совместимые пакеты Python. Если зависимости и setuptools уже установлены, используйте `python -m pip install --no-index --no-deps --no-build-isolation .`. После установки исполнитель работает с местными файлами.

```console
python -m lopata_neuro.cli predict --model "Моя сборка.lopatanet" --image panel.png --text "Покажи настройки"
python -m lopata_neuro.cli predict --model "Модель со слухом.lopatanet" --image panel.png --text "use the second word" --audio first.wav second.wav
```

Поддерживаются две записи моно PCM 16 бит длительностью до 30 секунд каждая. Исполнитель переводит частоту в 16 кГц. Для выбора устройства добавьте `--device cpu` или, например, `--device cuda:0`. При автоматическом выборе учитывается сохранённая настройка модели и доступное в PyTorch оборудование. Для повторения результата эталонных сборок используйте проверенный стек выше.

## В своей программе

```python
from lopata_neuro import open_model

with open_model("Моя сборка.lopatanet") as model:
    result = model.predict("panel.png", "Покажи настройки")
    print(result["position"])
```

Внутри одного блока можно обрабатывать новые кадры и команды с уже загруженными весами. В `predict` передайте путь к изображению или объект `PIL.Image.Image`. Для голоса передайте ещё список из двух путей к WAV. Поле `slot` содержит номер ячейки от 0 до 3 в порядке чтения. `route` показывает, какой состав подготовил ответ. `calls` содержит количество вызовов специалистов на этом задании. `link_bytes` учитывает переданную подсказку между CPU и ускорителем. Для начала отдельной последовательности кадров вызовите `model.reset_series()`.

## Формат версии 1

Контейнер ZIP64 без сжатия. Схему вычислений определяет установленный исполнитель по идентификатору `four-cell-icons-v1`. В `manifest.json` записаны состав `kind`, редакции моделей `models`, места подключения языка и речи `graph`, настройки вызова и передачи `settings`, контрольные суммы SHA-256 и размеры файлов `files`, версия ЛОПАТЫ и время сохранения `provenance`. Команда `inspect --model FILE` показывает описание без запуска вычислений.

| Раздел файла | Содержимое |
|---|---|
| `models/` | Полные веса, конфигурации, словари и карточки моделей MiniLM, OmniParser и, у тройки, Whisper. Лицензия детектора находится рядом с его весами. |
| `weights/` | Обученная связь языка и зрения, словарь коротких подсказок, выбор ветви и, у тройки, связь речи. |
| `checks/` | Контрольные картинки, команды и WAV, правильные и сохранённые ответы. Пара содержит 12 текстовых заданий. Тройка дополнительно содержит 12 голосовых. Для проверки прежней способности тройки используйте `check --model FILE --suite pair`. |
| `licenses/` | Текст лицензии Apache 2.0 для моделей с этой лицензией. Идентификаторы источников и точные редакции указаны в `manifest.json`. |

При открытии исполнитель проверяет состав и целостность файлов, извлекает веса во временную папку и загружает их с диска. На время работы понадобится дополнительное место примерно размером со сборку. В эту версию формата включены адаптеры трёх указанных семейств и обученные связи совместимой формы. Установленный исполнитель определяет список допустимых файлов и контрольные суммы исходных моделей.

## Сборка из программы

`pack --source DIR --kind pair --output FILE --app-version VERSION` собирает эталонную пару. Папка DIR содержит `models/` с вложенными папками моделей по идентификаторам репозиториев либо сама является такой папкой. Укажите `--kind trio` для варианта со слухом. Веса для поддерживаемых моделей идентифицируются по описи `lopata_neuro/reference/catalog.json`.

Для создания своей версии добавьте `--parent ORIGINAL.lopatanet` и сохраните результат под новым именем. Веса, уже входящие в родительскую модель, читаются из неё. При добавлении слуха требуется также установленный Whisper указанной редакции. Ключ `--overrides DIR` подключает полученные от обучения файлы связей `pair.pt`, `trio.pt`, `router.pt`, `byte.pt` и описание схемы речи `topology.json`. При изменении весов или настроек контрольные ответы для сохранения вычисляются заново. Параметры исходного запуска можно передать в JSON-файле через `--settings`:

```json
{"routing":"learned","channel":"continuous","send":"always","device":"auto"}
```

Для раздельного размещения задайте `languageDevice`, `visionDevice` и при наличии слуха `speechDevice`. Например, `{"languageDevice":"cpu","visionDevice":"gpu","speechDevice":"gpu"}` оставляет язык в оперативной памяти и размещает зрение и слух на совместимой видеокарте. `auto` предпочитает оперативную память для языка и слуха и доступную видеокарту для зрения. `gpu` требует совместимый ускоритель. Допустимо указать конкретное устройство, например `cuda:1`. Исполнитель сохраняет выбор в файле. На другом компьютере `--device cpu` или `open_model(path, device="cpu")` позволяет разместить все модели в RAM. Поле `placement` в результате показывает фактические устройства. Счётчики передачи различают направления к процессору, к ускорителю и между ускорителями. В них входят подсказки и ответы между частями модели. Загрузка весов и подготовка исходных изображений, текста и звука учитываются отдельно от этого обмена.

`routing` принимает `learned` (выбор по команде), `input` (выбор по наличию двух записей) и `always` (обработать предоставленные записи при любом маршруте). Для пары доступны `channel="continuous"` (16 чисел) и `channel="byte"` (один байт). У тройки голосовая подсказка передаёт 16 или 33 числа в зависимости от схемы соединения. Для `send` доступны `always` и `changed`. Второй режим повторно использует уже переданную идентичную подсказку в пределах одной последовательности. Например, зрение может разобрать новый кадр, используя подсказку от тех же реплик и той же команды. С началом новой последовательности первая подсказка передаётся полностью.

У пары есть исследовательский режим `channel="feedback"`. Зрение получает короткую подсказку и решает, понадобятся ли подробности для текущей картинки. В ответ передаётся один байт со значением «да» или «нет». При запросе язык отправляет ещё 16 чисел (64 байта). Если короткий код уже был передан в режиме `send="changed"`, зрение повторно использует этот код и заново оценивает текущую картинку. Обученный порог из первого опыта редко просит дополнительные данные. В результате `feedback_requested` показывает принятое решение. В `transfers` отдельно указаны переданные подсказки, байт обратного запроса и суммарный возврат на CPU с четырёхбайтовым индексом ответа. Передача входного изображения в эти числа не входит.

## Средний набор

В ЛОПАТЕ откройте «Эксперименты» → «Нейроконструктор» → «Авто» и выберите «Полный средний набор». При первом запуске задайте число циклов и папку исходных моделей. После успешной проверки можно использовать сохранённые связи. Выбор набора сохраняет отдельный проект для лёгких моделей.

Файл среднего набора использует формат 2. Внутри лежат оригинальные веса, настройки размещения, обученная связь, редакции компонентов и контрольные примеры с ответами до сохранения. Формат 1 для лёгких моделей также поддерживается. В голосовом задании MiniLM выбирает одну из двух записей. Слуховой код Qwen3-ASR и признаки восьми зрительных компонентов определяют ячейку. Для текстового задания используется ранее проверенная связь MiniLM и детектора OmniParser. Зрительные энкодеры Florence, Qwen3-VL и PaddleOCR-VL передают признаки изображений. Распознаватели PP-OCR передают оценки символов. Этот профиль решает задачу выбора ячейки.

Для внешнего запуска установите пакет этой папки командой `python -m pip install .`. Кроме окружения PyTorch нужен Python с PaddlePaddle 3.2.1, NumPy и Pillow. Его можно держать отдельно. В PowerShell задайте `$env:LOPATA_PADDLE_PYTHON` равным полному пути к его python.exe. При работе через ЛОПАТУ программа выбирает проверенное окружение Paddle сама. Открытие требует свободного временного места под распакованные веса.

```python
from lopata_neuro import open_model

with open_model("LOPATA-medium-6.lopatanet") as model:
    answer = model.predict("panel.png", "выбери первое слово", ["first.wav", "second.wav"])
    print(answer["position"])
```

Команда `lopata-neuro check --model LOPATA-medium-6.lopatanet` повторяет 12 текстовых и 12 голосовых заданий и сравнивает ответы с сохранёнными. В поле `matched` указано число воспроизведённых ответов, в `correct` — число верных по разметке. Режим `--device cpu` позволяет запустить вычисление без видеокарты.

## Тяжёлый набор

В режиме «Авто» выберите «Полный тяжёлый набор». Слух обрабатывает Qwen3-ASR-1.7B, за зрительные признаки Qwen отвечает Qwen3-VL-8B-Instruct. Оба специалиста загружают все необходимые части весов своей редакции. При поиске значка используются 24 слоя звукового энкодера и 27 слоёв зрительного энкодера Qwen. Средний профиль использует 18 и 24 слоя соответственно. Оба сохраняют восемь зрительных выходов, один способ выбора записи и одинаковый формат команды.

Сохранённый файл формата 2 можно открыть через `open_model` или проверить командой `lopata-neuro check --model LOPATA-heavy-6.lopatanet`. Перед открытием требуется свободное временное место под оригинальные веса. Библиотека версии 1.2 также поддерживает лёгкие и средние сборки.
