# 0.5.88-dev — повторная подготовка и контекст умного конвертера

20.10.2026. App-only patch к активному второму этапу «Текст в книгу».

Повторно подтверждены два дефекта пользовательского запуска .87: окно подготовки
безусловно открывалось из ConvertAsync; JSON текста книги содержал буквальные
Unicode-escape последовательности. Уже ограниченный по символам русский фрагмент
мог превысить контекст Qwen3-8B: в пользовательском отчёте 43194 при лимите 32768.

Изменения:

- Успешная подготовка запоминается на время жизни окна. Перед конвертацией
  проверяются координаты/проверенные отметки моделей, состав, размеры и время
  изменения файлов среды, worker, выбранные модели, хранилище и набор движков.
  Повторное чтение гигабайтов и Python probe не запускаются для неизменного набора.
  Изменённые/удалённые компоненты либо новая необходимая визуальная модель
  возвращают подготовку. Уже проверенная установленная Альфа/Бета используется
  при добавлении иллюстрированного источника после выбора режима.
- В классификатор отправляются только id/text/kind, с читаемой кириллицей;
  HTML, координаты и профиль пользователя не раздувают запрос.
- Точный шаблон запроса считается токенизатором текущего исполнителя. Оставляется
  4096 токенов на ответ и 512 запаса. При превышении пакет делится, вплоть до
  безопасного разделения одного длинного блока; все слова и ID сохраняются.
  Ответ с finish_reason=length не принимается. Глобальный контекст не увеличен.
- Чаты, музыка, распознаватели и их существующие методы генерации не изменены.
