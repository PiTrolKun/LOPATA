Нарисуй жирного кота из дождя Матрицы. Кот должен быть хорошо узнаваемым, с округлым большим телом, ушами, мордочкой, лапками и хвостом. Чёрный фон, зелёные светящиеся символы цифрового дождя; сам кот тоже связан с этим цифровым дождём. Нужна законченная векторная иллюстрация. Ответь одним полным самодостаточным SVG-файлом с viewBox, без Markdown и пояснений. Не используй внешние ресурсы, растровые картинки, JavaScript или анимацию.
