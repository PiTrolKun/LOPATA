# Защита литературных чатов — 0.1.80-dev

2026-09-09. Перенос проверенного механизма из [исследования](../loop_lab_20260909/README.md) в оба чата Runeweaver. Первая попытка сохраняет профиль .8/.5 и repeat_penalty 1.05. При длинном буквальном повторении или шаблоне с меняющимися числами поток закрывается; после освобождения слота выполняется одна повторная попытка с 1.1 и cache_prompt=false. Сообщения исходного запроса неизменны; испорченный ответ не добавляется в память модели. Семафор удерживается на обе попытки, отмена действует на весь запрос.

Первый фрагмент остаётся видимым с отметкой незавершённости; отдельный буфер второй попытки исключает склейку текстов. Пользователь видит статус восстановления и сообщение о запасном профиле/проверке цитат. Повторный цикл останавливается окончательно. Ошибки транспорта, отмена и лимит вывода не запускают автоматических повторов. Диагностика пишет номера попыток/признаки цикла; тела подчиняются прежнему переключателю подробного логирования.
