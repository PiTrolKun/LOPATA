# Линейный литературный режим: проверки

[ТЗ исследования поведения Советника и Писателя](PLAN_20260915.md) — согласованные условия перед отдельным запуском: обсуждение и подготовка задания по команде, подбор промптов/параметров/контекста, один поток генерации, без ограничения времени, остаток общей квоты не менее 10% для внедрения. Сам файл не запускает серию или субагентов.

Стенд использует производственные `LiteraryParagraphSources`, `LiteraryChatRuntime.ParagraphAsync` и окно `LiteraryParagraphWindow`. Пользовательский проект определяется по штатному активному проекту; рабочие данные копируются в `runs/`. Оригинал проверяется по хешам.

```powershell
dotnet run --project Тесты/LiteraryParagraph/Probe.csproj -- --model
dotnet run --project Тесты/LiteraryParagraph/Probe.csproj -- --mechanics
dotnet run --project Тесты/LiteraryParagraph/Probe.csproj -- --ui
dotnet run --project Тесты/LiteraryParagraph/Probe.csproj -- --route
```

`--model`: синтетическая завершённая глава и подтверждённый факт, штатная индексация Giga/Qdrant, три цикла Советник → вручную изменённое задание → Писатель, продолжение и очистка. `--mechanics`: два новых первоисточника, реальная фильтрация Qdrant по выбранному разделу, общая блокировка, отмена, три пробы рекомендаций. Эти два режима запускают установленные компоненты, новых загрузок не делают. `--ui`: WPF RU/EN, обе темы, сохранение, независимые галочки, рекомендации, F1 и возврат редактора; генерация не вызывается.

Исходные ответы и подробная диагностика остаются в соответствующей копии проекта. `runs/`, `bin/`, `obj/` исключены из Git. Итоги и текстовые примеры сохранены в [REPORT.md](REPORT.md) и [Evidence/20260914.md](Evidence/20260914.md).

`dotnet run --project Тесты/LiteraryParagraph/Probe.csproj -- --budget` — воспроизведение пакета 0.1.106 и сравнение с 0.1.107 через настоящий токенизатор, затем три пары запросов со всем замыслом из текущего тестового проекта. Снимок старого пакета нужен только для воспроизведения дефекта. Результаты сохраняются в отдельной копии runs; весь текст замысла остаётся в запросе. Этот режим запускает уже установленный Runeweaver. Точные ответы: [Evidence/20260915.md](Evidence/20260915.md). Для исторического воспроизведения 14829 токенов в сессии были две предыдущие неудачные просьбы; после восстановления сессии число будет меньше.

Сборки основного проекта и стенда выполнять последовательно: они используют общий obj. WPF-стенд дополнен тремя ошибками отправки в каждом варианте RU/EN и темы; проверяется отсутствие дублей в сохранённой истории.

`--route` (0.1.108): три повтора на копии активного проекта с пустым снимком редактора, исходной просьбой и сохранённой ручной редакцией задания. Писателю намеренно передаётся прежняя экранная история, которую производственный пакет исключает. Текущий этап читается из проекта. Сравниваются граница этапа, фактический вход, форма и сохранность оригинала; установленный Runeweaver запускается без скачиваний. Для воспроизведения нужны сохранённые просьба, задание и выбранный ориентир. [Ответы 15.09](Evidence/20260915-route.md). Требование одного абзаца не заменяется автоматическим сокращением или склеиванием.

WPF-проход 0.1.108 дополнительно проверяет реальные параметры, обновление после калибровки, подписи ролей и текущий маршрут, в том числе исчезнувшую строку. Итог: 164 проверки в RU/EN и обеих темах.
