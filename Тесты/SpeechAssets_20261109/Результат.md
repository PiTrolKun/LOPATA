# Создание ассетов — этап 1, 09.11.2026

Версия: **0.7.66-dev**. Путь: **Утилиты → Работа со звуком → Создание ассетов**. Программная реализация готова к ручной проверке пользователя; принятие ТЗ не объявляется автоматически.

Выполнены импорт UTF-8 Markdown (включая вложенность, несколько абзацев, task-list и повторения), отдельные исходный/произносимый тексты, возврат, ручной выбор моделей/голосов через VideoVoiceWindow, собственные профили сеанса, потоковый прогон оставшихся строк и запуск отдельной реплики. Длинные реплики синтезируются частями и собираются в один WAV. Дубли не уничтожаются при повторе; исходное написание каждого дубля сохранено. Подтверждение всегда вручную, правки и смена выбора его снимают. Счётчик показывает всего/сгенерировано/подтверждено/осталось проверить. Есть исключение строк, имена и изменение порядка. ZIP Fastest содержит только выбранные подтверждённые записи, manifest и фактическую историю моделей. Сеанс сохраняется автоматически, доступен повторный вход.

## Границы

Качество произношения пользователь проверяет прослушиванием и подтверждением. Ранее созданные WAV с отличающимся текстом сохраняются для сравнения; для подтверждения текущей редакции выбираются соответствующие ей дубли. Утилита не гарантирует правильную интонацию модели автоматически.

По прямому уточнению пользователя выполняется **только утилита**. Каталог уведомлений, их голоса/записи и подключение голосовых уведомлений в этом проходе не готовились. Полный установщик не пересобирался; публикации и принятия/архивирования ТЗ нет.
