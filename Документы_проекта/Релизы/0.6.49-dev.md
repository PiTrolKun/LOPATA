# 0.6.49-dev — контекст референсов видео

Исправлено ложное переполнение контекста Qwen при подготовке референсов с
русскими описаниями. Текст передаётся обычным Unicode без раздувания в
escape-последовательности; вложенное определение запроса больше не кодируется
дважды. Тексты проекта не сокращаются, контекст модели не увеличивается.

На реальном сохранённом запросе: 21299 → 2980 входных токенов при лимите8192,
содержимое сохранено. Аналогичная передача исправлена для визуального мира.
Старые контексты/истории/receipts и формат .lopataAIVid не изменены.

Если материал действительно слишком велик, задание завершается с понятным
сообщением: форма разблокируется, анимация прекращается, готовые результаты
сохраняются. Автоматический повтор не выполняется. Неизвестные ошибки и ошибки
сохранения продолжают использовать штатное восстановление.

137 автоматических проверок успешны. Прежние предупреждения тестового baseline
сохранены. Установщик не пересобирался; публикации/архивации не было.

Физически: исходный запрос копии проекта проходит без сокращения, отдельный
двуязычный запрос3139 токенов; один GPU worker. Нативный WPF подтвердил
разблокировку после настоящего превышения и последующее открытие/сохранение
нормального набора. Подробности диагностического инцидента Recovery и его
устранения — в CONTEXTHUB и отдельном ТЗ; исходный пользовательский архив не менялся.
