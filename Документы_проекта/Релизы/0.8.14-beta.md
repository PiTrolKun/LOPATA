# ЛОПАТА 0.8.14-beta

В «Апскейле видео» исправлен запуск ИИ-способов на основе Visual Enhancer. Окно подготовки показывает компонент, этап работы, объём загрузки и скорость.

Встроенная сборка FFmpeg теперь поддерживает программное шумоподавление. Предпросмотр с FlashVSR+ и последующим программным увеличением продолжает обработку с сохранённых кадров.

Проверены короткие прогоны всех шести ИИ-способов, скачивание комплекта FlashVSR+ Base INT8 и возобновление пятисекундного превью 1080p со звуком.
