# ЛОПАТА 0.9.33-beta

- В разделе «Создание → Vibe Coding» появился визуальный конструктор Windows-приложений. Проект состоит из обычных файлов C# и XAML. Можно добавлять формы и вкладки, настраивать переходы, редактировать код действий и собирать самостоятельный EXE.
- Локальная Gemma предлагает готовые действия или C# для выбранного события. Редактор проверяет сборку на копии проекта. Запросы и ответы сохраняются в локальной истории.
- Исследователь ищет документацию и сохраняет источники в техническом архиве. Архив доступен без интернета. Выбранный материал можно передать программисту как источник.
- Добавлены проверочный размер окна, двухколоночная раскладка, звук ошибки Windows, открытие страниц, запуск программ, проверка процесса и ожидание.

Пользователь принял текущую сборку после беглой проверки. Запуск EXE на чистой Windows отложен до независимой пробы. Дополнительные проверки перечислены в архивном ТЗ.
