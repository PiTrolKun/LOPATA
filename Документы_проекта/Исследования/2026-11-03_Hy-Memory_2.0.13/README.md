# Hy-Memory 2.0.13 — отклонённый кандидат

03.11.2026 пользователь завершил исследование: Hy-Memory не оправдал ожиданий,
выглядит сырым для данного сценария. По прямому поручению SDK, его окружение,
скачанные оригиналы и рабочий стенд удалены пользователем вручную. После его
сообщения «Готово» проверено отсутствие обеих исходных папок. Имитация чата
сохранена в независимом каталоге.
Отчёт оставлен для будущего push.
Публикация сейчас не выполнялась.

- [Основной отчёт](REPORT.md) и [подробные случаи](CASE_DETAILS.md) сохранены без
  изменения содержимого. Их описания прежнего расположения баз/скриптов — история
  эксперимента, а не описание нового расположения сохранённых материалов.
- Сохранены JSON результатов поиска, ответов/справок, native-вызовов, экспорты
  памяти, параметры и сводные проверки. Это материалы отчёта, не исполняемый стенд.
- `retained-files.json` содержит SHA-256 всех перенесённых исходных материалов,
  проверенных при переносе. `artifact-manifest.json` — прежний манифест опыта;
  `removal-blocked.json` — история отказа автоматической проверки;
  `removal.json` — подтверждение последующего ручного удаления пользователем.
- Исполняемые Python-пакеты, venv, SDK source, скачанные wheel/sdist, временные
  базы Chroma/SQLite/Kuzu, служебные runtime-кеши и launch-скрипты не копировались
  в этот каталог отчёта; они удалены вместе с прежним стендом.
- По отдельному уточнению пользователя **имитация чата оставлена** целиком в
  `Тесты/LetItOutSyntheticChat_20261103`: 6 тем, 638 сообщений, HTML/JSON/JSONL/SQLite,
  авторские тексты и 36 контрольных вопросов. `synthetic-move-manifest.json`
  подтверждает побайтовую сохранность при переносе; после него изменены только
  инструкция и поиск корня проекта в упаковщике, повторная проверка данных сохранена.

Общие Gemma, GigaChat, Giga-Embeddings и их runtime продолжают использоваться
проектом. Удаление относится к Hy-Memory, не к выбранной модели самого чата.
Единое ТЗ сценария остаётся активным; отказ от кандидата не закрывает весь сценарий.
