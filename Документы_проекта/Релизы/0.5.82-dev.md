# 0.5.82-dev — просмотр и правка книги перед сохранением

При конвертации внутри утилиты готовый результат сначала открывается для
проверки. Его можно сохранить, пропустить или открыть в отдельном минимальном
редакторе текста. После применения правок выполняются повторный экспорт,
проверка происхождения/формата и обновление просмотра. Исходники не изменяются.
В пакете просматривается каждый выходной файл, при объединении — одна книга.

Книжное меню Проводника переименовано в «Перекодировать». Его отдельный тумблер
перенесён в Общие → Интеграция с Windows с сохранением прежнего состояния.
Тихая конвертация ПКМ обходится без нового диалога.

Модель документа, просмотр, редактор и экспорт разделены для будущего расширения.
Это структурный просмотр и минимальная правка текста, без обещания полной
совместимости с печатной вёрсткой Word/PDF. Новых зависимостей или моделей нет;
версии calibre/LibreOffice и музыкальных/рисующих движков прежние.

[проверки и ограничения](../../Тесты/BookConverterStand/README.md).
