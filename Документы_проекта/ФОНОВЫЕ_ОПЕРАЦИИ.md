Отмена удаляет только свой временный partial; PCM остаётся для продолжения.
Повторный запуск runner не вызывает модель для сохранённого PCM или готового
варианта. После фиксации завершения временный PCM нового задания удаляется.
Старые WAV-only задания сохраняют прежний контракт восстановления.

FFmpeg/ffprobe зарегистрированы как `Music.Audio` в OwnedProcessRegistry.
Отмена/тайм-аут ждут выхода своего процесса; DLL не требуют системной установки.
Прямые проверки короткого синтетического PCM покрывают сбой дубля, отмену,
восстановление, повреждение результата и сохранность источника плеера.
Реальная длительная генерация и физическая пауза GPU этим проходом не измерены.

### Быстрые команды Проводника

`image-shell`: `MainWindow.ImageShell.cs` → `ImageShellQueueRunner` →
`ImageShellProcessor` → встроенная CPU-обработка. Эта очередь использует
тот же `ApplicationBackgroundOperations` и ожидает завершения или разрешения
уже находящейся в общем механизме операции. Новые команды не прерывают её.

Single-instance IPC принимает запрос без показа главного окна. Если ЛОПАТА
не запущена, shell-команда запускает её скрыто; после обработки приложение
остаётся в трее. Приём подтверждается только после сохранения запроса
в `app-data/image-shell`. Повтор доставки с тем же RequestId не создаёт
новую работу. Идентификатор запроса служит Project в контрольной точке;
статусы файлов и число попыток сохраняются после каждого перехода.
После ошибки предусмотрены три повтора. Пауза сохраняет незавершённый файл
и не расходует попытку ошибки; готовые файлы не обрабатываются повторно.

Журнал файловой транзакции сохраняет этапы подготовки и публикации,
идентичность исходника/результата и SHA-256. Продолжение после остановки
проверяет уже опубликованный результат и завершает только незавершённый
этап; оно не увеличивает готовое изображение ещё вдвое. Замена исходника
допустима только для этих двух явно выбранных shell-команд, полная утилита
остаётся с политикой сохранения исходников. Уведомление результата открывает
Проводник с соответствующим файлом; ошибка очереди даёт уведомление в трее.
Модели и новые фоновые runtime не используются. Итоговые проверки этого
пути заносятся в общий протокол отдельно от приёмки утилиты и ИИ-методов.

## Общие ресурсы и оставшиеся проверки

ApplicationBackgroundOperations хранит слабые ссылки на собственные runtime
и пытается освободить все зарегистрированные модели даже при отказе одной.
