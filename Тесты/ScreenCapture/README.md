чтобы не активировать внешнее окно под курсором. Критерии записи не ослаблены.

Полный проход с настоящим MainWindow в отдельном профиле:

```powershell
$env:LOPATA_UPDATE_STAND_ROOT = 'H:/AI_HUB/Тесты/ScreenCapture/isolated-profile'
dotnet run --project 'Тесты/ScreenCapture/Probe.csproj' -p:DefineConstants=UPDATE_STAND -v quiet
Remove-Item Env:LOPATA_UPDATE_STAND_ROOT
dotnet build 'Исходники/AIHub/AIHub.csproj'
```

Последняя обычная сборка обязательна: UPDATE_STAND меняет путь данных только
в тестовом варианте. Стенд не принимает лицензии в пользовательском профиле,
не читает текст буфера и не записывает в настоящий буфер. Проверки выдачи
используют адаптер; реальные файлы создаются только внутри стенда.

Подтверждённый полный проход: **137/137**, `runs/20261002_204716/checks.txt`.
Проверены WGC hardware/WARP, содержимое тестового окна, декодирование PNG,
JPEG, WebP lossless/lossy, уникальность имён, оригинал/увеличенная область,
страховка перед подтверждением замены текста, отказ/ошибка/смена буфера,
лимиты размеров, сохранение настроек, RU/EN и ресурсы обеих тем.

Геометрия измерена на настоящих мониторах 3840×2160 и 1920×1080 слева,
объединение (-1920,0,5760,2160). Overlay проверен через его native rect и
управляемый физический указатель: выделение 200×150. Это не проверка каждого
возможного реального жеста, поворота экрана или HDR. Расширенные клавиши
F13/F14, четыре зажатые клавиши и Mouse X1 проверены синтетическими
Windows-событиями; отдельные аппаратные кнопки зависят от драйвера.

MainWindow: видимый/скрытый снимок, сохранение страницы и размещения,
отказ восстановления по настройке, Back из настроек и утилиты.
Стандартный системный конфликт клавиш отключается с пояснением;
внешние сложные сочетания другого приложения полностью обнаружить нельзя.

Не выполнено здесь: совместное продвижение длительного импорта с реальной
GPU-моделью, запись GIF/видео, измерение ресурсов записи и все устройства
дополнительного ввода. Тестовые снимки интерфейса прозрачные: ресурсы тем
проверяются отдельно, эти изображения не являются скриншотами всего приложения.
