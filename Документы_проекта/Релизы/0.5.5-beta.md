# ЛОПАТА 0.5.5-beta

Добавлена утилита «Публикатор разработчика GitHub → ВК» в «Обработка / утилиты».
Она читает опубликованные выпуски открытых GitHub-репозиториев, включая бета,
и отправляет новости от имени подключённого сообщества ВК.

- Сохранённые направления показывают источник, сообщество, режим и даты.
- Подключение пошаговое: куда, откуда, затем ручная или автоматическая публикация.
- «Показать все» открывает историю выпусков; галочками можно выбрать пропущенные.
- Есть предпросмотр и постепенная очередь для публикации старых выпусков.
- Проверки работают и в трее; автоматическая отправка включается для каждого направления отдельно.
- История отправок сохраняется. Потерянный ответ требует проверки, без слепого повтора поста.
- Ключ ВК скрыт при вводе и хранится зашифрованным средствами Windows для текущего пользователя.

Можно вставить ссылку на репозиторий или его страницу /releases. Ссылка проекта
в окне «?» теперь открывает выпуски. Сетевое ожидание ограничено, включая
чтение ответа; сообщения об отмене и истечении времени различаются.
Таблицы, выделение, меню, поля и подтверждения утилиты согласованы с обеими темами.

Публикацию в ВК проверил пользователь. Автоматическая отправка выключена по умолчанию.
Для установки используйте существующий [универсальный миниустановщик](https://github.com/PiTrolKun/LOPATA/releases/download/v0.5.2-beta/LOPATA_Setup.exe).
Установленная ЛОПАТА в бета-направлении получает подписанное файловое обновление.
