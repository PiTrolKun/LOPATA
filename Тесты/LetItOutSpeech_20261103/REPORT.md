# Прослушивание чата «Если накипело»

Начато 03.11.2026, завершение проверок 04.11.2026. Версия 0.7.15-dev.
Основание: поручение добавить прослушивание сообщений и верхнюю кнопку звука;
дополнительное замечание пользователя — белый список моделей во время генерации.

## Реализация

- Кнопка настроек звука перед общим STOP, видна в чате. Общее с видеоредактором
  окно VideoVoiceWindow: все 10 вариантов, загрузка/удаление через прежние службы,
  голоса, языки, устройство, темп и специфичные параметры. Kokoro также можно
  удалить через общий guard и retirement; общие файлы не дублируются для чата.
- Профили чата независимы от видеопроектов и сохраняются по модели в AppSettings.
  Авточтение по умолчанию выключено. Кнопки есть у полных пользовательских сообщений
  и ответов ИИ; частичные ответы не озвучиваются. Открытие истории ничего не читает.
- Тест использует текущий профиль и короткую фразу на языке синтеза. Проба сразу
  проигрывается и доступна повторно. Есть открытие папки локальных WAV.
- ChatSpeechWork: приватная операция `chat.let_it_out.speech`, единая очередь,
  пауза/возобновление и проверки прежних runtime/лицензий/ComponentAudit. Длинный
  текст обрабатывается частями до 600 символов без тихого усечения; готовые части
  переживают паузу. Кеш учитывает текст, параметры, модельную и runtime-ревизию.
  Проверяется целостность созданного WAV. Смена параметров не уничтожает старое аудио.
- Один проигрыватель. Новая ручная озвучка останавливает прежнюю; повторный клик,
  новый вопрос, смена темы, уход из чата, закрытие и общий STOP прекращают чтение.
  Восстановление задания заканчивает синтез, не начинает неожиданное проигрывание.
- При подготовке/синтезе не создаются новые записи в разговоре и не меняется его текст.
  Рабочие request/log лежат в дочернем `work`, публикуемые файлы — нумерованные WAV.
  Корень по умолчанию: `%LOCALAPPDATA%\AI_HUB\Chat\Audio`.
- Источник runtime уже содержал видеоредакторскую отметку: PCM копируется в свежий
  WAV, затем записывается ровно одна новая provenance-запись сценария чата с
  фактическими моделями/ревизиями и версией ЛОПАТЫ. Звук и исходный trial не меняются.
- По замечанию пользователя стандартный шаблон ListBox заменён тематическим:
  отключённое состояние не подставляет белый системный фон. Это общее исправление
  окна каталога, доступное и в видеоредакторе.

## Проверки

Финальный прогон `regression-theme`: 192 теста, 158 PASS, 34 ожидаемых opt-in SKIP,
0 FAIL. В него входят тесты чата/диктовки/навигации/голосовых настроек видеоредактора.
Новые проверки: профили и значения по умолчанию, длинный Unicode-текст, тестовые
фразы всех языков каталога, пауза с повтором только незавершённой части, повреждённый
кеш и смена профиля; UI RU/EN, dark/light, обе стороны сообщений, отсутствие
авточтения старой истории, реальный шаблон отключённого списка во время пробы.

Отдельный `physical-final`: 2 PASS, 0 FAIL. Установленные Vosk и Supertonic,
CPU, без скачивания новых компонентов. WAV 4,319 и 5,016 секунды. Измеренное
время первого Generate: Vosk 38,558 с, Supertonic 8,170 с; оно включает подготовку
и необходимые проверки компонентов, а не только сам акустический расчёт.
Повторное чтение кеша: 0,0076 с и 0,0190 с. Другие модели в этом проходе физически
не синтезировались; их прежние исполнители и параметры переиспользованы без замены.

Независимый PowerShell RIFF/ID3-парсер `check-wave-provenance.ps1` подтвердил
по одной записи LOPATA_PROVENANCE в обоих WAV: версия 0.7.15-dev,
`chat/let-it-out/speech`, реальные модель/runtime/hardware-ревизии. PCM не пустой.
Результат — `provenance.json`.

Сборка: 0 ошибок, 6 прежних предупреждений (NU1902/NU1903, CS4014, MSTEST0040
в старых тестах). Новых предупреждений в изменённых файлах нет. Restore успешен.
Первый rebuild после визуального замечания не заменил занятый apphost: модальное
окно закрыто штатно, после запроса закрытия остановлен только точный dev-процесс;
финальная сборка и регрессия успешны. На этот момент синтез уже не был активен.
Настоящие сообщения/SQLite не редактировались.

Предварительный safe-start открыл 0.7.15-dev (PID 40508). В реальном окне проверены
верхняя кнопка, 10 карточек, выключенный автотумблер, кнопки теста и папки;
`live-settings.json`. Проба дошла до создания WAV в папке чата; пользователь
параллельно пробовал другой профиль и сообщил визуальное замечание. После него
сделана повторная сборка; итоговый запуск — `safe-start-final.log`.

Проверка UTF-8/Cyrillic и scoped diff-check выполнены; результаты `utf8.log`,
`diff-check.log`. Все 14 новых ключей RU/EN присутствуют. Отдельные физические
проверки скачивания/удаления больших моделей в реальном хранилище не проводились:
используются прежние службы и guard, UI-вызовы проверены в изоляции.
