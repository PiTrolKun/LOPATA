# ЛОПАТА 0.9.13-beta

«Мастерская анимированных ассетов» открывается со смайлика рядом с геймпадом на странице «Начало работы».

- «Быстро оживить» добавляет готовое движение к картинке. Для него достаточно базовых компонентов.
- В покадровом режиме Художник рисует опорные позы, а ЛОПАТА рассчитывает плавные переходы. Советник может разложить описание сценки на шаги.
- Набор реакций собирается по одному утверждённому образу. Можно выбрать нужные выражения из 110 лицевых эмодзи и запустить весь набор одной очередью.
- Доступны GIF, WebP и WebM, включая профиль видеостикера Telegram. Проект можно сохранить и продолжить позже.

На встроенной странице подготовки видны статусы компонентов и модели, которые требуется скачать. Проверка учитывает общий режим аудита. Кнопки следуют выбранной теме ЛОПАТЫ.
