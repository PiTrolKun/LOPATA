## Запуск вручную

Открыть двойным щелчком **Start-Gemma4-QAT.cmd** в этой папке.
Он использует PowerShell 7 из PATH либо уже установленного комплекта Codex.
После проверки файла и загрузки модели вводить сообщения у приглашения чата.
Enter отправляет сообщение; /clear начинает новую беседу с тем же системным промптом;
/exit завершает процесс. Ctrl+C останавливает генерацию, повторный Ctrl+C выходит.

По умолчанию выбран существующий llama.cpp Vulkan из набора движков 002.
Устройство выбирает runtime; NVIDIA/CUDA0 не зафиксированы.
Ручной CPU-вариант из терминала в этой папке: `./launch.ps1 -Backend cpu`.
Устройство Vulkan можно явно задать параметром `-Device`.
Никакого скрытого повторного запуска после ошибки GPU нет.

Переписка каждого запуска сохраняется в отдельную папку
`sessions/<дата_время_идентификатор>/conversation.txt`.
Рядом сохраняются копия системного промпта, параметры запуска, native.log и код выхода.
Старые беседы не перезаписываются. Системный промпт не восстанавливает прошлые беседы:
каждый запуск начинает новый разговор.

Скрипт использует готовую процедуру скачивания прежнего стенда, указанный в ней
результат проверки относится к новому QAT-файлу, а не к удалённым даосским моделям.

## Системный промпт и стартовые параметры

`system.txt` — точная копия последнего авторского промпта пользователя
«самостоятельный, внимательный собеседник с даосским мировоззрением».
SHA-256: `3184ea14e277c82e99dd3a3e812a448244a092ba6468ab74224f84f2700027c0`.
Текст не сокращался, примеры и скрытые подсказки не добавлялись.

Стартовая конфигурация: контекст 16384, максимум ответа 1536 токенов,
temperature 1.0, top_p 0.95, top_k 64, min_p 0, repeat_penalty 1,
presence_penalty 0, frequency_penalty 0, seed 42. Thinking выключен,
история рассуждений не переносится, автоматический сдвиг контекста выключен.
При заполнении контекста нужно начать новую беседу, а не молча терять начало.
Vulkan использует автоматическое размещение слоёв и запас памяти 1536 MiB;
CPU включается явно. Эти настройки ещё не подбирались по качеству ответов.

Первые три параметра выборки соответствуют [рекомендации Unsloth](https://unsloth.ai/docs/models/gemma-4).
Для QAT см. [отдельное руководство](https://unsloth.ai/docs/models/gemma-4/qat).
Перед каждым ручным запуском скрипт сверяет весь файл по размеру и SHA-256;
это отдельный исследовательский запуск, а не новый путь ComponentAudit приложения.

## Проверки подготовки и границы

Доступны отдельные записи проверок синтаксиса/аргументов и режима ValidateOnly.
`./launch.ps1 -ValidateOnly` проверяет файлы и формирует команду, не загружая модель.
Общий runtime не обновлялся: llama.cpp b11669 / commit 620d2225c.
В [этой ревизии](https://github.com/ggml-org/llama.cpp/blob/620d2225cc436ab0b001e3200e590e3b286ef9ab/src/models/gemma4.cpp)
есть Gemma4 26B_A4B. [Обработчик аргументов](https://github.com/ggml-org/llama.cpp/blob/620d2225cc436ab0b001e3200e590e3b286ef9ab/common/arg.cpp)
передаёт enable_thinking=false при --reasoning off. Это проверка совместимости
по исходникам. Последующий физический повтор двух реплик описан в отчёте выше;
полные испытания русского языка, длинной истории и поведения ещё не проводились.

Первоначальное скачивание non-QAT остановлено после поправки пользователя.

не смог из-за `blocked by policy`. Он не используется этим запуском.
Путь к остатку и блокировка очистки сохранены в `non-qat-cleanup.json`;
сама отмена выбора — в `acquisition/SUPERSEDED_BY_USER.json`.
Прежние даосские результаты сохраняются в `../LetItOutDaoismStand_20261102`.
