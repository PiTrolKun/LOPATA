## Отличие от Studio и повторные работы

- Компоненты ACE: 25 253 699 649 байт весов/компаньонов и 193 600 704 байта wheels.
  UI и worker независимо вызывают полную проверку этих файлов подряд.
- MusicAceRuntime.VerifyAsync заново читает каждое колесо, вычисляет SHA256,
  открывает ZIP, хеширует распакованное содержимое каждого entry и сравнивает
  с установленным файлом. В установленном overlay 19 937 файлов (локальный
  files.json использован только для подсчёта, а не для подтверждения целостности).
- ManagedPythonRuntime.ResolveAsync проверяет весь подготовленный аппаратный
  комплект перед запуском hardware probe. Закреплённый cu126 manifest содержит
  19 564 файла суммарно 4 323 315 735 байт. Затем дерево обходится ещё раз для
  проверки отсутствия лишних файлов. Для каждого пути RejectLinks проходит
  через его предков; многие общие предки повторяются.
- Studio использует подготовленные native executables/DLL. Ей не требуется
  отдельный Python overlay ACE и проверка большого дерева PyTorch, импорт
  Python hardware probe и затем импорт официального ACE API. Studio тоже
  проверяет компоненты; вывод «она вообще ничего не проверяет» неверен.

Скорость накопителя, файлового кэша и антивируса отдельно не измерялась.
Нельзя приписывать 114/104 секунды именно антивирусу или только SHA256.
Не все подэтапы имеют отдельные таймеры, поэтому остаточные времена приблизительны.

## Реалистичные направления ускорения

Самый очевидный повтор — второе чтение того же комплекта ACE внутри одного
открытия. Сокращение этого чтения должно сохранять связь проверки с точными
файлами и учитывать изменения/конкурентный доступ, а не доверять карточке Installed.

Основной потенциальный выигрыш — около 39.5 тысяч файлов двух Python-деревьев:
проверить ограниченную параллельность, повторный обход путей и возможность
независимо закреплённого манифеста overlay вместо повторного ZIP-разбора wheels.
Повторная проверка содержимого остаётся обязательной, если нет надёжного
механизма обнаружения его изменений. Размер/mtime и локальная квитанция
не заменяют криптографическую проверку.

Обещать конкретное новое время до реализации и замеров нельзя. Импорт API
сам по себе здесь занимает около 11 с, а не несколько минут.
