# ЛОПАТА 0.5.104-beta — музыкальные LoRA

- Готовые LoRA для YuE2 Studio и ACE XL Turbo: можно выбрать несколько,
  настроить влияние каждой и временно отключить применение через ПКМ по кнопке.
  Выбор сохраняется в проекте. Есть скачивание/удаление отдельно и всей подборки.
- Поиск на Hugging Face по пожеланиям песни, ручным параметрам, названию или ссылке.
  Результаты появляются сразу и дополняются параллельно; скачивать можно во время
  поиска. Установленные варианты скрываются. Лайки и скачивания помогают выбору,
  но не определяют отбор. После скачивания доступен пересказ описания локальным ядром.
- Фильтр «Только выбранные» и звёздочки для закрепления любимых LoRA наверху.
- Оценка дополнительной памяти и всплывающие предупреждения о рискованных
  сочетаниях. При некорректном музыкальном плане программа объясняет вероятный
  конфликт, сохраняя исходные настройки и подробности в журнале.

Поставка содержит механику и каталог, без весов и личной коллекции пользователя.
Веса скачиваются по выбору пользователя с проверкой источника и условий автора.
Предварительная техническая проверка не гарантирует качество или совместимость
всех сочетаний; у других музыкальных моделей подготовленных LoRA пока нет.
Это тестовая бета. Файловое обновление сохраняет проекты, модели, настройки,
прежние наборы движков и ручной выбор. Полный установщик не пересобирался.
