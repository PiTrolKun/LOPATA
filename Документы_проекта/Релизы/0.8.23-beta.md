# ЛОПАТА 0.8.23-beta

Перед открытием «Шортсов» ЛОПАТА проверяет полный комплект для обоих режимов. Стандартное окно подготовки показывает недостающие компоненты и позволяет их скачать. В комплект входят MiniMax H3, Qwen3.6-27B для планирования сцен и DLSS.

Проверка использует общий переключатель «Аудит компонентов». Установленные файлы повторно не загружаются. Если для продолжения сохранённого задания нужны файлы, их можно подготовить в том же окне.
