# ТЗ — Музыкальное окно, шаг 3: пожелания к музыке

Статус закрытия: выполнено и принято пользователем 05.10.2026; архивировано
в составе 0.4.0-dev / публичного выпуска 0.4.0-beta. Принят первый музыкальный
сценарий. Будущие MIDI/расширенные инструменты, чат стихов и улучшение рифмы
остаются согласованными направлениями развития, а не выполненными функциями.
Датированные записи ниже сохранены как история этапов.


Дата: 05.10.2026. Статус: шаг принят пользователем после визуального уточнения 0.3.37-dev; продолжается родительское ТЗ рабочего окна. Редактор шага 2 принят пользователем.

## Цель и границы

Заполнить узкую колонку справа от текста песни. Простые пожелания задаются
галочками; группы вариантов открываются в отдельных окнах с галочками,
применением и отменой. Основного чата нет. Шаги 4–7 не реализуются в этом проходе:
кнопка назначения исполнителя тексту, ударение, плеер, генерация и её управление
остаются следующими этапами. Максимальная длительность согласована для будущей
панели генерации; это ограничение сверху, а не обещание точного хронометража.

## Состав

- Без вокала, без хора, без бэк-вокала — простые пожелания.
- Жанры: полный встроенный снимок списка названий MusicBrainz, поиск по названиям
  и русским поисковым синонимам, любое количество выбранных, собственные жанры.
  Смена поиска сохраняет выбор. Не заявлять полноту всех жанров человечества.
  Использовать только CC0 core data (названия/ID), без пользовательских тегов,
  рейтингов, связей жанров с артистами и чужих описаний. Каталог работает офлайн.
- Настроение, манера исполнения, инструменты, темп/ритм, развитие звучания,
  нежелательные особенности — отдельные окна множественного выбора.
- Исполнители: создавать, редактировать, удалять независимые карточки с устойчивым
  ID, именем, типом/высотой голоса, тембром, манерой, языком и своими пожеланиями.
  Поля с небольшим числом взаимоисключающих вариантов — выбор одного значения;
  совместимые свойства тембра и манеры — галочки. Дубликаты имён не принимать.
  Исполнителей сохранять для будущей привязки фрагментам; кнопку привязки пока
  не добавлять. Индивидуальные голоса/смена ролей экспериментальны по решению
  пользователя; это не причина урезать интерфейс настроек.
- В инструментах подсвечивать рекомендации по совокупности выбранных жанров.
  Правила рекомендаций — наши эвристики, без скрытого выбора и запрета остальных.
  Учитывать пересечения жанров, для неизвестного жанра не выдумывать соответствие.

## Поведение и данные

Состояние сохраняется в экземпляре рабочего окна при теме, локализации, возврате
и смене расположения модели, как текущий редактор. Новое долговременное хранение
проектов не вводится до обсуждения жизненного цикла музыкального проекта.
Изменения отдельного окна применяются атомарно, отмена/крестик исходное состояние
не меняют. Выбранные значения показаны коротким резюме под кнопкой.
При «Без вокала» настройки исполнителей и исполнения недоступны, но сохраняются
и восстанавливаются после снятия галочки. В запрос включаются только активные
пожелания; инструментальный режим использует пустые lyrics, сохраняя редактор.
Не изменять текст/отмену редактора при смене параметров. Структура песни остаётся
в тексте. Описание собирается в style с понятными модельными английскими тегами;
свои значения передаются как введены. Отдельного negative prompt нет: исключения
являются пожеланиями в style. Никакой гарантии их исполнения не заявляется.
Общий запрос и доступный вес пересчитываются штатным токенизатором после смены
пожеланий. Без вокала можно подготовить задание без текста; со словами пустой
текст не допускается. Пока генератора нет, проверить контракт выдачи задания.

названий жанров, 79 русских поисковых подсказок, свои значения и множественный
