# Приёмка внешних агентов в 0.9.16

24 ноября 2026 года пользователь принял ТЗ после проверки в рабочем окне ЛОПАТЫ. [Архив ТЗ](../../ТЗ/Архив/2026-11-24_Подключение_внешних_ИИ-агентов.md) · [Проверка подключения в установленной 0.9.14-beta](0.9.14-beta_проверки.md)

В dev прошёл 41 профильный тест. Прямой запрос из чата Codex без указания имени клиента вернул список сценариев. Слева от STOP появился значок приложения из Windows с подсказкой «Codex запрашивает сведения о сценариях». Через три секунды после ответа значок исчез. Тестовый клиент без своего изображения получил отдельную пиктограмму монитора.

На этом ПК при запуске обнаружены Codex, ChatGPT Classic и DeepSeek Harness. После связи с Codex кнопка предложила подключить две оставшиеся программы. Наличие GitHub Copilot проверяется отдельно от Microsoft 365 Copilot. Распознавание названий из списка проверено автотестами. Прямое подключение через интерфейс каждого из остальных клиентов отдельно не испытывалось.

Полный установщик не пересобирался. Выпуск поставляется через штатное файловое обновление.
