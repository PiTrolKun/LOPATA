# Проверки ЛОПАТЫ 0.9.28-beta

- На обычном пути запуска проверен обновлённый запускатор с действующей установкой 0.9.27-beta. При масштабе Windows 200% читаются статус и кнопка «Отменить», индикатор движется в тёмной полосе. Окно отдаёт Windows фирменную иконку. Главное окно открывается.
- Пройдены 112 тестов обновлятора. Проверка плана обновления действующей установки 0.9.27-beta подтвердила замену запускатора без операций удаления.
- Проверены подписи переходного и установочного манифестов и манифестов наборов движков. Сохранены все 8 012 путей предыдущего переходного манифеста. Исполняемый файл запускатора в архиве соответствует подписанному манифесту и содержит фирменную иконку.
- На GitHub сверены размеры и SHA-256 всех 25 вложений. Тег указывает на коммит сборки. [Выпуск](https://github.com/PiTrolKun/LOPATA/releases/tag/v0.9.28-beta)

Проверка окна выполнена обычным запуском. Для публикации собран подписанный файловый патч бета-канала.
