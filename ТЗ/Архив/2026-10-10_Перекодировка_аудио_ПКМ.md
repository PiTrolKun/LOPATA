# Перекодировка аудио через ПКМ в Проводнике

Статус: выполнено и принято пользователем. Дата: 10.10.2026.
Основание: прямое согласование пользователя. Версия: 0.5.6-dev.

## Цель и интерфейс

Только команда «ЛОПАТА → Перекодировать аудио…» для одного/нескольких файлов
Проводника. Отдельной страницы утилиты, редактора очередей и импорта папок нет.
Компактное вспомогательное окно: список выбранных файлов, формат MP3/Opus/FLAC/WAV,
битрейт для сжатых форматов, папка (по умолчанию рядом с исходником), начать,
отмена, прогресс, открыть результат. RU/EN, обе темы, перенос длинных строк.
Повторные обращения Проводника собираются в одном окне через существующий
защищённый per-user/per-installation IPC. Передача путей не запускает обработку.
Команда использует существующий переключатель интеграции Windows;
в Windows 11 допустимо «Показать дополнительные параметры».

## Обязательное сохранение данных

Исходники не меняются; существующие результаты не перезаписываются.
Читаем исходные теги, включая lyrics/comment/LOPATA_*; переносим их в контейнер,
где возможно, сверяем результат. Обложки и неизвестные контейнерные поля нельзя
молча терять: рядом с каждым результатом сохраняется `.metadata.json` с исходными
тегами, исходными бинарными блоками метаданных (включая изображения) и SHA256
результата. Пользователь видит предупреждение об этом до начала.
Сопроводительные файлы предыдущей перекодировки также сохраняются при повторной
перекодировке после проверки связи SHA256. Резервная копия содержит именно
метаданные, не исходную песню целиком. Не обещать распознавание любого неизвестного
тега сторонними проигрывателями; наличие побайтной копии и читаемого переноса
проверяются раздельно. ЛОПАТА не подменяет исходные параметры генерации новыми.

## Обработка и безопасность

Изолированный существующий `music.audio` FFmpeg; CPU, без моделей/сети/кодек-паков.
Отдельный конвертер: не использовать нормализующий WAV 48kHz stereo путь генератора.
Сохранять частоту/каналы там, где формат позволяет; Opus имеет штатную 48kHz шкалу.
Текущая поставка декодирует WAV PCM16; неподдерживаемые кодеки/разрядность
обнаруживать до записи и объяснять, не снижать точность молча.
FLAC не восстанавливает потерянное качество MP3/Opus. Один выбранный выходной формат.
Проверка длительности, числа каналов, частоты, полного декодирования, тегов,
целостности резервных метаданных. Временные файлы принадлежат операции;
публикация без перезаписи, отмена удаляет только свои незавершённые файлы.
Ошибка одного файла не блокирует остальные. Закрытие окна отменяет текущую работу,
готовые результаты сохраняются. Вспомогательное окно имеет локальный жизненный цикл
по исключению §15 AGENTS; основной музыкальный/изобразительный конвейер не меняется.

## Модули и проверки

AudioShellRequest/Protocol/Integration, отдельные AudioConversionMetadata/Archive/
Service, AudioConversionWindow, связь App/SingleApplicationInstance/MainWindow.
Обновить настройки интеграции, uninstall обоих шаблонов, облако механик
(переход к настройкам Windows, не к отдельной странице), RU/EN и историю.
ТЗ остаётся активно до пользовательской приёмки. Версия правки — 0.5.6-dev;
публикация и пересборка установщика сейчас не требуются.

Проверки: входы/IPC/registry ownership, четыре формата, русские и длинные теги,
lyrics/LOPATA_*, обложки/неизвестные бинарные поля, повторная перекодировка,
моно/44.1kHz, столкновения имён, повреждённые файлы, отмена, обе темы/языка/DPI,
build/профильные и имеющиеся регрессионные тесты, UTF-8 scanner, safe-start.

## Backup и риски

Оригиналы: `_backups/20261010_audio_shell/files.json`, path-safe копии.
Риски: разные стандарты тегов, непрочитанные сторонними программами WAV ID3,
ограничения нативного комплекта, повреждённые/огромные метаданные, конкурентные
изменения файлов. При невозможности полной резервной копии файл не публикуется.
Существующие посторонние изменения рабочего дерева не затрагивать.
