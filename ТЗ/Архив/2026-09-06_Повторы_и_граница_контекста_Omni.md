# ТЗ — автоматические повторы и защита контекста

Дата: 2026-09-06. Статус: выполнено и принято пользователем 2026-09-06 в 0.1.48-dev; закрыто и архивировано. Проверены 386 .NET и 10 Python тестов, WPF RU/EN обе темы, реальный протокол подсчёта и safe-start. Отчёт: Тесты/Omni_guard_20260906/README.md.

## Согласованное поведение

Для общего двухэтапного Omni-сценария Альфы и Гаммы добавить до трёх автоматических попыток формирования корректного результата. Повторяется неудачный этап; готовое наблюдение сохраняется. Не добавлять неудачные ответы в историю разговора. Каждый сырой ответ сохранять отдельно, версию создавать только после успешного разбора. При повторе показывать «Ожидайте, потребовалось чуть больше времени…», без счётчика попыток. После третьего нарушения формата предложить перезапустить программу и повторить анализ. Ошибки памяти, отмену и исчерпание контекста автоматически не повторять. Перезапуск процесса при неправильном JSON не нужен.

Перед каждым модельным запросом, включая анализ, compose, revise и повторы, проверять будущий вход с шаблоном, историей, изображением и резервом ответа. Порог — 95% рабочего окна runtime, не максимального окна из карточки модели. Минимальный резерв — 4096 токенов, включая рассуждения; оставшийся разрешённый бюджет ответа ограничить границей 95%. При достижении границы не принимать обрезанный ответ за готовый результат.

Для Альфы использовать /apply-template и /tokenize установленного llama.cpp b9442. Этот API считает текст, поэтому дополнительно учитывать консервативный верхний предел 4096 визуальных токенов на каждое вхождение изображения; явно закрепить существующий предел backend аргументом --image-max-tokens. Это безопасная оценка, а не точное измерение картинки; она может предупредить раньше. Для Гаммы проверять точный размер input_ids после processor и до model.generate. Не вводить дополнительную генерацию ради подсчёта.

Блокировка сессии сохраняется на диск и переживает повторное открытие. Автоматически не удалять историю, версии или файлы. Не добавлять кнопок или диалогов подтверждения: использовать существующий статус и навигацию; просмотр и экспорт готовых версий доступны. Предупреждение объясняет необходимость новой сессии и сохранность результатов. Новая работа получает чистый контекст. Существующие данные без нового поля остаются совместимыми. Бета использует другой pipeline; её перевод на общий Omni-сценарий не входит в эту доработку.

## Проверки и закрытие

Проверить границы ниже/на/выше 95%, резерв ответа и визуальный бюджет; два сбоя и третий успех, три сбоя, отсутствие повторов при отмене/контексте/ошибке runtime, неизменность предыдущих версий и точного анализа. Проверить сохранение блокировки, RU/EN и доступность экспорта без новых кнопок. Restore/build/test, Python boundary tests, scanner, diff и штатный safe-start. Реальные модельные тесты — короткие, только для проверки протокола подсчёта, без повторения серии качества.
