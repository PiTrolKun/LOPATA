# Стенд связанной памяти `.lopata`

Это исследовательская схема версии 1. Приложение ЛОПАТА пока не читает эти контейнеры.

## Состав

- `book_source.py` — EPUB в порядке spine, текст глав и заключения. Обложка и издательская аннотация исключены; эпиграфы сохранены. Пробелы внутри строк нормализованы один раз до фиксации версии. Адреса считаются в символах этого сохранённого текста, не в байтах EPUB.
- `book_adapters.py` — родные вызовы GLiNER, NuExtract3 и отдельный llama-server для Runeweaver. Модели получают только текущий фрагмент и описание полей; историю чужих ответов не получают.
- `jelly_store.py` — единая схема SQLite, параметризованные операции, транзакции и проверка адресов цитат.
- `book_run.py` — отдельная папка модели, запись сырого ответа и фиксация фрагмента. Повторный запуск пропускает зафиксированные фрагменты; ответ, успевший сохраниться до сбоя транзакции, используется повторно. Несовпадение версии исходника/контракта требует новой папки серии.
- `book_inspect.py` — чтение записей и экспорт для проверки человеком.
- `test_store.py` — механическая проверка контейнера, не тест интеллекта модели.
- `book_checks.json` — контрольные вопросы для ручной оценки, не вход моделей.

## Хранение

Каждая папка кандидата содержит `память.lopata`, сырые `chunk-*.json`, параметры запуска и отчёт целостности. В самой базе: полный исходный текст, его SHA256, область `reference`, позиции фрагментов, объекты/упоминания, события, утверждения, доказательства и журнал добавлений.

`entity` пока является локальной группой точных упоминаний внутри фрагмента. Одинаковое написание не доказывает одинаковую личность; `identity_status=unresolved_mention_group` прямо сохраняет эту неопределённость. Между фрагментами личности не склеиваются. События связываются с субъектом, возможным объектом и доказательством через ключи. Свободный текст значения допускается отдельно от ссылки на объект.

Тип сообщения (`narrated/reported/belief/intention/hypothesis/unknown`), перспектива и сюжетное время независимы. Статус всех извлечений — `unreviewed`. Программа проверяет форму и происхождение цитаты, но не объявляет содержание истинным. Первая точная позиция повторяющейся цитаты используется как адрес; различение одинаковых упоминаний остаётся будущей работой.

SQLite работает с `synchronous=FULL`, журналом DELETE и внешними ключами. Во время транзакции журнал находится рядом; после штатного завершения основной контейнер один. OS-блокировка серии освобождается после завершения процесса или перезагрузки. Не переносить работающую базу простым копированием; сначала завершить стенд. Автоматический резерв пользовательского проекта и продуктовое восстановление ещё не реализованы.

## Запуск из корня репозитория

```powershell
& 'Runtime/Python/giga-embeddings/py312-torch210-transformers530/python.exe' 'Тесты/JellyModels/book_run.py' gliner --run book-next
& 'Runtime/Python/giga-embeddings/py312-torch210-transformers530/python.exe' 'Тесты/JellyModels/book_run.py' nuextract --run book-next
& 'Runtime/Python/giga-embeddings/py312-torch210-transformers530/python.exe' 'Тесты/JellyModels/book_run.py' runeweaver --run book-next
```

Запускать по очереди. GLiNER — CPU, 6 потоков; NuExtract — BF16 на GPU; Runeweaver — штатный GGUF Q4_K_M, один слот отдельного локального сервера, без повторного использования prompt cache. Данные в сеть не отправляются. Наличие моделей и библиотек обеспечено предыдущим этапом.

Для нового контракта выбрать другое имя `--run`. `--limit 1` проверяет только первый фрагмент. Для чтения указать контейнер в `book_inspect.py`, при необходимости `--query Германн` или `--export`.

Серии `book-02` и `verified` уже зафиксированы: не использовать их имена для новой генерации. В `verified` повторно проверены старые ответы с исправленной проверкой границ слов; это пересборка, не новые ответы модели. `book_rebuild.py` создаёт этот результат один раз и отказывается перезаписывать папку. `book_split.py 19` подготавливает меньшие части проблемного фрагмента; `book_run.py nuextract --run small-next --source source-small-19.json` выполняет отдельный контроль.

## Ограничения сравнения

Общий текст и формат хранения одинаковы, но способы извлечения различаются. Это проверка применимости кандидатов в нашем конвейере, не рейтинг моделей по одинаковому вычислительному бюджету. Доставка всех фрагментов не означает извлечение всех знаний. Единичные ошибки рассматриваются по источнику; выборка не даёт процента достоверности всей книги. Механизм исправления и разрешения противоречий оставлен для следующего обсуждения с пользователем.
