# ЛОПАТА 0.5.55-beta

Добавлена утилита подготовки локальных баз знаний из TXT, HTML и PDF.
Она сохраняет прогресс, работает при свёрнутой программе и продолжает
подготовку после перезапуска. При паузе можно пользоваться другими сценариями.

- Обработка страниц выполняется параллельно с учётом памяти и ориентиром
  общей нагрузки CPU (по умолчанию 50%). Индексация предпочитает совместимый
  GPU, CPU служит резервом. Сомнительные фрагменты исключаются с объяснением.
- Поддержан импорт RU/EN словарей, ударений, вариантов е/ё и произношений.
  Словарный и книжный слои сохраняются отдельно в одной библиотеке.
- Встроены проверка файлов компонентов, лицензии и общий многопоточный загрузчик.
- В результатах доступны пробный поиск, источники и причины исключений.

Нейросеть не переписывает первоисточники. Словарный поиск работает без загрузки
чат-модели. Лингвистическая правильность каждого утверждения исходного словаря
не гарантируется. Мастерская рифмы будет подключена отдельным этапом.
Пакет обновляет программу; пользовательские книги, готовые частные базы,
веса моделей, настройки и браузерные профили в него не входят.
