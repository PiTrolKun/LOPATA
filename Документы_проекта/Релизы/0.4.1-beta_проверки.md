## Подтверждённые проверки

- Restore/build и свежие Release publish приложения/обновлятора прошли.
  Собственный C# код не добавил предупреждений; прежний baseline тестов:
  CS4014 и три MSTEST0040. Native upstream CUDA overflow и MSVC /W не скрывались.
- MSTest: 1165 успешных, 0 ошибок; 2 native opt-in случая отдельно — 2/2.
  Виртуальная матрица: SM86/89/120, AMD/Intel Vulkan, старый драйвер, отсутствие
  GPU, занятая VRAM, недостаточная RAM, AVX2, однократный GPU→CPU и запрет
  fallback при отмене/ошибках файлов. Сохраняются runner/checkpoint проверки.
- Реальный GGUF: 33 независимых reference token vectors совпали.
  Исправлена старая поломка JSON whitespace-примера: вход восстановлен из
  неизменённых IDs/словаря; продуктовый токенизатор и ожидаемые IDs не менялись.
- Физические CPU AVX2 и CUDA через MusicYueWorker; Vulkan напрямую CLI.
  На RTX4090 каждый путь создал WAV 191788 байт, stereo PCM16 48000Hz,
  47936 frames. Журналы подтвердили LM/NAR/VAE backend; отмена убрала только
  собственный процесс и не опубликовала незавершённый план.
- Проверены native manifests, SHA-256 и подписи неизменённых Microsoft CRT.
  CUDA DLL содержит SM86/SM89/SM120a: 432 cubin, проверено cuobjdump.
  Vulkan/CPU сборки используют закреплённые yue2.cpp/GGML; 106 лицензий каталога.

- Safe-start: отвечающая ЛОПАТА 0.4.1-dev, build 0 errors / 0 warnings.
  RU/EN: 4066 одинаковых ключей, UTF-8/local links и scanner пройдены.

## Границы

Физически доступна только RTX4090. RTX30/RTX50/AMD/Intel и аппаратный OOM/отказ
старого драйвера не объявляются физически проверенными. Оценка памяти не
гарантирует последующего выделения. Изменение численных результатов между
backend допустимо при одинаковом seed. Качество песни этим не оценивается.

Полный установщик не пересобирался по правилам обычной правки. Доставка выполнена подписанным файловым обновлением; фактические GitHub
артефакты проверены. Старые выпуски не удаляются.

Evidence: `_tmp/music-hardware` и резерв `_backups/20261005_1023_music_hardware`:
native-build.log, cuda-elfs.txt, verified-tests, native-final-tests,
native-final-* с WAV/журналами, fresh publish и лицензионные оригиналы.
