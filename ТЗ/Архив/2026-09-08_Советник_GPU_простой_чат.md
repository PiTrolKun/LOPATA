# ИИ2 Советник: GPU и простой чат

Дата: 2026-09-08. Статус: выполнено и принято пользователем.

Подключить правый чат к отдельной копии установленной модели Альфы Qwen3.8-4B-Distill Q5_K_M на GPU. ИИ1 остаётся на CPU, без оптимизации его профиля. На этом этапе оба — простые независимые чаты: без наблюдения, обмена переписками, общей памяти, паспорта проекта и редактирования главы. Чаты временные, это явно указано в интерфейсе.

Один файл весов, два независимых процесса/порта/контекста/истории и отмены. Загружаются по первому сообщению, остаются загруженными между ответами; уход со страницы/очистка/ошибка/остановка освобождают соответствующий процесс. Остановка одного не должна затрагивать другой. GPU — существующий CUDA backend, без проектора и тихого перехода на CPU при недоступной видеокарте. Контекст 32768, слот 1, дополнительный кэш RAM выключен. Параметры генерации как у принятого ИИ1/Альфы; скорость сначала измерить, отдельную оптимизацию не выдумывать.

Общую механику чата и процесса вынести под нейтральные имена с явными профилями WriterCpu/AdvisorGpu; экземпляры состояния строго раздельные. RU/EN, поток ответа, отправка/остановка/очистка, исходные правила контекста. Существующий файл модели и backend, без загрузок/новых лицензионных экранов по предыдущему указанию пользователя.

Проверки: CPU профиль сохранён; GPU размещение подтверждено сервером; ответ ИИ2; два одновременно живых процесса; независимые ответы/контексты и отмена одного при работе другого; RAM/VRAM по доступным измерениям отдельно от фона. Целевой класс 32 ГБ RAM, 10–16 ГБ VRAM; короткий тест не доказывает максимум длинных сессий. WPF RU/EN и темы, build/test/scanner/start. Backup: _backups/literary_advisor_20260908. Установщик и публикации отложены. Приёмка пользователем отдельно.
