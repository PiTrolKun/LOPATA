# Стендовые переписки «Если накипело»

Создано 03.11.2026 по поручению пользователя. **Шесть вымышленных бесед, 638 сообщений: 319 реплик человека и 319 ответов собеседника.** Тексты написаны Codex; Gemma и другие локальные модели не запускались. Это имитация манеры разговора для испытаний памяти, не измеренный результат модели. Все персонажи, организации, события и суммы вымышлены и не относятся к пользователю.

## Посмотреть как чат

Открыть `index.html` обычным браузером. Файл самодостаточен: не нужен сервер, интернет, установка пакетов или запущенная модель. Слева шесть тем, по центру переписка, справа визуальная заглушка дерева. Есть поиск в выбранной теме, переход к началу/концу и узкая компоновка.

Это просмотр подготовленных историй, без отправки новых сообщений, автозаглавия, переименования и удаления. Заголовки и два избранных чата выставлены при подготовке. Страница не читает и не меняет настоящую библиотеку ЛОПАТЫ. Встроенный браузер инструмента запретил открытие `file:`; визуальная проверка не выполнена. Проверены синтаксис JavaScript и совпадение встроенных данных с исходным корпусом; обход ограничения не выполнялся.

## Данные для дальнейшего стенда

- `corpus.json` — основной структурированный корпус: темы, устойчивые ID, `role/content/complete`, признак синтетики и происхождение.
- `messages.jsonl` — 638 отдельных записей с `user_id`, `agent_id`, `session_id`, порядком и ID сообщения. Все беседы принадлежат одному вымышленному пользователю; у каждой свой сеанс. Это транспортный формат стенда, не готовый контракт импорта Hy-Memory.
- `conversations.db` — **отдельная** SQLite-база схемы 1 по образцу `LetItOutConversationStore`: JSON сообщений с полями `Role/Content/Complete`, ручные названия, 52–55 завершённых ответов. В `metadata` указано, что это синтетика Codex, а не ответы Gemma. Совпадение проверено чтением базы; импорт в работающее приложение не выполнялся.
- `dialogues/*.md` — шесть читаемых переписок с номерами и ID реплик.
- `source/*.txt` — авторские тексты, а не шаблонная генерация наполнителя. `U:` — человек, `A:` — собеседник.
- `recall-probes.json` — **36 отложенных контрольных вопросов с ожидаемыми ответами и ссылками на реплики**. Включает обновления сведений, ложные предпосылки, неизвестное, чужие слова, ошибки ассистента и межчатные связи. Этот файл держать вне загрузки в память и вне контекста отвечающей модели.
- `manifest.json` — размеры и SHA-256 выходных файлов корпуса; `validation.json` — результат структурной проверки.

Вопросы отдельной темы рассчитаны только на неё. Межчатные вопросы с `scope=all` требуют отдельного явно включённого испытания общей памяти вымышленного пользователя; это не решение о межчатной памяти настоящего сценария. Контрольные вопросы пока **не выполнялись**. Не оценивать ответы простым совпадением слов: нужны проверка смысла и опора на указанные сообщения. Краткий правильный ответ может отличаться от текста эталона.

Точные времена вымышленных сообщений не придумывались. `generated_utc`, даты создания/изменения в SQLite обозначают создание файлов стенда, а не даты событий рассказа. Порядок реплик задаётся номером. ТЗ сценария и версия программы указаны в происхождении; точная ревизия модели Codex инструментом не раскрыта.

**В Hy-Memory ничего ещё не загружено.** LLM и embeddings по-прежнему не подключены. Этот этап готовит материал, а не подтверждает запись, поиск, удаление или качество памяти. Пользовательская база в AppData, реальные переписки и исходники приложения не менялись; пересборки и публикации нет.

## Пересобрать или проверить

В PowerShell из этой папки:

```powershell
& '..\venv\Scripts\python.exe' '.\build_corpus.py'
& '..\venv\Scripts\python.exe' '.\prepare_probes.py'
& '..\venv\Scripts\python.exe' '.\validate_corpus.py'
```

Пересборка сохраняет предыдущие выходные файлы в `revisions`, затем перезаписывает только файлы этого стенда. Авторские `source` автоматически не редактируются. Проверка требует уже установленный Node.js только для разбора синтаксиса страницы; сам просмотр страницы его не требует. Ни одна из этих команд не вызывает Gemma или API модели.
