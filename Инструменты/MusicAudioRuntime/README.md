# Музыкальный аудиокомплект

Изолированная сборка x64 на CPU: FFmpeg 8.1, Opus 1.5.2, LAME 3.100; FLAC/WAV встроены в FFmpeg. Без GPL/nonfree-режима, сетевых протоколов, установки системных кодеков и изменений драйвера. DLL заменяемы.

Закреплённые оригинальные архивы и SHA256: `sources.json`. Проверка до распаковки и выполнения. LAME можно получить с официального SourceForge либо с зеркала BLFS https://ftp.osuosl.org/pub/blfs/conglomeration/lame/lame-3.100.tar.gz; байты должны совпасть с закреплённым SHA256. HTML вместо архива не принимается.

Нужен отдельный MSYS2 UCRT64: GCC, binutils, make, CMake, Ninja, pkg-config, nasm, patch. Путь передаётся явно; системный PATH не меняется. Точные версии использованного инструментария записаны в комплект исходников. FFmpeg использует собственную поправку `ffmetadata-escape.patch`: нечётная обратная косая черта продолжает строку, чётная завершает экранирование; это сохраняет значение тега, оканчивающееся `\`, согласно синтаксису FFmetadata.

```powershell
./build.ps1 -MsysRoot <изолированная-msys64> -BuildDirectory <новая-папка-сборки> -Jobs 6
./package.ps1 -BuildDirectory <папка-сборки> -OutputDirectory <новая-папка-комплекта>
```

Для пересборки из `corresponding-source.zip` распакуйте его в отдельную папку,
создайте `<папка-сборки>/sources` и скопируйте туда три архивных файла, указанных
в `sources.json`. Запустите извлечённый `build.ps1` с явными `MsysRoot` и
`BuildDirectory`: имеющиеся архивы проверяются по SHA256, повторная загрузка
не нужна. Для подготовки полной папки лицензий `package.ps1` используется из
репозитория ЛОПАТЫ; замена DLL возможна непосредственно из `prefix/bin` новой
сборки. Каталог лицензий и хеши manifest должны соответствовать заменённым файлам.

Ожидаемая поставка: `Runtime/MusicAudio/FFmpeg-8.1/bundle`. MSBuild переносит всю папку в `MusicAudioRuntime` приложения. `manifest.json` фиксирует SHA256 executable/DLL. `corresponding-source.zip` содержит оригинальные архивы трёх компонентов, собственную поправку, оба скрипта, настройки FFmpeg, перечень инструментов и этот документ. Лицензии/уведомления рядом в `licenses`; они и комплект исходников обязательны также для файлового обновления и установщика. Замена/rebuild LGPL-библиотек допускается; сведения каталога и новый manifest обновляются явно вместе с новым комплектом. Исходный аудиокомплект не смешивается с `CaptureRuntime`.

Протокол: нативный YuE2 сохраняет PCM16 stereo 48 kHz. Каждая выбранная кодировка начинается непосредственно с этого PCM. Opus использует VBR; значение битрейта — целевое среднее. MP3 — выбранный CBR. FLAC и WAV сохраняют исходные PCM-сэмплы. Кодирование — внешний процесс с отдельными аргументами, отменой и ограничением времени. Контейнер, продолжительность и полное декодирование проверяются до публикации файла. ID3v2.4 UTF-8 используется для MP3/WAV; Vorbis comments для Opus/FLAC. Текст песни, комментарий и собственные теги не передаются через shell.

Новый компонент `music.audio` включён в штатный каталог лицензий; ознакомление запрашивает общий `ComponentLicenseGate`, без отдельного самодельного файла согласия. Для разработческих автоматических проверок используются короткие синтетические PCM, без запуска весов модели.
