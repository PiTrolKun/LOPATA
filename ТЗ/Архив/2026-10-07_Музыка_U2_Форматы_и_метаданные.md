# Музыка U2 — форматы, один дополнительный файл и метаданные

Дата: 07.10.2026. Статус на 08.10.2026: выполнено и принято пользователем; архивировано без публикации.
База: 0.4.8-dev, опубликованная 0.4.8-beta. Итоговая рабочая версия: 0.4.10-dev.
Связь: [карта конвейера, U2 и §10](../Музыкальный_конвейер_карта.md).

## 1. Согласованный интерфейс

- Рядом с «Главные настройки», сверху, необязательное поле «Комментарий».
  Пустое поле почти сливается с фоном; подсказка еле заметна. При фокусе рамка,
  фон и текст становятся отчётливее; заполненный комментарий остаётся читаемым.
- Строка названия разделена поровну: «Исполнитель» — «Название».
  Эти слова — интерфейсные подсказки, никогда не значения тегов/имени файла.
  При заполнении обоих имя «Исполнитель — Название»; без ввода прежнее автоимя.
  Если заполнено только одно поле, лишний разделитель не добавляется.
- Рядом с вариантами и длительностью выбор формата и битрейта.
  Только Opus (.opus), MP3, FLAC, WAV. По уточнению 08.10.2026 по умолчанию Opus, 320 кбит/с.
  Разрешённые битрейты: 160 / 192 / 256 / 320; для FLAC/WAV поле скрыто.
- Мини-переключатель «+» разрешает ровно один дополнительный файл:
  под основным выбором появляется вторая строка формата/битрейта. Начальный
  дополнительный формат FLAC; основной исключён. Отключение скрывает строку.
- Форматы и битрейты запоминаются между запусками. Результаты одной генерации
  показываются одной карточкой, с обозначениями обоих форматов и доступом к файлам.
  Отдельная кнопка сведений ⓘ не добавляется.
- Компактное окно переносит элементы по строкам без перекрытия и обрезания.
  Круг и нижняя панель сохраняются. RU/EN и обе темы обязательны.

## 2. Сохранение аудио

Каждый выбранный формат создаётся из исходного аудио backend, без промежуточного
lossy-перекодирования. Дополнительный файл — то же исполнение, не новая генерация.
Громкость, микс и содержание не изменяются. Выход YuE2 сейчас PCM16 stereo 48 kHz.
Старые WAV и задания остаются совместимыми и не конвертируются задним числом.
Нативный мастер хранится до подтверждения всех выбранных файлов; после успешной
компактной записи ненужный временный WAV можно убрать. План и данные повторения
сохраняются. Ошибка/отмена не удаляет единственный исправный исходник.

Готовность публикуется только после кодирования, проверки декодирования, длительности,
каналов, встроенных тегов и фиксации хешей. Восстановление не перезаписывает чужой
файл, не повторяет готовую генерацию и продолжает незавершённую конвертацию.
Поддержка плеера не должна требовать стороннего системного codec pack.

## 3. Метаданные внутри каждого файла

Снимок конкретного задания: название, исполнитель, комментарий, исходные lyrics
с секциями, фактический Style, выбранные жанры/пожелания; дата/время, номер варианта,
ID задания; версия ЛОПАТЫ, модель/вариация/precision, runtime/backend и версии;
два фактических seed; фактические экспертные параметры, рецепт, круг/закрепления;
использованное устройство и время работы. Неизвестные сведения не придумываются.
Новые движения круга и ввод не меняют старые файлы.

Обычные поля — стандартные музыкальные теги, дополнительные — однозначные
LOPATA_*; компактные текстовые технические поля допустимы. Не вкладывать полный
ABC, semantic tokens, runtime logs, tensors, внутренний request JSON.
Текст песни — вход модели, не гарантированная расшифровка исполнения.
Комментарий не входит в имя файла и не меняет Style/Lyrics.
Opus/FLAC: UTF-8 comments; MP3: ID3; WAV: поддерживаемые встроенные теги и ID3.
Разные сторонние программы могут показывать лишь часть полей.

## 4. Техническая реализация и поставка

Отдельные компоненты настроек хранения, тегов и кодирования; старый исполнитель
и сборщик пожеланий не изменяют музыкальное поведение. Использовать минимальный
проверенный аудиокодировщик, с закреплёнными исходниками, SHA-256 и лицензиями.
Сверить существующий FFmpeg; если его возможностей недостаточно, подготовить
отдельный аудиокомплект без изменения видеозахвата. Согласие через штатный gate.
Только CPU-кодирование, доступное на совместимых Windows x64 независимо от GPU.
Пауза/отмена/восстановление сохраняют общий жизненный цикл фоновой операции.

## 5. Проверки и граница приёмки

Проверить все четыре формата, четыре битрейта lossy, кириллицу/многострочные lyrics,
оба seed, фактические параметры, сохранность заметки, отдельный lossless-дубль,
имена/коллизии, повтор и старые job, отмену/ошибку/восстановление, плеер/перемотку,
RU/EN, обе темы и узкое окно. Потоки сохранения проверять на синтетическом аудио;
длительная генерация модели и сравнительные тесты звучания не нужны для этого ТЗ.
Обновить справку «?», пользовательскую документацию, реестр, облако механик,
историю и rollback. Scanner/build/tests/safe-start обязательны.
Установщик автоматически не пересобирать. Архивирование и публикация — после
приёмки пользователя по правилам проекта; текущая команда разрешает реализацию.

## 6. Результат реализации и проверок, 08.10.2026

Реализовано в 0.4.9-dev. Все четыре формата и битрейты проверены на коротком
синтетическом PCM. Подтверждены теги UTF-8, ударение, смешанные переводы строк,
точное сохранение PCM для FLAC/WAV, воспроизведение/перемотка Opus, совместимость
старых WAV-заданий и продолжение после ошибки дубля/отмены кодирования без
повторного запуска модели. RU/EN, обе темы и узкая панель проверены WPF-тестами.
Общие тесты: 1301 успешно, 75 специальных пропущены, 0 отказов; обновлятор 63/63.
Новых предупреждений нет: в тестовом проекте остаются четыре прежних.
UTF-8 scanner проверил 47 текущих изменённых/новых текстовых файлов без ошибок.
Штатный safe-start прошёл; сборка приложения без ошибок/предупреждений.

[Подробный протокол](../../Документы_проекта/Исследования/2026-10-08_Музыка_U2_проверки.md).
Длительный музыкальный inference, качество звучания и физическая пауза GPU
не проверялись: исполнитель и музыкальные пожелания в этом ТЗ не менялись.
Commit/push, архивирование ТЗ и публикация не выполнялись. Установщик не
пересобирался по правилу проекта. ТЗ остаётся активным для пользовательской приёмки.

## 7. Частичная приёмка и проверка реальных тегов, 08.10.2026

Визуальная часть принята пользователем. По запросу о невидимых данных проверены
четыре существующих пользовательских Opus: Lyrics (654 символа), Style, seeds,
параметры и обычные поля совпадают с заданием и фактическими запросами модели.
Потери тегов не обнаружено. Обработчик Windows на этом ПК не выводит Lyrics
и произвольные LOPATA_* в стандартные свойства. SubTitle — другое поле.
[Результат диагностики](../../Документы_проекта/Исследования/2026-10-08_Музыка_U2_проверки.md).
Проверка хранения метаданных не подтверждает качество пения или синхронизацию
слов с аудио. Изменений приложения нет; ТЗ не архивировано и не опубликовано.

## 8. Уточнения при приёмке, 08.10.2026 — 0.4.10-dev

Пользователь подтвердил корректность хранения тегов. Кнопка дубля должна
переключаться «+» → «−»: минус отключает создание второго файла, скрывает
дополнительную строку и сохраняет выбор. Знак и подсказка меняются и при
восстановлении сохранённых настроек. Реализовано, RU/EN обновлены.
По отдельному уточнению основной битрейт по умолчанию — 320 вместо 160;
такой же исходный выбор для сжатого дубля. Ранее выбранное пользователем
качество не затирается. Диапазон 160/192/256/320 остаётся доступным.
8 профильных тестов прошли; приложение собрано/открыто штатно, новых
предупреждений нет. Установщик не пересобирался; публикация/архивирование
не выполнялись. ТЗ остаётся активным до приёмки этих уточнений.
