# Дикторы видеоредактора — 0.6.27-dev

Реализация и быстрые пробы выполнены. Пользовательская приёмка открыта.

## Причина ошибки и исправление

На снимках пользователя Kitten/Supertonic останавливались на import soundfile,
до загрузки модели. В общий pin попал универсальный SoundFile без libsndfile.
Используется официальный Windows wheel 0.13.1 с libsndfile 1.2.2 и оригинальным
COPYING; размер и SHA256 закреплены. Скачанные веса не переустанавливались ради этой ошибки.
Новая ревизия окружений — voices-20261026-2. Старые файлы сохранены.

Доделаны Vosk/Silero/Orpheus/CosyVoice: штатные upstream API, закреплённые
модельные файлы и отдельные зависимости, общий загрузчик/лицензии/ComponentAudit.
Vosk получил requests и безопасное раскрытие официального ZIP. CosyVoice —
замкнутый набор зависимостей, пустые Python-файлы из tar сохраняются; из GitHub
ZIP проецируются inference-пакеты/лицензии, учебные symlink не извлекаются.
Ссылки внутри выбранных пакетов и выход за каталог по-прежнему запрещены.
При исполнении запрещена сеть, известные модельные файлы передаются локально.
Полный ограниченный worker.log сохраняется, ошибка в окне прокручивается.
Старый Kokoro тоже получил маркированную копию пробы с происхождением видеоредактора.

## Границы и оставшаяся приёмка

Orpheus — публичная сторонняя Q4_K_M + SNAC через рекомендованный авторами
OrpheusCpp/Windows CPU, не gated Safetensors. CosyVoice — исходный 300M-SFT,
семь голосов, без русского; ttsfrd/zero-shot/training/Triton не подключались.
Состав зависимостей адаптирован к общему Torch 2.10/Python 3.12, не выдаётся за
дословный upstream training environment Torch 2.3.1. Подробные лицензии/pins — REESTR.
Все встроенные голоса, языки, длительные тексты и аппаратная матрица не проверены.
Основное окно программы не запускалось; реальное окно диктора проверено отдельно.
ТЗ не архивированы; точное forced alignment и анализ всей сведённой композиции
не добавлялись этим исправлением. Commit/push/публикации нет, установщик не пересобран.

## Политика аудита и сохранность

Исходные архивы скачиваются только общим ManagedModelAcquisitionService,
с докачкой и MaximumParallelConnections. Распаковка не вызывает pip/setup.py.
Полный аудит реконструирует ожидаемые файлы из закреплённых wheel/tar;
быстрый режим после первого успешного прохода проверяет только наличие.
Явная повторная подготовка сохраняет прежний Expanded в previous-каталог
и инвалидирует общую квитанцию. Первая проверка новой установки остаётся полной.
Скрипт запускается owned-процессом, отмена завершает только его дерево.
Python -I/-B и офлайн-флаги не меняют системные библиотеки; Kitten также получает
штатный offline=True. Целостность исходников, лицензии и provenance не отключаются.

Проба не получает экземпляр VideoProject и не добавляет материал на ленту.
Применение профиля проходит через VideoEditing/Undo; готовые WAV сохраняются.
У материала хранится NarratorProfile фактического синтеза. При новом синтезе
прежний TTS не приписывается новому звуку, исходные модели автора текста сохраняются.
Видеооперация speech остаётся в общем video.editor с прежними checkpoint/паузой.
