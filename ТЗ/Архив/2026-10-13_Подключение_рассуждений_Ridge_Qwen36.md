# Подключение управления рассуждениями Ridge 27B и Qwen3.6 27B

13.10.2026. Рабочее ТЗ; реализация по предложению пользователя после исследования. Исследование подтвердило механизмы, но не превосходство большого бюджета. Предыдущие рабочие ТЗ и результаты не архивировать автоматически.

## Контракт

Для gamma (Qwen3.8-27B Ridge) и executor (Qwen3.6-27B) добавить к существующей кнопке меню: вкл/выкл, бюджет 2048/4096, возврат прошлых мыслей. Для Ridge дополнительно medium/xhigh. Новые настройки: on, 2048, medium у Ridge, возврат мыслей true; default применяется только при отсутствии сохранённого поля. Сложность не угадывать программно: effort выбирает человек. Выключение мышления отключает применение остальных опций, но сохраняет их выбор; повторное включение не меняет сохранённый preserve=false/budget/effort. Четыре ранее подключённые модели сохраняют свой фиксированный on/off2048 без новых опций.

Предпочтения независимы по устойчивым ID моделей, атомарно сохраняются, восстанавливаются новым окном/сеансом. Старые ModeId-only preferences совместимы; неизвестные поля сохраняются. Недоступный сохранённый budget/effort/mode блокирует отправку до явного исправления, без замены defaults. Ошибка записи не меняет live-выбор. Во время операции меню и его запоздалые callbacks не меняют параметры; запрос, сборка и repair используют один snapshot.

В native передаются enable_thinking, reasoning-budget и deepseek; preserve_thinking явно задан для подключаемых моделей, effort только Ridge. Выключенные мысли: budget0, preserve не применяется. Sampler/schema/аппаратный выбор не изменять. Generation и native count используют общий сериализатор сообщений/kwargs. Резерв конечного ответа прежний, поверх него выбранный бюджет; не снижать его скрыто при недостатке контекста. Предпросмотр учитывает реальные возвращаемые мысли; существующее исключение старых целых turn при переполнении остаётся видимым в истории.

Возвращать только мысли завершённой успешно принятой попытки, связанные с её TurnId/Attempt и ID этой модели. Передавать отдельным reasoning_content вместе с аутентичным окончательным Raw этой попытки, не с искусственным пересказом. Отклонённые, active, interrupted и мысли другой модели исключать; старые блоки без известного ID безопасно не возвращать. Поддержать принятый ответ с пустым chat (например, только правка параметров). Мысли не превращать в song/parameters/chat, не переписывать сохранённые сообщения. Входная проекция служит только контексту и сериализации. После смены модели её собственные прежние мысли могут снова использоваться.

Существующие поток, зелёный цвет, сворачивание, ручное раскрытие, язык интерфейса/песни и ПКМ-размер сохранить. Дополнить покрытие существующего тега каталога и RU/EN подсказки; новых отдельных панелей/операций не создавать. Lifecycle и GPU→гибрид→CPU прежние, чужие процессы не завершать.
