## Фоновый ИИ-инспектор ПК

- `LOPATA Controller PC` наблюдает за нагрузкой, предупреждает о возможной нехватке ресурсов и продолжает работать после полного закрытия ЛОПАТЫ. Инспектор включён по умолчанию и запускается при входе в Windows.
- ЛОПАТА beta и dev с общим профилем используют один процесс и одну задачу автозапуска. При полном аудите инспектор включается автоматически.
- Из трея можно запросить локальный отчёт через Ядро. Для поиска необычных изменений в измерениях отчёт использует IBM Granite TSPulse.
- В Острове доступна отдельная страница советов за последние 24 часа. Оценка добровольна, а история похожих задач со временем помогает уточнять советы.
