## Включение и лицензии

calibre: полный исходный Windows-комплект, без вырезания зависимостей, переносится
AIHub.csproj в `BookConverterRuntime`. Проверено 1356 оригинальных файлов,
695592869 байт. Соответствующий исходный архив, LICENSE и COPYRIGHT сохранены.
`books.calibre` использует штатный ComponentLicenseGate; подтверждение обязательно
и для уже поставленного комплекта. Лицензия calibre — GPL-3.0; вложенные компоненты
сохраняют собственные условия. Отдельный полный аудит всех транзитивных бинарных
зависимостей не завершён.

LibreOffice не дублируется в сборку. При необходимости пользователь явно запускает
подготовку; уже установленный LibreOffice обнаруживается. `msiexec /a /qn` создаёт
административный образ в управляемой папке, без установки продукта в систему.
Используется существующее подтверждение `runtime.libreoffice`; в каталог лицензий
добавлены оригинальные `license.txt` и `NOTICE` этой поставки. Набор включает MPL,
Apache и другие условия, перечисленные в оригинальном тексте. Скрипт подготовки
общего каталога воспроизводит эти записи; версия Terms учитывает приложенные тексты.

Системные политики могут запрещать административную распаковку. Повышение прав
автоматически не запрашивается; ошибка отражается в результате и журнале.
Тихий ПКМ не скачивает и не показывает лицензий. CLI использует `soffice.com`,
а преобразование — отдельный профиль.

## Независимые валидаторы — только стенд

EPUBCheck 5.4.0, Temurin JRE 21.0.12.1+1 и lxml 6.0.2 находятся в `validators`.
Точные официальные URL и SHA сохранены в `validators/provenance.json`.
Java и Python-пакеты глобально не устанавливались; в зависимости приложения
эти средства не добавлены. Их оригинальные лицензии оставлены в архивах/каталогах.

Результаты конкретных проверок находятся в `epubcheck-*.json`,
`fb2-independent-*.json`, `runtime-extraction-result.json`,
`calibre-smoke-result.json`, `libreoffice-smoke-result.json`.
Нулевой код конвертера сам по себе не гарантирует корректность схемы.

## 20.10.2026 — переход к встроенной поставке, 0.5.85-dev

Описание отдельной подготовки LibreOffice выше — история 0.5.80. По новому
требованию оба книжных компонента входят в приложение. URL/версии/исходные SHA
прежние; новый prepare-office.py проверил оригинальный MSI из downloads и
прежние 19528 файлов provenance. Преобразованный административный MSI исключён
из поставки. Полный образ и десять app-local копий оригинальных DLL System64
входят в BookOfficeRuntime: 19537 записей, 1575595694 байта, плюс provenance.json.

Манифест Tools/book-office-files.json встроен в AIHub. Первая офисная операция
процесса проверяет размер/SHA/безопасность путей; стартовую проверку оборудования
не расширяли. UI/runtime больше не скачивают calibre/LibreOffice. Старые managed/
системные установки остаются резервом совместимости. Основной источник — папка
программы. Профили преобразования отдельные; собственный офис пользователя не закрывается.

В каталоге лицензий изменена только runtime.libreoffice: bundled, дата, добавлен
texts/books-libreoffice-sources.txt и пересчитан Terms из точных текстов.
Оригинальные license.txt/NOTICE и кредитные сведения сохранены; источник кода
указан в новом уведомлении. Общие подтверждения не отключены и не подделываются.
Для изолированного стенда используются отдельные тестовые receipts; рабочие
подтверждения пользователя не меняются. Полный аудит транзитивных лицензий
upstream-комплекта отдельно не объявляется завершённым.
