# Удаление литературного проекта — 0.1.87-dev

До этого этапа LiteraryProjectStore и UI вообще не предоставляли удаления. Теперь × в списках выбора проекта/активного проекта открывает вопрос с названием и полным путём. Можно убрать запись, сохранив файлы, удалить всю папку или отменить.

Удаление файлов выполняется в фоне; диалог не закрывается до завершения. После успеха список обновляется, звезда удалённого проекта сбрасывается. Экспортный список не содержит операции удаления. Из редактора сначала нужно выйти штатным путём с проверкой несохранённых изменений.

Очистка ограничена зарегистрированным проектом с совпадающим ID project.json. Запрещены корень диска, папка с общим индексом, вложенные зарегистрированные проекты и ссылки/junction в дереве или его предках. Копии материалов внутри проекта удаляются; оригиналы вне проекта остаются. Общие модели и Qdrant не затрагиваются: проектных коллекций пока нет.

Проверка файлов на занятость/readonly выполняется до удаления. Индекс изменяется последним. При ошибке запись остаётся, UI прямо предупреждает о возможном частичном удалении. Это не файловая транзакция: аппаратный сбой, изменение папки другим приложением во время очистки или ошибка записи индекса могут оставить частичный результат. Отсутствующую папку можно удалить из списка повторной операцией; повреждённый паспорт позволяет только сохранить файлы и убрать запись.
