# Закрытие «Если накипело» — 0.7.21-beta

04.11.2026 пользователь подтвердил выполнение единого ТЗ. Документ находится в общем архиве. Приёмка получена на 0.7.20-dev; 0.7.21-dev добавляет исправление повторно выявленного указателя модального окна. Публикация готовится в отдельной чистой копии на актуальной origin/main, исходная рабочая папка не сбрасывается.

Профильная регрессия в чистой копии: **542 теста, 518 PASS / 24 opt-in SKIP / 0 FAIL**. Отдельно механизм обновления: **78 PASS / 0 FAIL**. Сборка тестов: 0 ошибок и 6 прежних предупреждений в неизменённых зависимостях/тестах. RU/EN: 8610 совпадающих ключей. Scoped UTF-8/Cyrillic scanner: 185 текстовых файлов, PASS. Staged diff-check PASS; проверка 227 публикуемых файлов не нашла кандидатов закрытых ключей/токенов.

Первый общий прогон дал два сбоя. Проверка медиапаузы прошла отдельно без изменения кода, затем прошла в полном финальном прогоне; начальный сбой сохранён как плавающий результат. Проверка курсора повторилась и в исходной рабочей папке: одного Mouse.UpdateCursor было недостаточно на переходе от WebView2 к модальному окну. После установки текущей формы через Mouse.SetCursor тест с реальным окном, отказом/принятием и сменой темы прошёл отдельно и в общем прогоне. Глобального OverrideCursor нет. Защитные проверки и анализаторы не отключались.

Предыдущие физические испытания Gemma, памяти, мультимодальных вложений и речи остаются в отчётах этапов. При закрытии все модели заново не прогонялись. Финальный межчатный стенд: 6 вымышленных тем / 638 сообщений, пять запросов к настоящей Gemma успешно проверяют имя, сходную проблему, исправленную дату, поиск без явной просьбы и арифметику без источников. Источники не гарантируют правильную интерпретацию; в пользовательской проверке понадобился намёк на поиск.

В Git включены исходники, выбранные отчёты и вымышленный корпус. Генерированные копии для scanner/encoding, сырые логи, БД, личные чаты/вложения/настройки, веса и ключи исключены. В десяти публичных копиях Markdown-отчётов сняты только хвостовые пробелы; оригинальные стенды сохранены локально. У нового архивного ТЗ проверены относительные ссылки. Прежние ссылки в большой исторической документации могут вести к локальным непубликуемым материалам и не объявляются публичными доказательствами.

Проверенная база обновления: подписанный манифест 0.7.1-beta локально совпадает с SHA-256 GitHub. Для переходного комплекта подготовлены 1167 прежних файлов Engine Set 001. Подтверждение состава/подписей/серверных хешей выпуска добавляется после фактической публикации. Полный и сетевой установщики не собираются, установка пользователя автоматически не меняется.
