# ЛОПАТА 0.7.78-beta

Исправлено открытие документов в читалке. DOCX и TXT теперь отображает тот же встроенный движок, что и редактор. Отдельный офисный пакет для них не нужен.

Для старых форматов, таблиц и презентаций ЛОПАТА использует свой комплект преобразования. Прежний загрузчик LibreOfficeKit с Python больше не участвует в открытии документов читалки.

Оглавление, переходы внутри документа, комментарии, поиск, выделение, масштаб и разворот сохранены. Исходные файлы открываются только для чтения.

Подписанное файловое обновление доступно в разделе «Настройки → Обновления». Полный установщик для этого выпуска не пересобирался.
