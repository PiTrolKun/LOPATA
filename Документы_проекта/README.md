## Что остаётся ограничением

В рабочей версии 0.2.5-dev реализован [быстрый импорт литературного проекта из DeepSeek](../ТЗ/Архив/2026-09-20_Быстрый_импорт_литературного_проекта_DeepSeek.md): ZIP/JSON, выбор бесед и произведения, два прохода локального Qwen, новый проект, DOCX и XLSX с точными артефактами. Границы проверки описаны в [отчёте](../ТЗ/Архив/ОТЧЕТ_2026-09-21_реализация_быстрого_импорта.md). Сомнительный текст выделен и исключён из достоверной памяти до проверки. [Карта](../ТЗ/Архив/КАРТА_ИДЕИ_2026-09-20_импорт_литературного_проекта_из_облачных_чатов.md) и [официальные технические основания](../ТЗ/Архив/СПРАВКА_2026-09-20_технологии_облачного_импорта.md) остаются актуальными. Пользователь принял работоспособность импорта и продолжение литературной работы; количественная оценка качества всей книги не выполнена. Импорт входит в публичную 0.2.5-beta.

«Песочница» — экспериментальный сценарий. Качество модельных ответов, полнота извлечения фактов и точность выбора контекста не гарантированы. Проверенные механизмы доставки и валидации не подменяют человеческую проверку смысла. Замеры на одном ПК не доказывают скорость на другом. Исследовательские модели и идеи не равны штатным компонентам.
