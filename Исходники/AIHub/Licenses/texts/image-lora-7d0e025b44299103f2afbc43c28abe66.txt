# Z-Image-Turbo-Realism-LoRA

<Gallery />

This is a LoRA fine-tuned adapter for the [Z-Image-Turbo](https://huggingface.co/Tongyi-MAI/Z-Image-Turbo) model, trained on the [hand-selected subset of the well known C12M dataset](https://huggingface.co/datasets/opendiffusionai/cc12m-4mp-realistic). It specializes in generating high-quality ultra-realistic images.

## Features

* Generates **ultra-realistic scenes** in a consistent style.
* LoRA adapter — lightweight and easy to use with the base Z-Image-Turbo model.
* Compatible with Hugging Face `diffusers` pipelines.

## Trigger words

You should use `Realism` to trigger the image generation.
