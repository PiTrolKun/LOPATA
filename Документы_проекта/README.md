## 07.10.2026 — аппаратные библиотеки и сценарии

Внедрены отдельные CPU/Vulkan исполнители для ядра, литературы, финансового
GGUF, анализа и генерации изображений. Giga Embeddings, «Желе» и SwinIR используют
управляемые Python/PyTorch CPU/CUDA/XPU/Windows ROCm профили. Недостающие
библиотеки под оборудование предлагает штатный загрузчик первого запуска;
установленные модели не скачиваются повторно. Драйверы не устанавливаются.
Аппаратные пробы и свободная память проверяются перед работой, повреждённые
комплекты отклоняются. Подтверждённый аппаратный отказ GPU допускает один
безопасный повтор на CPU; частичный видимый ответ не считается готовым.

Физически проверены CPU и NVIDIA RTX 4090. Intel/AMD профили подготовлены, но
выполнение на физических Intel/AMD GPU пока не испытано. Kimi остаётся CPU/RAM
профилем. Полная матрица, версии, лицензии и границы испытаний:
[аппаратная поддержка](АППАРАТНАЯ_ПОДДЕРЖКА.md).

Датированные CUDA-only описания ниже сохранены как история; для действующих
основных сценариев аппаратную информацию брать из указанной матрицы.
