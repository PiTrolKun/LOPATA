# «Если накипело»: интеграция общей диктовки, 03.11.2026

Версия: 0.7.14-dev. Причина: редактор был перенесён в WebView2, а внутренний
выбор цели диктовки поддерживал только WPF TextBox/RichTextBox. Дополнительно
WPF InputHitTest не возвращал редактор, расположенный в дочернем native-окне.

Добавлена явная регистрация встроенного поля, общий учёт при автоматическом выборе
и ограниченная геометрическая проверка для прицела. Асинхронный адаптер передаёт
гипотезы прежнего распознавателя в plain-text редактор. Посторонние WebView не
становятся поддерживаемыми автоматически, история остаётся только для чтения.

Нативный тест на установленном WebView2 (`native-final.log`, TRX в `native-final`)
пройден. Изолированный чат, без настоящего микрофона и без запросов к Gemma:

- замена выделения, несколько уточнений одной гипотезы, финальная блокировка;
- дописывание с пробелом, браузерный Undo, сохранность ручных правок;
- многострочный текст и синхронизация с настоящим буфером черновика;
- автовыбор, координаты прицела внутри/вне поля, исключение скрытого буфера/истории;
- отказ старой цели после замены черновика и новой темы; недоступность скрытого поля;
- ни одно сообщение не отправлено в модель.

Первый тест выявил отсутствие Application.Current в изолированном WPF fixture;
общий алгоритм выбора выделен в тестируемую перегрузку. Второй выявил реальную
особенность hit-test WebView2, исправленную ограниченным выбором по координатам.
Неуспешные попытки сохранены в native/native2. Сборочная неоднозначность Point
устранена явным System.Windows.Point. Конечная сборка: 0 ошибок, 6 прежних предупреждений.
`restore.log`, `build.log` сохранены. Итоги регрессии/запуска/кодировки дописаны ниже.

Проверка реального микрофона, акустики и качества распознавания в этот прогон
не входила: они не изменялись. Установщик и публикация не выполнялись.
