Принятый набор содержит 1531 реплику на каждом языке, 5249 связей событий и 6398 шаблонов.
Для конвертера добавлены «Начинаю перекодирование видео.» и «Перекодирование видео завершено.» с английскими версиями. Группа приоритета 2. [Описание дополнения](../../Дополнения/2026-11-26_Конвертер_видео.md)
