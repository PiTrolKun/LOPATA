# 0.6.57-dev — получение первого H3-набора

По прямой команде пользователя начат первый набор MiniMax H3 Ref2VA + ComfyUI + obvpm-timeline. На финальном шаге «Далее» открывает штатное окно видеоредактора: автоматическая локальная проверка, отдельное ручное «Скачать / продолжить», общие SegmentedModelFileDownloader и ComponentAudit. Режим аудита фиксируется на операцию, получение/замена всегда проверяет SHA256, а первая проверка после установки остаётся полной. Ожидаемое отсутствие ещё не скачанных файлов не вызывает диагностику неизвестного сбоя.

Закреплены 12 компонентов / 21 файл, 57 474 016 461 байт. Основной Ref2VA pruned INT8 ConvRot, отдельный Qwen3-VL 32B INT8-энкодер, video/audio VAE, VAE для upscale, latent upscaler и Kijai TAEH3. ComfyUI/ноды получаются исходными архивами или файлами; архивы не исполняются, Python-среда пока не устанавливается. Сохранён оригинальный workflow 007A; будущий адаптер должен выбрать INT8-энкодер вместо NVFP4 из примера. Turbo/Spectrum не включаются автоматически. Сам H3 и генерация/продолжение видео ещё не испытаны.

67 профильных проверок PASS, 2 opt-in проверки установленных аудиокомпонентов SKIP. Проверены манифест/лицензии, отсутствие сети при локальной проверке, отказ от условий, многопоточная докачка, отмена без удаления пользовательского файла/частей, первый/повторный аудит ON/OFF, смена ревизии/замена/утрата файла, RU-dark/EN-light окно и повторная настройка перехода без дублирования. Restore и сборка тестового проекта прошли; предупреждения только прежние NU1902/NU1903, CS4014/MSTEST0040 из других тестов. Scoped UTF-8/Cyrillic scanner — PASS; штатный safe-start открыл ЛОПАТУ 0.6.57-dev (PID 3352), сборка приложения: 0 ошибок / 0 предупреждений.
