# Происхождение файлов ЛОПАТЫ

Первый проход внедрён в 0.5.75-dev по принятому ТЗ
[17.10.2026](../ТЗ/Архив/2026-10-17_Происхождение_выходных_файлов.md).
Это сведения о создании/обработке, а не заявление об авторском праве,
криптографическая подпись или защита от удаления сторонней программой.

| Результат | Встроенные сведения |
|---|---|
| Скриншот PNG | iTXt Software и LOPATA |
| Скриншот JPEG/WebP | XMP CreatorTool и lopata:Provenance |
| GIF | GIF89a Comment Extension |
| Видео MP4/MKV/WebM | comment с JSON, creation_time; поддерживаемые контейнером служебные теги |
| Литературный DOCX, XLSX истории импорта | Application=LOPATA, LastModifiedBy, свойство LOPATA.Provenance |
| Описание изображения DOCX | Те же свойства Office |
| Пакетное описание MD | Преамбула lopata_provenance с JSON |
| Экспорт озвучки описания WAV | RIFF id3 с Software и LOPATA_PROVENANCE |

JSON схемы 1 содержит Program, ProgramVersion, Scenario, ExportedUtc,
известное CreatedUtc, Models (Id, Name, Revision, Role), ModelScope и ModelHistory.
Неизвестная дата исходной записи при восстановлении старого GIF/видео не
заменяется вымышленной датой: CreatedUtc остаётся null, время экспорта известно.
Автор книги сохраняется отдельно; приложение не объявляет себя автором.

## Сведения о моделях

Литературный проект хранит `model-participation.json`. Новые проекты начинают
журнал при создании; у существующих явно неизвестна история до этого обновления.
Записываются принятые сервером запросы к литературной модели, фактическое
извлечение памяти специалистами и выполненные индексирование/поиск Giga.
При импорте используются settings и связанная с тем же запросом квитанция HTTP
2xx; одна выбранная модель или подготовленные настройки не доказывают участие.
В DOCX перечисляется участие в проекте в целом, а не авторство каждой строки.
XLSX объединяет сведения сеанса импорта и результирующего проекта.

Версии описаний изображений хранят снимок идентификатора и ревизии модели.
Пакетный обработчик сохраняет сведения фактического исполнителя до фиксации
результата и переносит их при продолжении. Старые сеансы без полного журнала
помечаются как неполные; текущий выбор модели не переписывает прошлое.
У экспортируемой озвучки сохраняется снимок связанного описания и исполнитель
синтеза; неизвестная ревизия синтезатора явно не выдумывается.

## Границы

Сведения пишутся до замены конечного файла. Ошибка записи отменяет этот экспорт;
прежний результат остаётся целым. Изображения не пережимаются ради метаданных,
звуковые сэмплы и текст произведения не меняются. Структурированная запись
ограничена 48 КБ, журнал проекта — 128 различными записями; превышение сообщает
об ошибке, не обрезает историю молча. Приватные пути, запросы и ключи не входят
в публичные сведения происхождения. XLSX истории импорта по прежнему содержит
собственно частную историю импорта и требует прежнего осторожного обращения.

Песочница исключена по решению пользователя. Её существующий вызов общего
DOCX-экспортёра не получает новых свойств. Музыка и генерация изображений имеют
ранее реализованные собственные сведения; финансовый экспорт и остальные
старые пути этим проходом не дорабатывались. Точные копии исходных файлов,
скачанные оригиналы и извлечение вложений сохраняют исходные байты.

Проверки: синтетические реальные файлы, ExifTool как независимый читатель,
FFmpeg для декодирования видео, ZIP/XML и OpenXML Validator для Office,
сравнение сжатых пиксельных данных и звуковых сэмплов. Тестовые модели и
синтетические ответы не заменяют физическую проверку генерации каждой моделью.
