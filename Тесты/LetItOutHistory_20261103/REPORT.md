# История «Если накипело» — 0.7.8-dev

Слева добавлены новая тема, избранные и последние темы. История и черновики
хранятся локально между запусками. ПКМ: закрепить/открепить, переименовать,
удалить выбранную тему с подтверждением. В узком окне история открывается через ☰;
дерево скрывается первым. Справа пока только визуальный эскиз без анализа беседы.

После второго полного ответа та же Gemma выполняет один короткий запрос названия
в рамках уже занятой общей операции. Никаких отдельных параллельных запусков.
Служебные инструкции и название не добавляются ни в видимые сообщения, ни в
дальнейшую историю запроса. Это не означает физического уничтожения загруженных
весов/KV во всей памяти: последующий обычный запрос содержит только полезную беседу.
Ручное имя блокирует подбор до старта и имеет приоритет при гонке с результатом.
Частичные ответы не засчитываются. Ошибка/остановка названия сохраняет второй ответ
и не запускает бесконечные повторы. Выход/пауза этого шага не скрывают готовый ответ.

## Данные

`%LOCALAPPDATA%/AI_HUB/LetItOut/conversations.db`, SQLite schema 1. Таблицы:
conversation, metadata и deleted_conversation. Метаданные тела, имени и избранного
изменяются отдельно. Удаление оставляет только ID/время для запрета восстановления
старым заданием, без сохранения удалённого текста/названия в этом маркере. Оно
снимает неработающие задания восстановления этой темы; живое задание сначала
останавливается. История другой темы не включается в запрос собеседника.

Ввод сохраняется через 350 мс; важные переходы, отправка, окончание ответа и
штатный выход подтверждают запись сразу. Откат версии не должен удалять эту базу.
В поставку/публикацию исходников пользовательские данные не входят. Используется
прежняя Microsoft.Data.Sqlite; библиотек и моделей дополнительно не скачивали.
