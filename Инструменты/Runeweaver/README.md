# Runeweaver — отдельный терминальный стенд

Обычный запуск из PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File H:\AI_HUB\Инструменты\Runeweaver\start.ps1
```

Сначала скачивается недостающая модель (8 соединений), проверяется SHA256, затем открывается чат. Только скачать: добавить `-DownloadOnly`.

В чате можно вставлять многострочный текст. Завершение ввода — `/` на отдельной строке. Управление остановкой — Ctrl+C и подсказки llama-cli. Начальная длина одного ответа ограничена 2048 токенами; это настройка стенда, не предел возможностей модели.

Файлы: `Тесты/Runeweaver/model`; логи backend и снимок настроек: `Тесты/Runeweaver/logs`. Части загрузки хранятся рядом с моделью, докачка продолжится после повторного запуска. Во время сборки файла нужно около 15 ГБ дискового места. Веса загружаются только после успешной проверки. Не запускайте второй экземпляр загрузчика одновременно: он завершится с ошибкой блокировки.

Если проверка SHA256 не пройдёт, файлы сохраняются для диагностики; сообщите об ошибке. Скрипт не исправляет повреждённые части наугад. Никаких изменений моделей приложения, установки пакетов, серверов в автозапуске или публикации.

Python 3.12 и установленный llama.cpp используются как внешние инструменты. Конфигурация — `config.json`. Реальный запуск модели и замеры ресурсов выполняются после окончания скачивания. Двухслотовый сервер — следующий этап ТЗ, в этом скрипте пока обычный llama-cli.
