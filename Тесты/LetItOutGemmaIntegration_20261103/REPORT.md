## Автоматическое размещение

1. Измеряются общий объём и текущая свободная VRAM всей выбранной совместимой
   видеокарты, включая другие приложения. Выбор не привязан к названию карты.
2. Если модель с рабочими буферами и резервом помещается — полный GPU.
3. Если общий объём достаточен, а свободного места мало — предлагается закрыть
   тяжёлые программы. Доступны повторный замер, продолжение с автоматическим
   выбором и отмена. Приложение не закрывает чужие программы.
4. Для гибрида в CPU/ОЗУ переносятся экспертные веса первых N блоков. N определяется
   по точным размерам тензоров GGUF и текущему бюджету. Если подходящий гибрид
   невозможен либо надёжный замер GPU недоступен — CPU.
5. Перед запуском проверяется физическая ОЗУ с общей политикой резерва. Недостаток
   памяти даёт понятную причину ожидания, без попытки загнать систему в подкачку.

**2 ГиБ VRAM резервируются отдельно от модели, KV и рабочих буферов.** Предварительная
консервативная оценка полного GPU для закреплённого файла: 14 249 047 104 байта весов,
650 117 120 байт KV, 1 ГиБ рабочих буферов; с резервом требуется около **16,88 ГиБ
свободной VRAM**. Поэтому карта 16 ГиБ при этой политике может выбрать гибрид.
Это оценка допуска, а не измерение максимального фактического расхода.

При загрузке и каждые 500 мс во время генерации проверяется сохранение резерва.
Если другие программы заняли память, ответ останавливается с сохранением
доступного checkpoint и частичного текста. Самопроизвольного повторного ответа
после аппаратной ошибки нет. Переразмещение допускается до генерации; возобновление
через общий механизм снова выбирает режим по текущим ресурсам.

## Общие механизмы приложения

Модель подключена через стандартное окно проверки/скачивания, управляемый каталог,
ComponentAudit и общий лицензионный контур. Сохранены режимы аудита ON/OFF, проверка
первого использования, обнаружение повреждения и инвалидация после установки.
Добавлена одна необязательная запись Apache-2.0; лицензии остальных компонентов и
квитанции установщика не менялись — [проверка](license-check.json).

Сохранены STOP, пауза/продолжение и приватные checkpoint. Завершённые старые результаты
читаются без пересчёта. Незавершённый запрос Qwen3 не отправляется Gemma под видом
продолжения старой модели: показывается объяснение, переписка остаётся доступной.
Контекст не обрезается молча. Название модели, выбранный режим и причины ожидания
отображаются в чате; интерфейсные тексты предусмотрены на RU/EN.

### Реальные запуски в трёх режимах

Gemma действительно исполнялась на данном ПК с RTX 4090 / i9-13900KF / около 128 ГиБ
ОЗУ. Во всех трёх случаях использованы одинаковые промпт, параметры и две реплики.
Первый ответ включает загрузку, второй использует уже загруженную модель.

| Режим | Первый видимый текст, первая реплика | Вся первая реплика | Первый текст, вторая реплика | Вся вторая реплика |
|---|---:|---:|---:|---:|
| GPU | 8,77 с | 9,06 с | 0,22 с | 1,67 с |
| Гибрид, бюджет карты 12 ГиБ | 8,44 с | 10,06 с | 1,46 с | 10,93 с |
| CPU | 12,78 с | 14,91 с | 1,04 с | 18,04 с |

Артефакты: [GPU](native-final/Gpu.json), [гибрид](native-final/Hybrid.json),
[CPU](native-final/Cpu.json), [бюджет](native-final/memory-policy.json),
[размещение](native-final/placement.json).

Для гибрида тестовый процесс ограничивал доступный бюджет адаптера до 12 ГиБ с
учётом реально измеренной занятости другими программами; были выбраны 19 CPU-блоков
экспертов. Для проверки CPU бюджет был уменьшен до 2 ГиБ и действительно запускался
CPU backend без выгрузки слоёв на GPU. Этот служебный in-process механизм доступен
тестам; приложение его не включает, пользовательских/env-переключателей нет.
Проекция воспроизводит ограничение памяти, **не производительность физической 4070**.
Ответы имеют разную длину; времена не являются сравнением одинакового числа токенов.

4. Один тесный английский макет музыкальной панели: круг меньше ожидаемого минимума.

Связанные тесты и перечисленные исходники совпадают с HEAD —

совпадение исходников не подменяет такую проверку. Полный набор не объявляется зелёным.

## Ограничения и восстановление

испытаны этим этапом. Короткая интеграционная проверка не заменяет оценку качества
