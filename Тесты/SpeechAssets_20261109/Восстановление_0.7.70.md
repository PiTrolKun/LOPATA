# Восстановление большого проекта и перенос окна

Дата: 10.11.2026 (Asia/Novosibirsk). Версия: 0.7.70-dev.

## Исправление

Список больше не сбрасывается через `ItemsSource = null` после каждой записи. Сохраняются список и объекты строк, обновляются только изменённые видимые строки. События из исполнителя объединяются раз в 300 мс; чтение проекта выполняется вне UI, синхронного Dispatcher.Invoke из очереди больше нет. После завершения применяется финальный сохранённый снимок. F1 сохраняет атомарное подтверждение и согласуется с обновлениями.

Исполнение очереди/проверка файлов перенесены на Task.Run с сохранением общего scheduler/audit scope. Восстановление один раз читает снимок готовых строк, проверяет реальные SHA-256, не вызывает TTS и UI-callback для готового дубля. Checkpoint при пропуске готового префикса фиксируется раз в 64 строки; готовые WAV остаются источником проверки, checkpoint не разрешает слепой пропуск. Незавершённые части и прежние TakeId сохраняются. Начало запуска атомарно обновляет актуальный проект из store, не перезаписывая подтверждения старым UI-снимком.

Физический прогон обнаружил дополнительную гонку: вход в сценарий из restore-scope мог начать независимый прогрев, который затем включал UI-кнопки во время задания. Теперь наличие pending/running задания блокирует такой прогрев даже внутри scope. Регрессионный тест повторяет именно вход из scheduler. Исправлена также неразрешённая строка ChatSpeech.Busy: у утилиты есть согласованный ключ RU/EN.

Основные новые файлы: `SpeechAssetsControl.Updates.cs`, `SpeechAssetsRecoveryUiTests.cs`. Новых моделей/зависимостей нет, формат проекта не изменён.
