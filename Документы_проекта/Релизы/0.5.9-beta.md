# ЛОПАТА 0.5.9-beta

В музыкальном сценарии появился ИИ-чат для совместной работы над песней.
Текст, обсуждение и музыкальные пожелания находятся в отдельных регулируемых
областях. При открытии чат получает текущую песню; готовый результат переносится
в музыкальный сценарий вручную через копирование.

Кнопка «Сборка песни» собирает полный текст и пожелания по обсуждению.
ИИ± переключает собеседника среди установленных чат-моделей, сохраняя контекст.
Есть управление сессиями, автосохранение, независимые шаги текста и параметров,
проверка опечаток и счётчик видимого модели контекста.

Программа проверяет, появились ли заявленные правки. Копия прежнего текста
не считается изменением: выполняется одна исправительная попытка, затем
результат отклоняется с сохранением прежней песни. Непринятые ответы доступны
для просмотра. Наличие правок проверяется; их качество оценивает пользователь.

Чат работает как обычное отдельное окно. Кнопка в музыкальном сценарии мигает
красным, пока чат открыт, и горит постоянно во время запроса к модели.
Одновременные тяжёлые генерации в разных сценариях блокируются.

Новые веса не входят в обновление. Для новой установки используйте универсальный
миниустановщик: он скачает актуальный комплект нашей многопоточной загрузкой.
Для установленной бета-копии доступно подписанное файловое обновление.
