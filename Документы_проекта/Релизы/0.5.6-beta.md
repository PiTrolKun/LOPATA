# ЛОПАТА 0.5.6-beta

Добавлена перекодировка аудио через правую кнопку мыши в Проводнике:
«ЛОПАТА → Перекодировать аудио…». Можно выбрать один или несколько файлов,
формат MP3, Opus, FLAC или WAV, битрейт и папку результата.

- Названия, исполнители, альбомы, текст песни, комментарии и обложки переносятся в новый файл там, где формат позволяет.
- Рядом сохраняется .metadata.json с резервной копией дополнительных метаданных. Храните его вместе с песней; повторная перекодировка сохраняет эту историю.
- Исходники остаются без изменений. Существующие результаты не перезаписываются.
- Есть отмена и открытие результата; ошибка одного файла не останавливает остальные.
- Диалог поддерживает русский/английский интерфейс и обе темы.

Команда включается существующей настройкой интеграции Windows. В Windows 11
может находиться в «Показать дополнительные параметры».
WAV пока поддерживается только с 16-битным звуком. Перевод MP3/Opus в FLAC/WAV
не восстанавливает утраченное качество.

Файловый бета-патч и универсальный миниустановщик. Полный установщик не выпускался.
