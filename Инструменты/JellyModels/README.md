# Загрузка кандидатов для «желе»

Запуск из корня репозитория:

```powershell
powershell -NoExit -ExecutionPolicy Bypass -File .\Инструменты\JellyModels\start.ps1
```

Скрипт скачивает сначала GLiNER2.5 Multi, затем NuExtract3, в видимом терминале.
Каталог: `Тесты/JellyModels/models`, отдельная папка для каждой модели.
После завершения окно остаётся открытым. Для продолжения прерванной загрузки
нужно повторить запуск. Одновременный второй загрузчик блокируется.

Используется штатный `Инструменты/Runeweaver/download.py`: до 8 HTTP Range
потоков, докачка, сборка, проверка размера и SHA256, очистка своих частей
только после успешной проверки. Для небольших файлов настроек проверяются
размер и Git blob SHA1 из Hugging Face. Версии и контрольные суммы закреплены
в `config.json`; автоматического перехода на новую версию нет.

Оригинальные веса Safetensors, конфигурации, токенизаторы и инструкции:

- `fastino/gliner2.5-multi-v1`, revision `aaecfe45db1d828c963717054ccb868e8ad1f1d5`;
- `numind/NuExtract3`, revision `c99dc8f5641b866aa0192b6ea78f84bf9f3535f1`.

NuExtract3 включает опубликованные MTP-веса и индекс. Иллюстрации карточек
не скачиваются. Размеры пакетов: примерно 1,17 и 9,34 ГБ соответственно.
Это размеры загрузки, а не измерение потребления памяти.

Загрузка не устанавливает зависимости, не запускает модели и не подключает
их к программе. Следующий этап — отдельно согласованные проверки.
`download.py --check` проверяет манифест без сети и загрузки.
Текущее состояние записывается в `models/download-status.json`.
