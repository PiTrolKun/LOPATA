# ЛОПАТА 0.8.46-beta

В ЛОПАТЕ появился **NabyScape — LOPATA Edition**. Остров открывается через **Обработка / утилиты → Экран**. Там же доступны настройки и живой предпросмотр.

- Остров может оставаться открытым после выхода из ЛОПАТЫ. У него есть собственный значок в трее и отдельный автозапуск.
- Плеер открывает музыку из Коллекции ЛОПАТЫ и ваших папок, сохраняет общее избранное и показывает тексты. Управление медиасессиями Windows, включая YouTube в браузере, настраивается отдельно.
- Чат использует локальное ядро ЛОПАТЫ. Когда программа открыта, введённый текст переносится в «Если накипело». Из острова можно посмотреть активные задачи и управлять паузой, если задача её поддерживает.
- Остров проверяет обновления ЛОПАТЫ, показывает число пропущенных выпусков и сбрасывает счётчик после установки. Главный виджет можно выбрать звёздочкой. При боковой привязке остров перестраивается под вертикальный формат.

Файлы острова входят в штатное файловое обновление. [Исходный код редакции](https://github.com/PiTrolKun/NabyScape-LOPATA-Edition) · [Оригинал NabyScape](https://github.com/BillyNabil/nabyscape)
