# Как ЛОПАТА поможет подготовить литературный проект

Редакция: 13 сентября 2026 года.

**Статус: согласованный план, материал для будущей публикации. Визуальный набросок рассмотрен; принятые правки включены в эту редакцию. Реализация автоматического режима не начата.** Примеры ниже придуманы для объяснения механики; это не результаты теста модели и не сведения пользовательского проекта.

Существующее окно создания проекта останется как **«Экспертный режим»**. Новый **«Автоматический режим»** поможет собрать замысел постепенно: обычными словами, без требования заранее написать синопсис или профессиональную карточку произведения.

В основе — 36 коротких программных вопросов и одна ручная таблица маршрута, всего 37 пунктов в фиксированном порядке. Где возможно, пользователь выберет готовый вариант и при желании напишет свой. Для неизвестного есть **«Пока не придумал»**. Вместо абстрактного «Не относится» используются варианты по смыслу вопроса, например «Без первоисточника». Неизвестное, неприменимость и явное отсутствие чего-либо сохраняются раздельно.

Папка хранения и техническое название проекта определяются в самом начале, чтобы сразу сохранять подготовку внутри проекта. Название самой книги выбирается в конце. Незавершённую подготовку можно продолжить в другой день.

## Когда подключается ИИ

У литературного Советника здесь две разные операции:

1. **Проверка понимания после содержательного ответа, кроме ручного маршрута.** Пользователь нажимает **«Далее»**, ИИ показывает понимание, пользователь подтверждает или исправляет. Только подтверждённое содержание становится частью замысла. Технические поля, однозначный выбор готовых значений и таблицу маршрута обрабатывает программа.
2. **Дополнительные вопросы после обязательной части темы.** ИИ уточняет именно этот проект, опираясь на уже подтверждённые ответы. Пользователь сам завершает уточнения текущей темы.

В таблице показаны примеры дополнительных вопросов. Реальные формулировки заранее не заданы: они зависят от ответов пользователя. Вопросы и предложенные в них варианты ничего не утверждают за автора.

## Вопросы в порядке прохождения

Все примеры относятся к одному вымышленному произведению о часах, показывающих будущее.

| 19 | **Что важного произошло до начала действия?** | Дед Ильи умер и оставил ему дом с часовой мастерской. | Продолжаем обязательную часть темы. |

| 29 | **Как быстро должны развиваться события?** | Начало спокойное, затем напряжение постепенно растёт. | Продолжаем обязательную часть темы. |
| 30 | **Насколько подробно описывать происходящее?** | Описания короткие, важные предметы и поступки — подробнее. | **После № 26–30 — уточнение стиля.** Например: «Тревогу Ильи чаще показывать через его мысли или через поведение: перепроверяет замки, прислушивается, избегает некоторых разговоров?» |

Количество вопросов не означает столько же больших текстовых полей. Форму, жанры, настроение, темп и подробность можно выбрать из готовых вариантов. Свободному ответу часто достаточно одной фразы. Конкретное расположение элементов окна обсуждается отдельно.

Список жанров будет широким, включая нишевые направления, например **уся**. Можно выбрать несколько жанров и добавить своё уточнение. По наведению на жанр появится подсказка с его ключевыми особенностями, характерными элементами и отличиями от близких направлений.

## Маршрут: десять строк, первые две обязательны

Вместо отдельных вопросов о текущем этапе, его границе и двух будущих направлениях используется обычная таблица. Заполнение полностью ручное, без вопросов, пересказа или проверки понимания ИИ.

| № | Название | Описание |
|---:|---|---|
| **1 · обязательно** | Приезд | Герой приезжает в деревню и осматривает дом деда. |
| **2 · обязательно** | Первое предсказание | Часы показывают событие, которое ещё не произошло. |
| 3 | | |
| 4 | | |
| 5 | | |
| 6 | | |
| 7 | | |
| 8 | | |
| 9 | | |
| 10 | | |

Примеры не заполняются за автора. В первых двух строках нужны название и описание; эти строки выделены и отмечены словом «Обязательно». Пока одно из четырёх полей пустое, «Далее» недоступно. Остальные восемь строк заполняются по желанию.

Программа сохраняет введённое дословно внутри папки проекта, включая незавершённый ввод. Для первых тестов литературные роли получают эту таблицу как план. Использование маршрута при написании и ручное продвижение по этапам обсуждаются отдельно.

## Пример уточнения с ручной поправкой

В точках подключения ИИ может задать несколько вопросов по текущей теме. Ниже — пример продолжения после вопроса № 22.

| Момент | Что происходит |
|---|---|
| ИИ уточняет | «Показанное будущее можно предотвратить?» |
| Пользователь отвечает | «Да, но часы тогда больше этому человеку ничего не покажут». |
| ИИ показывает понимание | «Будущее можно изменить. Если человек предотвратил показанное событие, часы больше не показывают предсказания этому человеку». |
| Пользователь исправляет | «Не навсегда, только до следующего полнолуния». |
| ИИ показывает исправленный вариант | «Будущее можно изменить. После предотвращения показанного события человек не получает новых предсказаний до следующего полнолуния». |
| Пользователь подтверждает | **«Всё верно»** — только теперь эта формулировка сохраняется. |
| ИИ задаёт следующий вопрос этой темы | «Остальные люди в этот период продолжают получать предсказания от тех же часов?» |
| Пользователь завершает уточнения | **«По этой теме больше нечего добавить»** — переходим к следующему программному блоку. |

ИИ не может сам перепрыгнуть на другую тему или объявить весь опрос завершённым. Возвращаться к завершённым шагам в создателе нельзя; дальнейшее редактирование замысла планируется в рабочем окне отдельным этапом.

## Что остаётся после подготовки

В папке проекта сохраняются подтверждённый замысел, требования, ограничения, неопределённости, независимые якоря Писателя и Советника, ближайший маршрут и начальные направления для памяти произведения («желе»). Будущие намерения не становятся событиями уже написанного текста.

Для первых тестов весь подтверждённый замысел, включая дословно заполненный маршрут, передаётся в контекст литературных ролей с обозначением назначения разделов. Полную переписку опроса вместо него не подставляем. Дальнейшее дозирование сведений и управление процессом написания обсуждаются отдельно; продвижение по этапам предполагается ручным.

При нехватке контекста программа показывает уведомление с одной кнопкой «ОК». Дополнительные вопросы и пересказ ИИ отключаются до завершения подготовки, но пользователь проходит оставшиеся обязательные вопросы. Их ответы подтверждаются дословно. Уже введённые сведения сохраняются.
