# Проверки ЛОПАТЫ 0.9.32-beta

- В сборке выпуска прошли 180 тестов приложения, 8 тестов Инспектора и 113 тестов обновлятора. Восемь тестов приложения с отдельными условиями запуска пропущены. Проверка обновлятора включает тестовый ответ объёмом больше 4 МиБ.
- На изолированной копии 0.9.31-beta применены оба подписанных манифеста. Сверены SHA-256 8020 целевых файлов переходного манифеста и 6853 файлов манифеста, который выбирает обновлятор. Проверены также сохранённые файлы предыдущего набора движков. В обеих проверках штатный откат вернул 8018 подписанных файлов 0.9.31-beta. Три контрольных файла в папках приложения, проектов и моделей сохранились.
- Обновляторы из подписанных сборок 0.9.28-beta и 0.9.31-beta прочитали опубликованный список GitHub и предложили подписанную 0.9.32-beta. После выпуска первая страница списка содержала 4191258 байт при прежнем пределе 4194304 байта.
- На GitHub сверены тег, размеры и SHA-256 всех 28 вложений. Пройдены 18 проверок панели обновлений в поставляемом Острове, включая счётчик, повторную проверку и сохранение состояния. Тег форка указывает на закреплённый коммит `3a477d8b58933609ec97ea6692d86c24ddac343a`.
