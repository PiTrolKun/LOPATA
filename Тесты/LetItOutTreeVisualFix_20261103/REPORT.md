# Визуал дерева темы — 0.7.13-dev

По снимкам пользователя исправлены два отклонения новой карты.

1. Боковая панель заменяла дерево списком больших кнопок. Теперь она показывает
   вертикальное превью настоящей иерархии: корень, крупные ветви и линии между
   родителями/детьми. Выборка главных ветвей не переписывает модельный документ;
   остальные узлы доступны во внешнем окне. Длинные подписи в маленьком превью
   сокращаются с многоточием; полное название/описание есть в подсказке и по нажатию.
2. Внешнее немодальное окно не наследовало ресурсы владельца. Получались чёрные
   подписи на чёрном фоне, невидимые линии и системные светлые кнопки. Ресурсы
   MainWindow подключены до построения содержимого. Текст, фон, рамки, поиск и линии
   используют палитру ЛОПАТЫ. Узлы получили собственный шаблон без фиксированной
   высоты стандартных кнопок сценария, чтобы многострочные названия не обрезались.

При фокусировке выбранная точка центрируется по вертикали после расчёта layout.
Зум, перемещение, поиск, источники, переключатель панели и default-off сохранены.
Изменения касаются отображения, модельные карты и исходные сообщения не меняются.

фон и цвет текста в тёмной/светлой палитре, точные исходные реплики; тест превью —
