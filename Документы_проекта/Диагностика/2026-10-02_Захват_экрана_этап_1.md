## Результат

«Обработка / утилиты» → «Захват экрана». Рабочие фотоисточники: окно
ЛОПАТЫ, монитор под курсором, весь рабочий стол, выделенная область.
PNG/JPEG/WebP, файл/буфер/оба отдельно для каждого источника. Имена содержат
дату, время и суффикс уникальности; готовые файлы не перезаписываются.
Перед заменой текста буфера сначала сохраняется страховка, затем спрашивается
подтверждение. Отказ сохраняет текст и снимки. Маленькую область можно
обычно увеличить на CPU: оригинал и увеличенная копия сохраняются отдельно.
При сбое последняя картинка остаётся в RAM и предлагается PNG в другую папку.

Настройки в общем разделе Utilities; глобальные назначения для четырёх
источников каждого режима и остановки. Три и более клавиши, несколько
обычных клавиш, дополнительные события мыши, отображение зажатий в реальном
времени. По умолчанию Ctrl+Alt+1/2/3/4 для фото; остальные выключены.
Дубликаты и зарегистрированные системные конфликты не запускают команду.
Настройки GIF/видео сохраняются, запись недоступна; звуковые устройства
пока только Windows default, их перечень подключится на этапе 3.

Существующий трей дополнен снимком монитора и папкой результатов.
Скрытое окно временно восстанавливается по настройке и возвращается обратно
с прежней страницей. «Назад» из настроек сохраняет вход в утилиту.
Код захвата не вызывает остановку/паузу/выгрузку модельных операций.

## Технологии и поставка

Собственный `LOPATA.Capture` использует системные WGC/Direct3D11 через COM ABI.
Windows SDK.NET и C#/WinRT runtime не входят в поставку функции. Кадр копируется
в RAM, сессия освобождается, ожидание ограничено. Программный WARP — запасной
путь при недоступности hardware device или соответствующей ошибке устройства.
Это не обещает захвата с нулевым GPU: системный compositor участвует.

PNG/JPEG — WPF/WIC. WebP и обычное масштабирование — SkiaSharp 3.119.4 на CPU.
Встроены MIT и полный native third-party notice; прежние Terms каталога
сохранены. Отдельного скачивания кодировщика пользователем нет. GIF/видео
кодировщики пока не добавлены. Снимок ограничен 64 Мп, увеличение — 32 Мп;
BGRA8 без отдельного HDR-преобразования. VRAM под модели не резервируется.
