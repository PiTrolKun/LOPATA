# Обновление 0.5.2-dev: сетевое ожидание файлового патча

10.10.2026. Пользователь сообщил о пустой странице лицензий миниустановщика и ожидании проверки патча 0.5.1 около десяти минут на установленной 0.5.0-beta.

## Подтверждённые факты

- Миниустановщик после подготовки показал лицензии и номер 0.5.1-beta. Пользователь подтвердил исправное отображение. При повторной проверке RU/EN текст содержит 1050185 символов, переход без согласия блокируется. Код страницы не изменялся; причина первого пустого кадра не установлена.
- В установленном AIHub PID 33736 обнаружен HttpRequestException с внутренним IOException: Received an unexpected EOF or 0 bytes from the transport stream. Стек: HttpConnection.SendAsync → UpdateRangeDownload.TryDownloadAsync → DownloadCoreAsync → FileUpdatePreparation → ApplicationUpdateWindow.DownloadAsync.
- В момент осмотра сеть и CPU не работали, staging 0.5.1 отсутствовал; затем окно показало ошибку скачивания. На момент дампа операция уже завершилась ошибкой. Точное начало ожидания не зарегистрировано прежней версией; десять минут — сообщение пользователя, а не измерение агента.
- В старом UI последняя проверка одного пакета могла скрыть продолжающийся сетевой запрос другого. HttpClient приложения имел бесконечный общий timeout, загрузчик не ограничивал ожидание отдельного ответа/чтения.

## Правка

Общий загрузчик ограничивает отсутствие сетевого прогресса 60 секундами на ответ и каждое чтение. Продолжающая передавать данные большая загрузка не ограничена минутой целиком. До трёх попыток на пакет, задержки 1/2 секунды, повтор из сохранённого префикса/диапазонов. Повторяются сетевые сбои и временные HTTP-ошибки, не неверные подписи, SHA256 или постоянные HTTP-ошибки. Ручная отмена не превращается в повтор.

UpdateBatchProgress учитывает состояние всех нужных пакетов. Пока есть сетевое ожидание, UI не выдаёт его за проверку файлов; повтор обозначен отдельно на RU/EN. Ошибки подготовки пишутся в LocalAppData/AI_HUB/Diagnostics/Updates/download-*.json, без изменения механики подтверждения и применения.
