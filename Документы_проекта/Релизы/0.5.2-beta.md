# ЛОПАТА 0.5.2-beta

Исправлена обработка сетевых задержек и обрывов при скачивании файлового
обновления. Если сервер не отвечает или перестаёт передавать данные на 60 секунд,
загрузчик повторяет запрос с докачкой уже сохранённых данных. Для временного
сетевого сбоя предусмотрено до трёх попыток; ручная отмена останавливает загрузку.
Продолжающаяся передача большого файла не ограничивается одной минутой целиком.

Окно обновлений учитывает состояние всех загружаемых пакетов: ожидание сети
больше не маскируется сообщением о проверке другого файла. Повторная попытка
показана отдельно. При ошибке сохраняется диагностический журнал.

Тот же сетевой загрузчик включён в обновлённый универсальный миниустановщик.
Подписи, контрольные суммы и подтверждение установки сохраняются.
Миниустановщик скачивает последний совместимый опубликованный выпуск нашим
многопоточным загрузчиком и работает без предварительной установки .NET или Python.

Проверены сетевые задержки, докачка после обрыва, отмена, контроль целостности,
статус нескольких одновременных пакетов и страницы лицензий на русском и английском.
Полный офлайн-установщик для этого патча не пересобирается.

## English

File updates now recover from temporary network stalls and interrupted responses.
After 60 seconds without a response or incoming data, the downloader retries and
resumes saved data, with up to three attempts for temporary network failures.
User cancellation stops the download. Large files remain unrestricted while data
continues to arrive.

The update window tracks all packages, so one file's verification no longer hides
another file's network wait. Retries have a separate status and failures produce
a diagnostic log. The updated universal mini installer uses the same downloader.
Signature checks, checksums and installation confirmation remain in place.
It downloads the latest compatible published release using parallel downloads,
without requiring a preinstalled .NET or Python runtime.
