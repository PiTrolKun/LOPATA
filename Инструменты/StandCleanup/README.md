# Очистка стендов

Ярлык «Очистка стендов» на рабочем столе открывает общий список. Введите номера папок через пробел или слово `все`. Утилита проверит выбранные папки, покажет оставшийся объём и попросит подтверждение `да`. Пропущенные папки останутся в очереди с причиной.

## Работа из терминала

Один раз соберите утилиту из корня проекта. Ей нужен установленный .NET 10.

```powershell
dotnet build 'Инструменты/StandCleanup/StandCleanup.csproj' -c Release
$cleanup = 'H:\AI_HUB\Инструменты\StandCleanup\bin\Release\net10.0\StandCleanup.exe'
& $cleanup list
```

`add` применяется только к проверенной временной папке конкретной завершённой задачи. Укажите хотя бы один сохранённый файл результата или протокола за пределами `_tmp`.

```powershell
& $cleanup add $verifiedStandPath $taskName $savedReportPath
& $cleanup list --json
& $cleanup clean $queueId $verifiedStandPath
& $cleanup clean $queueId $verifiedStandPath --apply
```

Команда `clean` без `--apply` проверяет состав и показывает план. `--apply` повторяет проверку и выполняет очистку выбранной записи. Запуск через Codex проходит штатную проверку разрешений. При отказе запись остаётся доступной по ярлыку. Если мешает занятый файл или доступ к папке, закройте связанные процессы и повторите запуск. При изменении состава сначала проверьте, что появилось в папке. Сохранённая запись допускает удаление только прежнего проверенного состава.

Очередь и подтверждения хранятся в `_backups/StandCleanup/queue.json`. `list --all` показывает закрытые записи. Если папка удалена через Проводник, следующий просмотр закрывает её запись. Объём в списке — сумма размеров файлов. Освобождённое место зависит от того, есть ли у файлов другие ссылки на диске.

Утилита сверяет принадлежность пути к `_tmp`, исключает ссылки и отслеживает замену файлов и папок. Самостоятельные репозитории и временные копии Git с локальными правками проверка сохраняет. Для чистой временной рабочей копии Git требуется, чтобы коммит был доступен в известных удалённых ветках. Удалённый стенд Git распознаёт как отсутствующую рабочую копию. Служебные записи общего репозитория за пределами стенда остаются в Git.
