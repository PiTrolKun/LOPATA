# ЛОПАТА 0.5.74-beta

В «Обработка / утилиты → Базы знаний» добавлена утилита «Метаданные файлов».
Можно открыть несколько файлов, просмотреть сведения, технические поля,
служебную историю и встроенные изображения. Есть миниатюра изображения
и предпросмотр третьего кадра видео, увеличение и извлечение картинок.

Обычные поля изменяются только по явному выбору, с предупреждением перед
сохранением исходников. История создания файла защищена. Аудиообложку можно
заменить, указав рисующую модель ЛОПАТЫ либо происхождение вручную;
первоначальные сведения об обложке сохраняются отдельно.

Проверена запись обычных полей MP3, Opus, FLAC, WAV, PNG, JPEG, WebP и DOCX.
PDF, видео, неизвестные контейнеры и обнаруженные подписанные материалы
доступны для чтения. Замена обложки у аудио с несколькими картинками пока
отключена; правка тегов сохраняет их. Lyrics доступны для чтения.
Подробная матрица и ограничения размеров — в руководстве метаданных.

Исправлена прокрутка длинных многострочных полей. Полоса страницы сценариев
теперь соответствует теме и подсвечивается при наведении/перетаскивании.
Работа локальная, без ИИ и скачивания новых моделей. Для чтения сведений
добавлен закреплённый комплект ExifTool 13.59 с оригинальными лицензиями.

Это файловое обновление. Полный и универсальный миниустановщик не пересобирались.
