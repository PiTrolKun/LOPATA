# Проверки калибровки

Запуск из корня репозитория; используется установленный Runeweaver и штатный runtime. Пользовательские проекты не изменяются. Синтетические проекты и полные расширенные логи находятся в `runs/`, сводки контрольного прогона — в `Reports/`.

```powershell
dotnet run --project Тесты/LiteraryCalibration/Probe.csproj
dotnet run --project Тесты/LiteraryCalibration/Probe.csproj -- --mechanics
dotnet run --project Тесты/LiteraryCalibration/UI/Probe.csproj
```

Первый запуск: по три повтора пересказа, противоречия, неоднозначности, отрицания, чистого текста, фантастического допущения и необычного имени. Второй: все 12 пресетов, ручной EN-запрос, превышение бюджета, общий gate, отмена и новый запрос после отмены. Включается подробное логирование только в процессе стенда. Загрузка весов не выполняется.

WPF-стенд проверяет обе темы и локализации, сохранение длинного текста, область проверки, несохранённую редакцию, устаревший ответ, связанные отметки, отказ и отмену, закрытие во время запроса, меню модели и штатной орфографии, ручную замену слова и undo. Изображения сохраняются в `runs/ui/`.

## Контрольный результат 2026-09-14

Доставка исправлена после первого диагностического прогона: вложенный текст JSON теперь содержит читаемую кириллицу вместо буквальных Unicode-escape последовательностей. Для калибровки temperature=0.2, max_tokens=3072, контекст с резервом проверяется по токенизатору. Настройки интервью сохранены.

Финальная серия: 21 запрос, 17 ответов с корректными адресами и 4 отклонённых из-за неточных цитат/адресов. Служебный пересказ, противоречие и отрицание обнаружены во всех трёх повторах каждого случая. Неоднозначность отмечена в одном, два ответа отклонены. Чистый текст в трёх повторах оставлен без замечаний.

Ограничение качества: фантастическое допущение и необычное имя дали по два ложных замечания и по одному ответу с неверной цитатой. Это не исправляется разрешением неточных ссылок: программа отвергает неверные координаты, а смысловую оценку оставляет пользователю. Красная отметка — предложение проверить текст, не установленная ошибка. Автоматического изменения текста нет.

Отдельный механический прогон: все 12 пресетов и ручной EN-запрос вернули структурно корректные результаты; бюджет, gate, отмена и восстановление после неё прошли. Это свидетельство работоспособности интеграции, а не гарантия качества каждого анализа.

Полные локальные серии: `20260914_150334` (после исправления кириллицы), `20260914_150524` (финальные промпт/temperature), `20260914_151018` (механика runtime). Первый диагностический прогон также оставлен в `runs/` для сравнения.

Проверки завершения этапа: 574/574 автоматических теста; WPF-стенд RU/EN и обе темы, меню модели/орфографии и undo; runtime-прогон 12 пресетов + ручной запрос, бюджет/gate/отмена; scanner и diff-check пройдены.
