# Литературные наборы промптов — 0.1.125-dev

20 сентября 2026. Реализовано по [ТЗ](../../ТЗ/Архив/2026-09-20_Литературные_наборы_промптов.md), результат принят пользователем, ТЗ закрыто и архивировано по его команде. Commit/push отложены до дальнейшей полировки по прямому указанию пользователя. Результаты проверок ниже относятся к реализации; при архивировании код не менялся, тесты не перезапускались.

## Результат

Кнопка «Свои промпты» открывает отдельное окно с выбором стандартного/кастомного режима, списком именованных наборов, созданием через «+» и управлением через шестерёнку. Выбор сохраняется сразу для текущего проекта. Менеджер позволяет переименовывать, редактировать, удалять с подтверждением и перемещать варианты выше/ниже.

Один вариант содержит 12 действий. Редактор — единый вертикальный список: две роли → шесть действий каждой роли → инструкция роли и инструкция действия. Оба уровня свёрнуты при каждом открытии; раскрываются независимо. Название, сохранение и отмена относятся ко всему набору. У полей есть отмена, повтор, перенос строк, возврат стандартного текста с подтверждением, поиск и Ctrl+F. При закрытии несохранённого набора требуется подтверждение. Пустые обязательные поля не сохраняются, нужные группы раскрываются для исправления.

Встроенные тексты не изменены. Новые наборы и восстановление поля используют копии из кода. Режим «Стандартный» обходит выбранную пользовательскую копию. Жанровый профиль, сведения проекта, формат ответа, источники и отдельная подготовка ТЗ сохраняют прежнее поведение. Свободный чат, F1/F2, память и калибровка не получают пользовательские тексты этого редактора.

## Данные и совместимость

- Новая библиотека: `AppDataPaths.BaseDirectory/Prompts/literary-sets.json`, schemaVersion 1. Это отдельный файл, прежний `pairs.json` не перезаписывается. Атомарная запись с блокировкой и проверкой хеша защищает от конкурирующего сохранения.
- В `Dialogs/Studio/session.json` добавлено необязательное `PromptSettings`: флаг Custom и снимок Selected. Версия прежнего журнала остаётся 1. Без нового поля runtime продолжает читать старые словари действий; открытие окна не пишет проект.
- Старые применённые пары отображаются единым снимком «Текущие промпты проекта». Его можно сохранить в библиотеку. Прежние библиотечные варианты доступны в редакторе для вставки в соответствующее действие; остальные поля остаются прежними. Эта строка появляется только при наличии старых литературных вариантов.
- Удаление/изменение библиотеки не превращает активную копию проекта в стандартный режим. Несовпадающий снимок явно помечен «копия проекта» и доступен для сохранения как вариант. Правка выбранного библиотечного варианта через менеджер применяется к проекту; при ошибке записи проекта прежний снимок сохраняется.
- Кастомный режим без выбранного набора сообщает об этом перед отправкой и не подставляет стандартные тексты скрыто.

Новые компоненты разделены: модель/разрешение набора, библиотечное хранилище, окно выбора, менеджер, редактор и помощник оформления. Темы действуют локально в новых окнах; переиспользованы оформленные селекторы RAG. Заголовок окна следует теме. Общий редактор и библиотека анализатора изображений не изменены.
