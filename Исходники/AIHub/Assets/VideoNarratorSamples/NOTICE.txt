LOPATA narrator evaluation examples / Оценочные примеры дикторов

These are generated audio examples of the user's test text, not model weights,
voice clones, endorsements, or recordings of the upstream authors. Original
spellings Лопата and LOPATA are intentionally kept in both languages.
Exception requested by the user on 2026-10-26: the Vosk Russian example
uses Лопата in both sentences, since its native frontend rejects Latin text.
One default speaker per model is demonstrated. Language support and synthesis
quality are model-specific. No other model or voice was substituted.
Experimental entries test foreign-language text through that model's native
pipeline: language is the text language, synthesisLanguage is the actual native
pipeline, experimental is true. This does not add advertised language support.
Unsuccessful attempts are listed separately in unavailable.json.

samples.json records the exact text, speaker, model sources and actual execution
revisions; each WAV embeds LOPATA provenance. PCM16 audio is copied unchanged
from the model run, apart from the application's embedded metadata.
