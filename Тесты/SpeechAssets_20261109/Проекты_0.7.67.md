## Результат

- Исправлен active/disabled вид в тёмной и светлой палитре основного окна. Во время генерации строки доступны для прокрутки и прослушивания, изменения блокируются; кнопки сохраняют фон и контраст.
- F1 скрыто подтверждает все уже существующие выбранные дубли с текущим текстом, валидным PCM и совпадающим хешем. Не подтверждает отсутствующие/повреждённые/невыбранные/устаревшие и будущие записи.
- ZIP Fastest: Opus (default 64 kbps), MP3, FLAC, WAV; выбор битрейта. Общий MusicAudioRuntime, ComponentAudit и лицензирование, реальная история моделей, хеши экспортированных байтов и исходного WAV, отмена без порчи прежнего архива. Оригиналы остаются в проекте.
- Проекты переделаны по MusicProjects/MusicProjectController/MusicProjectsWindow: одна кнопка «Проекты», внутренний каталог, «Сохранённые вручную»/«Сохранённые после запроса», фиксация/переименование/новый/открытие, история запусков. Каждый запрос автоматически фиксирует проект; ручная фиксация закрепляет его в ручном списке. Файловые диалоги и внешний проект с соседней папкой из окончательной реализации исключены.
- Сеансы сохраняют тексты, модель/профили/формат, все дубли и их выбор/подтверждения, неизменные ID очереди и квитанции частей. JSON fsync + атомарная замена + `.bak`; повреждённый основной снимок сохраняется отдельно, поднимается предыдущий. UI во время обработки не перезаписывает данные worker устаревшим снимком; F1 и commit используют сериализованный Update.
- Только поток: первоначальная попытка + до трёх повторов на реплику. Сбойный narrator освобождается, готовые части используются снова. После исчерпания повторов ошибка и счётчик сохраняются, обрабатывается следующая строка. Пауза/отмена не повторяются; ручная одиночная генерация оставляет прежний отказ без автоповтора. Следующий запуск оставшихся возвращается к неудачным строкам.
