# ЛОПАТА 0.9.27-beta

- **«Песня → клип».** Исправлен сбой в окне подготовки MiniMax H3. Теперь окно корректно показывает ход проверки и установки компонентов в вариантах H3, включая Deno RTX и pi-H3 DWD.
- Если для планирования клипа не хватает модели-помощника, ЛОПАТА скачивает нужную модель и продолжает обработку в том же проекте. Для H3 используется Qwen3.6-27B Q4_K_M, для Glitchframe — модель ядра.
- **Конвертер видео.** При включённом «Собрать в ZIP» в выбранной папке сохраняется один архив. После сбоя упаковку можно повторить с уже перекодированными роликами.

Подписанное файловое обновление бета-канала.
