# «Желе» в программе — 0.1.92-dev

Реализована цепочка: завершённая часть → существующая индексация RAG → Runeweaver извлекает предложения → пользователь проверяет все записи → SQLite `Jelly/память.lopata` → ограниченный пакет актуальных фактов обоим чатам. Открытый редактор остаётся предварительным. Старые завершённые части готовятся при открытии проекта; отменённая проверка возобновляется без повторного извлечения.

В шапке рабочего экрана добавлена «Память произведения». Она открывает принятые записи для правки/исключения. Изменение факта не меняет текст рукописи; предыдущие значения хранятся в журнале. Предложения, исключения, версии источников и решения пользователя остаются внутри проекта. Это первая продуктовая версия формата SQLite, schema/user_version=1, format=AIHub.Jelly.

Подготовка последовательная, без фонового архивариуса и дополнительных обязательных моделей. Общая Runeweaver использует существующий runtime и защиту от циклов. NuExtract3, GLiNER и Vikhr остаются стендовыми кандидатами.

## Ограничения

Предложения требуют проверки человеком: возможны дубли, пропуски и смысловые ошибки даже при точной цитате. Выборка памяти ранжируется по совпадениям слов, максимум 12 фактов и 2400 символов списка, с дальнейшим уменьшением под фактический токенный бюджет. Числа omitted/stale сообщают о неполноте. Это не универсальный графовый поиск и не автоматическое разрешение противоречий.

При ошибке поля/цитаты окно показывает номер записи и прокручивает к ней. При ошибке диска правки остаются в открытом окне; отмена не подтверждает их. Подготовленные предложения сохраняются на диск, но незавершённый ручной ввод в окне не переживает аварийное завершение программы.
