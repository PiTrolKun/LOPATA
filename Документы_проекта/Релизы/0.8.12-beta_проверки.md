# ЛОПАТА 0.8.12-beta — проверка файлового обновления

[Подписанное файловое обновление](https://github.com/PiTrolKun/LOPATA/releases/tag/v0.8.12-beta) опубликовано на бета-канале. Тег указывает на [исходный коммит](https://github.com/PiTrolKun/LOPATA/commit/f1edd8b7a9757bdc9af81ce2a6d09615d02f5532).

- «Песня → клип» подбирает размер запроса и восстанавливается с сохранённых сцен. Размеры генерации отмечены короткими подписями и значками формы. В «Апскейле видео» исправлена отрисовка шкалы предпросмотра.
- Прошли 374 профильных проверок приложения, 105 проверок обновлятора и 60 проверок Python. Пропущены 20 опциональных проверок приложения, 0 проверок обновлятора и две проверки Python. Апскейл проверен на коротком ролике. Для «Песня → клип» ранее проверены полный план из 157 сцен и короткие рендеры.
- Подпись подтверждена публичным ключом, которым проверяется предыдущий выпуск. Переходный манифест сохранил все 7695 путей из 0.8.6-beta. Сверены 2531 записей в 17 новых ZIP.
- Все 21 вложений GitHub совпали по размеру и SHA-256. Скачанные подписанные манифесты совпали с локальными. SHA-256 переходного манифеста — `2ecf69842309240da7be3dd90bec333587dc19c12960fc3d9664fd2c46c4cbf2`. SHA-256 манифеста для новой установки — `f82f7aff7953bb6966d59751e2386566af21d71229bdd03457bce111fabba313`.
- Проверка выпуска выполнена в отдельной рабочей копии. Обновление установленной программы на этом компьютере отдельно не запускалось.
