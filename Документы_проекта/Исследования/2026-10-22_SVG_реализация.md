# Генерация векторной графики — реализация 22.10.2026

Версия 0.6.3-dev. Первый рабочий поток реализован по прямой команде пользователя;
ТЗ остаётся активным до практической приёмки. Публикация/установщик не выполнялись.

## Состав

- Создание → Изображения → Генерация векторной графики, отдельный устойчивый
  vector_generation в каталоге и облаке тегов, RU/EN. Компоновка простого
  генератора: история/запрос, крупный результат, миниатюры.
- Qwen3.8-27B-Ridge 3.7 bpw, существующие registry, license gate, file audit,
  native engine selector, KV/memory budget и retirement. Дополнительные веса
  и vision projector не требуются. Отдельного output cap нет: max_tokens=-1,
  stream до EOS; context exhaustion/обрыв не являются успешным SVG.
- Отдельный transport entry в LiteraryChatRuntime не включает прозовый loop
  detector: повторяющиеся координаты и цифровой дождь допустимы в графике.
- Статическое безопасное подмножество SVG, DTD/PI/внешние ресурсы, script,
  foreignObject, image, animation, use и CSS-блоки отклоняются. Inline style
  проверяется после XML-декодирования, в том числе запрет escape обходов URL.
  viewBox конечный и положительный; технические XML/node/time guards сохранены.
- Официальный resvg 0.47.0 CPU Windows x64, pinned archive+file SHA256; оригинальные
  MIT/Apache-2.0/dependency notices. Один PNG-источник для центрального просмотра,
  миниатюры и большого окна; прозрачность — шахматная подложка. SVG остаётся
  самостоятельным векторным файлом. Встроенное большое окно — фиксированное
  превью, не редактор с бесконечным зумом. Qt/Calibre/Node/Sharp не нужны продукту.
- Все пользовательские файлы — GUID jobs и выбранное хранилище результатов;
  answer.txt/partial.txt сохраняются отдельно от производных image.svg/preview.png.
  В SVG/PNG встроено происхождение LOPATA, версия, actual engine/backend/revisions.
  Запросы, raw ответы и private пути не попадают в публичные метаданные.
- Общие vector-graphics.generate / vector-graphics.prepare зарегистрированы для
  фона/паузы/продолжения/перезапуска/трея; завершённый inference коммитится до
  renderer. Превью связано SHA256 с SVG; стабильное имя экспорта не дублируется
  и не заменяет другое содержимое. Чужие процессы не завершаются.
