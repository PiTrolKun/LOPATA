# Подготовка RAG и переключение после паузы — 0.5.53-dev

## Что доступно

Вход: **Утилиты → Базы знаний → Подготовка базы знаний**.
Выбрать TXT, сохранённый HTML или PDF, указать название и папку библиотеки,
нажать «Начать подготовку». Обработка выполняется в приложении и продолжается
при скрытом окне/работе в трее. Результат открывается на вкладке «Результат»;
там доступны количество фрагментов, причины исключений и пробный поиск.

Сначала проверяются закреплённые файлы Giga 3B и управляемого Python. Индекс
использует поддерживаемый Transformers: двунаправленный encoder, усреднение
по действительным токенам, L2-нормализация, 2048 измерений. Документы передаются
без инструкции, поисковый запрос — с инструкцией поиска. Совместимый GPU
предпочтителен, CPU используется как резерв. Новый индекс не заменяет базу 480M.

Чат-модель не переписывает книгу и не нужна для обычного построения индекса.
Установленные GigaChat/Qwen остаются доступными для дальнейшего адресного
разбора сложной структуры; такой разбор не выдаётся за реализованный здесь.

## Сохранность

- Оригинал не изменяется. Управляемая копия сверяется по SHA256.
- Страницы сохраняются атомарно с контрольными суммами; повреждённая порция
  извлекается повторно. Завершённые страницы используются при продолжении.
- Векторы фиксируются порциями в транзакционном SQLite с synchronous=FULL.
  Протокол, модель, ревизия и идентичность источников проверяются перед повторным использованием.
- Готовая версия публикуется отдельно и только после проверок. Незавершённая
  или полностью забракованная версия не заменяет предыдущую.
- Сомнительные единицы отсутствуют в готовых фрагментах и векторах. Исходники,
  журнал, OCR TSV и quality.json остаются в рабочей диагностике.
- Пользовательская библиотека помечена private=true / shipping_corpus=false:
  успешная индексация не подтверждает право распространять исходную книгу.

Для сканов используются Windows.Data.Pdf и уже установленный Tesseract RU/EN.
Страница с уверенностью хотя бы одного слова ниже 85 исключается целиком.
Без нужного OCR-компонента страница также исключается с причиной. Отсутствие
такой причины не является доказательством идеального распознавания.

## Новое поведение паузы

Полностью остановленное задание освобождает общий допуск моделей. Можно
запустить другой сценарий или вспомогательный чат. Независимые состояния
хранятся в Background/Jobs/<id>.json; прежний operation.json сохранён как
совместимое представление выбранного задания.

В трее есть список **«Продолжить задание на паузе»**. Возобновление выбирается
явно; пользовательская пауза сохраняется после перезапуска. Два модельных
исполнения одновременно не запускаются. Пока модели освобождаются либо
освобождение не подтверждено, допуск остаётся занят.

Отмена приостановленной задачи адресуется по её ID и не выгружает модель
другого сценария. При завершении приложения сохраняются все незавершённые
задания. Установка автозапуска Windows не выполнялась.
