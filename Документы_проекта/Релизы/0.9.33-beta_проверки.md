- На рабочей Windows 11 x64 прошли 55 адресных тестов. Из исходников WPF собран самостоятельный EXE. Проверены переходы между формами, вкладки, сохранение ввода при изменении размера, звук ошибки без всплывающего окна и запуск тестовой программы с параметром.
- Проверены подсказки Gemma для готовых действий и C#, исправление ошибки сборки, сохранение диалога и открытие истории после перезапуска. В двух сравнительных пробах сводка проекта помогла Gemma найти форму по кнопке и использовать существующую функцию. Поведение проверено в EXE.

- Запуск без ЛОПАТЫ, Gemma и сети на чистой Windows отложен до пробы другим пользователем. Проверки системного масштаба, перетаскивания рамки и открытия браузера перечислены в архивном ТЗ. [Архив ТЗ](../../ТЗ/Архив/2026-11-27_Визуальный_конструктор_с_Gemma.md)
