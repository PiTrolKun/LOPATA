# ЛОПАТА / LOPATA 0.1.53-beta

Первый опубликованный тестовый установщик ЛОПАТЫ с механизмом обновлений.

- Проверка новых установщиков из GitHub Releases после запуска программы.
- Окно «Обновления программы» в настройках: ручная проверка, отключение
  автоматической проверки и выбор получения Beta-выпусков.
- Скачивание внутри программы через общий многопоточный загрузчик,
  продолжение после паузы, проверка размера и SHA-256.
- Установка по подтверждению пользователя после завершения работы программы.
- Общий ввод изображений для Альфы, Беты и Гаммы: перетаскивание и Ctrl+V
  на шаге выбора изображения, сохранение импортированных изображений.

Модели скачиваются отдельно штатными средствами программы. Установщик
содержит приложение и поставляемые runtime-компоненты, а также сведения
об их лицензиях. Это тестовый Beta-выпуск; обратная связь приветствуется.

Чтобы получать следующие тестовые установщики, оставьте включённым пункт
«Получать тестовые версии программы (Beta)». Скачивание и установка
обновления требуют вашего действия; программа не устанавливает их скрыто.
