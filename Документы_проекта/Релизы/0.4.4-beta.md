# ЛОПАТА 0.4.4-beta

- Музыка: отдельное окно экспертных настроек YuE2 с понятными названиями, описаниями и техническими подсказками. Настройки учитываются в заданиях, контексте, оценке памяти и повторе генерации.
- Пользовательские пресеты: сохранение, выбор, обновление, переименование, удаление; импорт и экспорт JSON с проверкой совместимости.
- Нижняя панель музыкальных действий: экспертные настройки и место будущего чата для стихов.
- Крупная загрузочная анимация во время начальной проверки оборудования и зависимостей. После проверки сохраняется обычный стартовый экран; повторный переход «Начать работу» не запускает стартовую проверку заново.
- Справка RU/EN и документация обновлены; опубликована карта дальнейшего музыкального конвейера.

Чат для стихов пока недоступен. Новые модели и зависимости в этом выпуске не добавлены. Полный установщик остаётся 0.4.0-beta; этот выпуск распространяется файловым обновлением.
