# ЛОПАТА 0.5.0-beta

Полный бета-выпуск музыкального сценария. В списке выбора оставлены четыре
подключённые модели: YuE2 Studio Q8, ACE-Step 1.5 XL Turbo 4B,
DiffRhythm 2 и HeartMuLa 3B. Неподключённые кандидаты убраны из интерфейса;
план следующих подключений сохранён в документации.

Музыкальные проекты общие, настройки привязаны к модели. Доступны
переключение установленных моделей через ИИ±, экспертные параметры,
модельные пресеты, примеры исполнения и измеренное потребление памяти.
В карточках есть значок безопасного удаления файлов модели с подтверждением;
песни, проекты, настройки и общие компоненты сохраняются.

YuE2 работает через Studio; ACE — через штатный конвейер авторов.
Русский у DiffRhythm 2 и HeartMuLa остаётся экспериментальным.
Описание возможностей отражает наши испытания и не гарантирует одинаковое
качество для всех запросов. У компонентов могут быть собственные условия,
включая ограничения коммерческого применения; лицензии показываются
перед загрузкой и использованием.

Выпуск содержит подписанное файловое обновление существующей установки,
полный автономный установщик и небольшой сетевой установщик.
Веса моделей загружаются отдельно через ЛОПАТУ.
