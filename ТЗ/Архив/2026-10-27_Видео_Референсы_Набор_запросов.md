# Референсы: набор запросов до рисования

## Приёмка — 27.10.2026, 0.6.55-dev

Пользователь подтвердил завершение подготовительного этапа и поручил закрыть текущие ТЗ согласно правилам. Реализация этого этапа выполнена и принята. Модельные мастера, адаптация под каждый видеогенератор, сам видеосинтез и последующая адаптация музыкального сценария — отдельный следующий уровень, этим закрытием выполненными не объявляются.
Сохраняются ограничения: художественное качество ответов требует проверки пользователем; другие GPU физически не испытаны; плавающий native-сбой сохранения не объявляется окончательно исключённым; случай восстановления после реальной перезагрузки подтверждён пользователем, а не принудительным crash-тестом. Локальный HTML не проверен визуально в управляемом браузере из-за запрета file; его структура и логика проверены отдельно, нативный аниматик проверен со звуком.
Предыдущие промежуточные статусы и записи об отсутствии архивации/публикации ниже являются историей разработки.
Публикация исходников и подписанного файлового обновления 0.6.56-beta оформляется отдельно в отчёте выпуска. Эта запись фиксирует приёмку, а не уже состоявшуюся публикацию.

Статус: выполнено и принято пользователем 27.10.2026; архивировано.

Основание: пользователь согласовал следующий подэтап после импорта: выбор
полуавтоматического/ручного режима, определение нужных изображений и подготовка
всех запросов до переключения на рисующую модель.

- Использовать существующего проверенного помощника Qwen, наследовать выбор;
  сохранить общий прогрев, GPU/гибрид, аудит, лицензии и фоновые операции.
- Модель предлагает список в массиве []; привязки проверяются по существующим
  карточкам. Показывать исходный ответ, позволять добавлять/править список вручную.
- Учитывать принятый замысел, развитие, визуальный мир и уже привязанные файлы.
- Сначала пользователь выбирает элементы. Затем для каждого независимо
  готовятся описание и английский рабочий запрос. Можно редактировать оба,
  улучшать выбранный запрос и перемещаться по истории версий.
- Прерывание не теряет готовые результаты. Повторное получение ответа не
  создаёт дубликаты; устаревший ответ не заменяет изменённые пользователем данные.
- Набор, исходные ответы, версии, модельное происхождение и связи сохраняются
  в переносимом .lopataAIVid, старые проекты остаются читаемыми.
- Орфография: язык интерфейса для описания, en-US для рабочего запроса.
- Ручной путь позволяет самостоятельно собрать тот же набор без вызова ИИ.
  Два окна рисования/привязки файлов, выбор и прогрев графической модели,
  освобождение GPU Qwen и само рисование — следующий подэтап, не имитировать их.
