# ЛОПАТА 0.8.15-beta

После аварии отдельный процесс Windows перезапускает ЛОПАТУ и отправляет сообщение в Центр уведомлений. Запись о сбое можно прочитать позднее.

ЛОПАТА возвращает сохранённые рабочие окна. Задачи с автопродолжением возобновляются с последнего сохранённого этапа. При повторном сбое программа открывается в безопасном режиме. После штатного выхода ЛОПАТА остаётся закрытой.

Проверены принудительное завершение через диспетчер задач, восстановление окна, продолжение апскейла и экспорт видеоредактора.
