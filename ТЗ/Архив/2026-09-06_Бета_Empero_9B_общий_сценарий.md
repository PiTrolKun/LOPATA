# ТЗ — Бета Empero 9B по образцу Альфы

Дата: 2026-09-06. Статус: принято пользователем и закрыто 2026-09-06 после исправления подписи профиля. Версия 0.1.49-dev.

## Цель и границы

Перевести новые работы Беты с экспериментального Kimi/Florence/редактора ядра на модель empero-ai/Qwen3.8-9B-Distill и общий механизм Альфы. Альфа — новый функциональный образец. Сохранить один пользовательский сценарий: два этапа той же модели, стандартные/кастомные промпты, пожелания, версии, экспорт, Kokoro CPU, дождь, до трёх автоматических попыток и защиту контекста 95%. Изменение Гаммы, ядра и MTP не входит в задачу.

## Комплект и целевой профиль

Цель: 32 ГБ RAM, видеокарты с 10–16 ГБ VRAM. Нижняя граница проверяется по полному расходу процесса и сопутствующих компонентов, а не размеру файла. Предварительный профиль: Q4_K_M, отдельный F16 модуль изображений, один слот, 32768 токенов, GPU для модели и проектора, без автоматического CPU offload/fit/context shift. Sampling как в карточке 9B: temperature 0.6, top_p 0.95, top_k 20, min_p 0; reasoning отделяется от конечного ответа. Профиль Альфы не менять.

Исходник Empero: https://huggingface.co/empero-ai/Qwen3.8-9B-Distill/tree/0934f3d2327ff2df2197495278c4c46ae5a56bd9.
Текстовый GGUF: https://huggingface.co/empero-ai/Qwen3.8-9B-Distill-GGUF/tree/760121cd70bb4c36b2b5ec58eb765e0df5987efe.
В авторской GGUF-поставке нет mmproj. Предварительная пара использует F16 проектор исходной Qwen3.5-9B из https://huggingface.co/unsloth/Qwen3.5-9B-GGUF/tree/3885219b6810b007914f3a7950a8d1b469d598a5.
Это составной экспериментальный комплект; проектор не является проверенной конверсией визуальных весов Empero. Совпадение архитектуры/размерностей не доказывает эквивалентность весов или качество зрения. Подтвердить структуру по метаданным, реальные vision/русский/память — после пользовательского скачивания. Не объявлять пару проверенной до реального запуска.

Закрепить точные revision, размеры и хэши двух файлов из API в каталоге. Отдельный ID Беты и provenance учитывают обе ревизии. В лицензионном каталоге явно указать два источника, Apache-2.0 по их карточкам, дату проверки и известные ограничения. Штатная кнопка скачивает оба файла общим многопоточным загрузчиком с возобновлением и проверкой хэшей; пользователь запускает загрузку сам. Не добавлять обходы согласия, ручные скачивания весов или новую библиотеку моделей.

## Реализация и совместимость

Обобщить существующий llama runtime через профиль Альфы/Беты без копии сервера, pipeline, редактора и плеера. Новый pipeline ID Беты; старые Kimi-работы остаются доступны для просмотра/экспорта и сохраняют прежнее происхождение. Не продолжать старую работу новой моделью и не запускать автоматически старый тяжёлый runtime ради её открытия. Смена модели требует новой сессии; файлы старых моделей/результатов не удалять. В новых загрузках Беты Kimi, Florence и отдельный редактор ядра не участвуют.

Обновить карточку режима, подтверждение комплекта, подписи скачивания/готовности, RU/EN, рекомендации железа. Загрузка и прогрев используют ComponentLicenseGate. Прежние согласия и установленные модели сохраняются. Состояние прогрева/речи разделяется по профилю модели.
