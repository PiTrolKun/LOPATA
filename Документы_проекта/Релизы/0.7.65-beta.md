# ЛОПАТА 0.7.65-beta

Коллекция созданных работ в Проводнике Windows: документы, изображения, музыка, видео и проекты доступны в одном разделе. Файлы остаются в своих папках; группировка по типу или сценарию.

Интеграция включена по умолчанию после установки. Основную ЛОПАТУ можно закрыть: поиск и восстановление обеспечивает отдельный фоновый компонент. Явное отключение сохраняется при обновлении. Расширены метки происхождения и журнал успешных экспортов, сохранение известных моделей и LoRA.

Поиск зависит от доступных папок и индекса Windows. Переносимость редких форматов зависит от сохранения метаданных/NTFS-потока; без них локальная квитанция не переносится на другой ПК. Проверена Windows 11 x64; ARM64 физически не испытан. Установщик на чистом ПК не испытывался; полный установщик не пересобирался.
