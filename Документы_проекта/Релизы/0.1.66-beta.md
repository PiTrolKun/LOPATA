# ЛОПАТА / LOPATA 0.1.66-beta

- Групповое литературное описание изображений доступно в Альфе, Бете и Гамме. Каждое изображение анализируется независимо; можно получить общий DOCX с оглавлением или отдельные Markdown-файлы.
- Добавлены сохранение промежуточных материалов, продолжение работы, автоматические повторы и отчёт о завершении.
- Улучшен интерфейс группового сценария: общая история, перетаскивание порядка изображений, удаление из списка и понятные переходы между шагами.
- Для оформления результатов Гаммы выбран средний уровень рассуждений; при таймауте пары описаний обработка разделяется на отдельные запросы.
- Исправлена автоматическая проверка обновлений при запуске программы.

Пользовательские проверки обоих форматов успешно завершены. Языковые и фактические ошибки модели возможны; результаты следует просматривать. Длительные очереди на любом оборудовании не гарантируются.

[Замеры времени и памяти моделей на тестовом ПК](https://github.com/PiTrolKun/LOPATA/blob/main/Документы_проекта/ЗАМЕРЫ_ГРУППОВОГО_АНАЛИЗА.md). На другом оборудовании результаты могут отличаться.

Публичная тестовая версия Beta. Скачивание и установка обновления выполняются по команде пользователя.
