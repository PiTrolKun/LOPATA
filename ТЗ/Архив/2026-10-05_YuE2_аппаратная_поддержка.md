# YuE2: общая аппаратная поддержка

05.10.2026. Основание: приложенное пользователем описание и уточнение о проверке
памяти при входе в сценарий. Пользователь разрешил закрытие и push после наших
проверок, поскольку проверить другое оборудование самостоятельно не может.

## Цель и архитектура

Автоматически выбирать GPU по его возможностям, доступной памяти и реально
поставленному backend. NVIDIA SM86/89/120 — CUDA; совместимые AMD/Intel — Vulkan.
Один GPU-комплект с динамическими CUDA/Vulkan backend и существующий CPU AVX2
комплект для безопасного резерва. Стабильные имена комплектов и ревизии заданий
сохраняются для восстановления старых заданий. GPU не выбирается по названию карты.

Первичная проверка памяти выполняется при входе в музыкальное окно; перед каждой
стадией запуска она повторяется. Считать требования групп AR и NAR/VAE отдельно,
учитывать сохраняющийся KV, контекст, длительность и запас вычислительных буферов.
Оценка не выдаётся за точное измерение. Изучить сокращение KV без потери бюджета
задания; частичный offload не придумывать, если upstream его не поддерживает.

Обычный UI: «Видеокарта» / «Процессор», при fallback — человеческая причина.
Техническое устройство/backend и оценка памяти — в журнале. CPU используется
при объективной невозможности GPU, включая нехватку памяти и отказ инициализации.
Ошибки файлов, лицензий, контекста и отмена не превращаются в CPU-повтор.

## Обязательные проверки и доставка

- Виртуальные NVIDIA SM86/89/120, AMD/Intel Vulkan, нехватка памяти, старый драйвер,
  отсутствие GPU, отказ GPU с корректным CPU fallback.
- Настоящие CUDA и Vulkan на доступной RTX 4090: план, проверенный WAV, отмена.
  Другие физические карты остаются непроверенными.
- Сохранить seed, задания, SHA/manifest, ComponentLicenseGate,
  OwnedProcessRegistry, общий фоновый режим, паузу/восстановление и публикацию WAV.
- Закреплённые native-сборки и воспроизводимый рецепт; исходные лицензии;
  обновить исследования, реестр, руководство, RU/EN, release notes.
- Restore/build/test, safe-start, UTF-8; подписанное файловое обновление после
  scoped commit/push. Полный установщик без новой команды не пересобирать.

Закрытие допускается после выполнения этих проверок и доставки, с отдельным
отчётом о размере обновления и границах реально проверенного оборудования.
