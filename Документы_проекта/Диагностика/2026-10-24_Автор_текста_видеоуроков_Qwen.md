# Qwen/Ridge: первый стенд подготовки текста для озвучивания

Дата: 24.10.2026, Asia/Novosibirsk. Статус: исследовательский результат,
не приёмка будущего видеоредактора и не выбор модели для всех видов видео.

## Вывод

Существующая Qwen3.8-27B-Ridge пригодна как первый кандидат для разбора
навигационного скринкаста и подготовки русского черновика. В проверенной
записи распознаны все семь состояний / шесть переходов. Модель отличила
готовность компонентов и картинки-примеры от новой генерации SVG.

Практичным оказался краткий режим без рассуждения с разделением ролей:
зрительный разбор → интервалы, назначенные host → текст модели для этих интервалов.
Самостоятельное распределение времени моделью давало перегруженные реплики
или сдвиг описания относительно экрана. Финальный текст остаётся черновиком:
например, вступительное «Открываем мастерскую» в записи соответствует уже
открытой программе, а не показанному запуску приложения.

## Материал и способ подачи

- [Запись](../../Тесты/VideoNarration_20261024/lopata-svg-navigation-32s.mp4):
  32 секунды, 1920×1048, 8 кадров/с, без звука и указателя мыши.
- SHA256: `9F0B0EB099AA8499A5102F8B58718CF17B23D7244D73E84E8A6F10057E625A8F`.
- Из самого MP4 извлечены 17 JPEG 1280×698: 0, 2, …, 30 и 31,875 секунды.
- Первый проход получает нейтральный запрос, изображения и их времена.
  Имя файла, UIA-ID, журнал действий и правильная последовательность не передаются.
- Второй проход получает исходный ответ первого без ручной правки фактов.
  Внешние документы, TTS и автоматический монтаж не использовались.
- Модель: `empero-ai/Qwen3.8-27B-Ridge-GGUF`, 3.7 bpw, ревизия
  `486faa5f2032ff99bdc8993ade1b8fff13d1464c`, BF16-проектор.
- Исполнитель: существующий OmniLlamaRuntimeService/Gamma; набор 002,
  `b11669-lopata1`, ревизия `620d2225cc436ab0b001e3200e590e3b286ef9ab`,
  выбран Vulkan0. Контекст 32768, один слот, без отдельного ограничения ответа.

Это последовательность изображений в multimodal chat API, не нативный MP4-вход.
Формат image_url сверялся с [документацией llama.cpp](https://github.com/ggml-org/llama.cpp/blob/master/tools/server/README.md);
фактическая совместимость подтверждена установленным исполнителем.

### Ошибка первоначального стенда

Вложенный JSON наблюдений сначала сериализовался с буквальными кодами Unicode
внутри пользовательского сообщения. Это ошибка подачи данных в стенде.
После исправления модель получает обычный русский текст; на сопоставимом
текстовом входе число токенов уменьшилось с 6366 до 910. Время генерации
в отдельных прогонах различалось; ускорение от одной этой правки не доказано.
Первый остановленный авторский проход не использовать как чистое измерение
качества или скорости модели без этого замечания.

Начальный запуск 12:29:10 не дошёл до инференса из-за отсутствия JSON-каталогов
Tools в отдельном test-host. Копирование каталогов добавлено в проект стенда.
Это дефект подготовки host, не отказ модели. Приложение не изменялось.

## Сверка событий

Сопоставление выполняет отдельный offline-проверяющий скрипт, который не
вызывает модель и не передаёт ей эталон. Интервалы смены экранов ограничены
шагом выборки; UIA-журнал отражает время команды, а не точный кадр её отрисовки.

| Переход | Команда в эталоне | Первый новый экран по ответу модели |
|---|---:|---:|
| В «Создание» | 3,0 с | 4,0 с |
| В SVG-сценарий | 8,0 с | 10,0 с |
| К подготовке выбранной модели | 15,0 с | 16,0 с |
| Назад к карточке SVG | 23,0 с | 24,0 с |
| Назад в «Создание» | 28,0 с | 30,0 с |
| Назад на начало работы | 31,0 с | 31,875 с |

Порядок верный, расхождение с командами не более двух секунд. В кратком
наблюдении один экран получил start=end=30,0, а между некоторыми интервалами
были промежутки. Это не готовые монтажные интервалы. Стенд использует начала
последовательных состояний как приблизительные границы; последнее состояние
слишком короткое для речи и оставлено без реплики. Эта нормализация не делает
границы точными: для мелких действий потребуется более плотный разбор.

## Что пока не подтверждено

Один простой навигационный пример не проверяет сложный урок, реальное изменение
настроек, ошибки выполнения, понимание игр, длинную запись, звук и объяснение
внутреннего назначения функций. Разбор не гарантирует отсутствия выдумок
на другом материале. Текст требует просмотра автором; длительность речи
не измерялась, TTS не запускался. 65 проверок не являются пользовательской приёмкой
или оценкой качества на независимой коллекции роликов.

Следующий содержательный тест — реальная операция с видимым результатом и
коротким авторским заданием/соответствующей документацией. Это рекомендация,
а не автоматически начатый новый прогон.
