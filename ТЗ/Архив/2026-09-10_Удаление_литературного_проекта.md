## Поведение

- В списках выбора проекта и активного проекта появляется кнопка удаления у каждой строки.
- Диалог называет проект и абсолютный путь, предлагает сохранить файлы (убрать только из списка), удалить всю папку проекта с файлами или отменить.
- При удалении активного проекта сбрасывается активный выбор. Список и навигация обновляются после успешной операции.
- Полное удаление охватывает главы, черновики, резервные копии, настройки и копии материалов внутри папки проекта. Исходники вне папки, другие проекты и общие модели/runtime не затрагиваются.
- Проверяются актуальная запись индекса, ID project.json, абсолютный путь, отсутствие ссылок/reparse points и других зарегистрированных проектов внутри удаляемого дерева. Корень диска и каталог, содержащий индекс проектов, удалять нельзя.
- При ошибке индекс не удаляется; UI сообщает, что часть файлов могла быть удалена, и показывает путь. Отсутствующую папку можно убрать из списка. Это не обещание транзакционного восстановления удалённых файлов после аппаратного сбоя.
- Действие доступно из списка проектов после выхода из редактора с существующей проверкой несохранённых изменений. Очистка общих коллекций RAG появится при их подключении: сейчас проектных коллекций нет.
