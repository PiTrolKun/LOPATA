# Создание литературного проекта

Дата: 2026-09-08. Статус: выполнено и принято пользователем 2026-09-08 в 0.1.71-dev; закрыто. Основание: согласование полей и команда пользователя создать ТЗ и реализовать.

## Результат

Кнопка «Начать новый проект» открывает следующую страницу внутри основного окна. Все блоки формы расположены последовательно в общей прокрутке, без вкладок. Кнопка создания находится после последнего блока внутри прокрутки. Проект сохраняется локально и появляется в общем списке. Редактор и ИИ пока не запускаются.

## Поля

- Папка хранения и отдельное название проекта. Рабочее решение: внутри выбранной папки создаётся папка с этим названием и паспорт project.json; чужие существующие папки не перезаписываются.
- Название произведения, по умолчанию «Без названия»; имя/псевдоним автора.
- Язык автоматически из языка программы на момент создания, без отдельного выбора.
- Форма: рассказ, повесть, роман, сценарий, свободная форма. При выборе краткие понятные примеры.
- Один или несколько жанров, свободное уточнение. Для ориентира ИИ требуется хотя бы выбранный или вписанный жанр.
- Краткий замысел; «Что должно быть в произведении» и «Чего следует избегать». Не использовать слово «промпт» в форме.
- Тип: самостоятельное произведение или на основе существующего мира. Во втором случае первоисточник и добавление/удаление локальных материалов. Пока только сохранение копий, без разбора, загрузок и индексации для ИИ.
- Культурные и философские ориентиры: список стран/территорий с галочками, множественный выбор, ввод прокручивает к совпадению без снятия галочек; отдельное свободное поле для эпох, идей и собственных ориентиров. Это творческие ориентиры, не приписывание единых взглядов всем персонажам.

## Поведение

Обязательны папка и название проекта, жанр. Остальные творческие поля можно доработать позже. Название произведения при пустом вводе получает значение по умолчанию. Изменение данных позднее предусмотрено форматом, отдельный экран настроек сейчас не создаётся.

Паспорт содержит стабильный ID, версию формата и дату создания. Индекс известных проектов и выбранная звёздочка сохраняются в данных программы. Новый проект не назначается активным автоматически: это отдельный выбор пользователя. Список читает только зарегистрированные проекты, не сканирует диски. Ошибки чтения/сохранения показываются, повреждённый индекс не перезаписывается пустым. Отмена формы ничего не создаёт. При копировании материалов UI остаётся отзывчивым, повторное создание блокируется; исходники не изменяются. Совпадающие имена вложений сохраняются раздельно.

## Проверки

Сохранение/повторное чтение полей, русский текст и язык; защита от перезаписи и недопустимых имён; копии материалов; общий список и звёздочка после перезапуска. Проверка формы RU/EN и двух тем, примеров, чекбоксов и поиска стран. Build/test, UTF-8 scanner, штатный запуск. Целевой ПК сценария — уровень Беты (32 ГБ RAM, 10–16 ГБ VRAM), моделей в этом шаге нет.

## Границы

Без генерации, редактора, RAG, обработки первоисточников и реального экспорта. Без публикаций и установщика по действующему указанию пользователя. Приёмка и закрытие после проверки пользователя. Backup: _backups/literary_creation_20260908.

Страны/территории берутся из встроенного списка культур .NET, подписи RU/EN встроены в словари; подготовлены через штатный Intl.DisplayNames Node, без новой runtime-зависимости. Поиск прокручивает список, галочки независимы. Материалы скрыты для самостоятельного произведения; удаление из формы не удаляет исходный файл.
