# Проверки выпуска ЛОПАТЫ 0.9.0-beta

22 ноября 2026 года. ТЗ фонового инспектора принято.

На первой физической серии Black Desert в фоне заметно замедляла Krea 2 Turbo на RTX 4090. Все восемь заданий завершились с сохранением изображения. Ошибок выделения видеопамяти в этой серии не возникло.

Для встроенного инспектора проверены запись этапов реальной генерации Krea, работа после полного закрытия ЛОПАТЫ, связь с режимами аудита, один экземпляр для beta и dev и запуск задачи реальным Планировщиком по запросу. При формировании отчёта TSPulse завершил анализ сохранённых замеров, а Ядро показало объяснение в ЛОПАТЕ. Подтверждена отправка уведомления Windows. В Острове проверены оба режима, суточное окно и смена оценки.

Приёмочные проверки dev-сборки охватили 56 тестов приложения, семь тестов инспектора, 28 проверок Планировщика, семь проверок Острова и 107 тестов обновлятора. Один дополнительный тест предпросмотра Qwen пропущен, поскольку не задана папка модели. Повторный вход в Windows и длинная серия замеров точности предупреждений под игровой нагрузкой остаются вне проверенного объёма.
