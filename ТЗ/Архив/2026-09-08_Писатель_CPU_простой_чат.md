# ИИ1 Писатель: CPU и простой чат

Статус: выполнено и принято пользователем. Дата: 2026-09-08.

Цель — проверить запуск установленной модели Альфы Qwen3.8-4B-Distill Q5_K_M на CPU, затем подключить простой чат Писателя. Снять фон текущего ПК и отдельно потребление процесса модели. Целевой класс — 32 ГБ RAM, GPU резервируется для будущего ИИ2. Короткий тест не доказывает предельную нагрузку длинной беседы или двух моделей одновременно.

Использовать зарегистрированный файл Альфы и существующий llama.cpp. Без новых загрузок, лицензионных экранов и публикаций по указанию пользователя. Отдельный процесс, device none, gpu-layers 0, offload операций отключён; проектор изображений не нужен. Контекст 32768, один слот, до 8 CPU потоков, резерв ответа и проверка размера запроса. Измерить фон, запуск, короткий ответ, RAM процесса и CPU; GPU проверить по параметрам/логам и общему фону.

После успешного запуска: активный левый чат, отправка/остановка, поток ответа, собственная история текущего чата. Без паспорта проекта, общей памяти, изменения главы и ИИ2. Чат на этом этапе только в текущем открытом рабочем экране, без дискового сохранения; это явно указать. При уходе отменять работу и освобождать собственный процесс; чужие процессы не затрагивать. Ошибки и заполнение контекста показывать понятно, не очищать историю автоматически. Очищение чата только явной кнопкой.

Модули runtime и чата отдельные. RU/EN, сборка, имеющиеся тесты, проверки протокола/жизненного цикла и изолированного UI, UTF-8 scanner, штатный запуск. Backup: _backups/literary_writer_cpu_20260908. Закрытие после пользовательской приёмки.

Проверки завершения этапа ИИ1 (2026-09-08): финальный профиль --cache-ram 0 проверен через реальный сервис — ответ и отмена успешны, WS с дочерним процессом ~4,35 ГиБ. Изолированный WPF/реальный runtime стенд: 8 проверок; 447 .NET тестов прошли; restore/build без предупреждений и ошибок, UTF-8 scanner чист; штатный start 0.1.73-dev выполнен. Отчёт: Тесты/Literary_CPU_20260908/README.md. Код и установщик не публиковались; ТЗ принято пользователем.
