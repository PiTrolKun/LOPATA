# Проверка RU/EN библиотек и утилиты 0.7.71-dev

Дата: 10.11.2026. Библиотеки технически пригодны для следующего этапа подключения голосовых уведомлений. Автоматическая проверка охватывает все файлы; повторное прослушивание произношения всех реплик в этот проход не проводилось. Пользовательские проекты, выбранные дубли и исходные ZIP не изменялись.

## Библиотеки

| Длительности, с | 0,7875–11,8875 | 0,92–14,52 |

Оба архива: Opus, 64 кбит/с, mono; ZIP содержит 1529 аудиофайлов и manifest.json. Для будущего resolver ключ связи двух языков — ClipId `voice.…`; RowId и TakeId описывают конкретный проект/дубль и не заменяют этот общий ID.

Проверено целиком:

- Все 1529 ClipId реестра есть в каждом языке ровно один раз. Исходные тексты совпадают с соответствующим языком реестра; произносимые тексты учитывают ручные правки.
- В каждой строке проекта один выбранный актуальный дубль и подтверждение. Manifest указывает именно этот TakeId; неоднозначных/устаревших выбранных записей нет.
- SHA-256 всех 3246 сохранённых WAV, включая 188 невыбранных RU-дублей, совпали с проектами. SHA-256 всех 3058 архивных аудиофайлов совпали с манифестами; ZIP CRC проверяется при полном чтении.
- Встроенные LOPATA_SPEECH_ASSET совпадают с проектом/manifest по ClipId, RowId, TakeId, языку, исходному/произносимому текстам, голосу и фактическим моделям. LOPATA_PROVENANCE имеет recorded history и тот же состав моделей/ревизий.
- Структура Ogg/Opus, mono и длительности соответствуют исходникам. Все 3058 экспортированных файлов полностью декодированы установленным аудиокомплектом без ошибок.
- Пустых/нулевых PCM не найдено. Сигнальный тест исходников не обнаружил существенного клиппинга (порог отчёта — более 0,1% отсчётов на границе PCM16). Минимальный RMS: RU −22,33, EN −22,93 дБFS. Разница медиан языков около 1,4 дБ; резкого разрыва громкости между наборами нет. Это метрики сигнала, а не полная оценка произношения или воспринимаемой громкости.
- Хеши исходных проектов и ZIP до/после самого аудита совпали. Во время проверки синтез новых пользовательских записей не выполнялся.

При подключении следует учитывать реплики до 12–15 секунд в очереди уведомлений и уровнях подробности. Набор является широким каталогом: наличие записи не означает, что нужно озвучивать каждое промежуточное событие.

Подробные результаты — `result.json`, `ru-signals.json`, `en-signals.json`. Извлечённые проверочные копии Opus — `audio/{ru,en}`. Утилита проверки — `_tmp/speech-assets-exclusive/audit_libraries.py`, лог `audit-verified.log`. Первый диагностический запуск использовал отсутствующий в минимальном FFmpeg raw-PCM muxer; скрипт переключён на поддерживаемый WAV-вывод, после чего проверены все файлы. Исходный отказ сохранён как `audit-attempt1-unsupported-raw-pcm.txt` и не является ошибкой библиотеки.

## Изменения утилиты

Выбор дублей теперь одиночный: RadioButton и SelectTake снимают прежнюю отметку, не удаляя записи. Confirm/F1/ZIP принимают ровно один выбранный дубль с актуальным текстом. Для старой неоднозначной записи UI показывает отсутствие однозначного выбора и ждёт явного нажатия; автоматического выбора за пользователя нет. Смена варианта снимает подтверждение; повторный выбор того же единственного варианта его сохраняет.

Добавлена кнопка «Примеры RU / EN», открывающая Examples/SpeechAssets в Проводнике. В папке обычные файлы:

- `LOPATA_уведомления_и_статусы_ru.md`;
- `LOPATA_Notifications_and_Statuses_en.md`;
- `README_ru.md`;
- `README_en.md`.

README описывают требования к модели/UTF-8/Markdown, правила списка, правки произношения, одиночный выбор и подтверждение, проекты/продолжение, форматы и условия экспорта. Markdown-примеры скопированы побайтно из исходных списков. Пользовательские аудиоархивы в эту папку не копировались.

AIHub.csproj копирует все четыре файла в output и publish. GetCopyToPublishDirectoryItems подтвердил их TargetPath/PreserveNewest; Inno Setup LOPATA.iss:88 рекурсивно берёт publish payload, поэтому они входят в состав будущей установки. Полный установщик отдельно не пересобирался. Рабочая кнопка проверена: Проводник открыл фактический каталог output; файлы доступны для обычного копирования.

## Условия моделей

Техническая пригодность не является отдельным разрешением на публичное распространение. Для последующего поставочного аудиокомплекта сохранять фактические модели/ревизии и проверять условия конкретного использования. Авторы [Silero](https://github.com/snakers4/silero-models#licence) указывают некоммерческую лицензию моделей; из одной этой записи не делался вывод, что готовое аудио автоматически получает лицензию кода ЛОПАТЫ. В [лицензии KittenTTS 2](https://huggingface.co/KittenML/kitten-tts-2/blob/main/LICENSE.md) результат модели исключён из определения Derivative Works; условия использования самой модели рассматриваются отдельно. Аудиозаписи не включались в установку в этом проходе — пользователь запросил исходные Markdown-примеры.
