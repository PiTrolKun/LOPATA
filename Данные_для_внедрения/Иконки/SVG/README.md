# Значок типа файла SVG для ЛОПАТЫ

Дата подготовки: 23.10.2026.
Назначение: отдельный значок файлов `.svg` для будущего просмотрщика / редактора.
Состояние: комплект подготовлен; программное подключение и регистрация Windows
относятся к дальнейшей реализации рабочего ТЗ.

- `SvgFileIcon.svg` — точная копия предоставленного пользователем SVG, без правки
  рисунка, описания автора и сведений о генерации. Холст `viewBox="0 0 64 64"`.
- `SvgFileIcon.ico` — один ICO с прозрачными изображениями 16, 20, 24, 32, 40,
  48, 64, 96, 128 и 256 пикселей. Размер файла: 39400 байт.
- `SvgFileIcon-256.png` — прозрачная копия для обычного просмотра.
- `sizes/` — PNG каждого размера, непосредственно отрисованные из SVG.
- `Preview-light-dark.png` — сравнение размеров на светлом и тёмном фоне.

Исходная метка автора: `Author: Петр`. SVG содержит происхождение генерации:
LOPATA 0.6.10-dev, Qwen3.8-27B-Ridge 3.7 bpw,
ревизия `486faa5f2032ff99bdc8993ade1b8fff13d1464c`, llama.cpp Vulkan из набора 002.
Новой генерации при подготовке значка не было. Каждый размер отрисован resvg
0.47.0 из векторного исходника; рисунок вручную не изменялся.

SHA256 исходного SVG:
`8e4de1dab14d39f3c313e6ccb455eabdc20cf323b0423672b181a0d87f35fa9e`.
Созданные PNG и PNG-кадры ICO содержат встроенные сведения о подготовке,
исходном SHA256 и фактической истории модели; абсолютных локальных путей нет.

Проверено: независимое чтение всех размеров ICO через Pillow, совпадение пикселей
с отрисованными PNG, прозрачность и встроенные метаданные. Через Windows
`LoadImageW` каждый из 10 размеров загружен с запрошенной шириной и высотой.
Просмотрено сравнение на двух фонах; в 16×16 мелкие символы закономерно не читаются,
сохраняются силуэт монитора, листа и цветовой рисунок.
