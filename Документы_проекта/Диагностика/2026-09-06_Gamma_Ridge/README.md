## Что подключено

Общий runtime llama.cpp b9442 с профилем Gamma, без копии интерфейса/пайплайна. Анализ и составление текста одной моделью; стандартные/кастомные промпты, история/экспорт, Kokoro, дождь, повторы и защита 95%. Профиль задаёт BF16 проектора и temperature 1.0; значения Альфы/Беты .6/F16 прежние. Thinking включён, top_p .95, top_k 20, min_p 0; серверный presence_penalty по умолчанию 0. MTP/speculative decoding отдельно не включается.

Новый artifact ID, каталог, pipeline ID и происхождение в session/diagnostics. Старые работы Гаммы остаются для просмотра/экспорта без прогрева прежней модели и продолжения новой. Старые файлы не удаляются. Двухфайловый комплект использует штатные согласие/многопоточность/resume/SHA-256. Apache-2.0: ссылка на [исходный LICENSE](https://huggingface.co/Qwen/Qwen3.8-27B/blob/1d4bf0f2ff6012fd82039f2fa52739d0dd7c60c0/LICENSE) и дата проверки внесены в каталог.
