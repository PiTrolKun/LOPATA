# Фоновый ИИ-инспектор ПК

Для сборки ЛОПАТЫ подготовить пакет анализа TSPulse командой `py -3.12 Инструменты/Inspector/prepare-tspulse.py` на Windows x64. Веса IBM и дополнительные Python wheels закреплены по SHA-256. Ключ `--model-cache` позволяет использовать уже скачанные проверенные веса.

Архив и его манифест появляются в `Runtime/Inspector` и входят в обычную поставку. При запросе отчёта архив разворачивается в локальный профиль и проверяется через общий аудит компонентов. Анализ выполняет общая CPU-среда ЛОПАТЫ `py312-torch210-cpu-transformers530-1`, которую подготавливает штатная проверка компонентов. Сам инспектор собирает показания без запуска Python. Лицензии модели и дополнительных зависимостей находятся внутри пакета.

Разработческая сборка проекта `LOPATA.PcInspector` создаёт `LOPATA Controller PC.exe`. Для физических проверок использовать отдельный каталог профиля. Запуск по расписанию и прямой запуск используют один профиль и один экземпляр процесса.
