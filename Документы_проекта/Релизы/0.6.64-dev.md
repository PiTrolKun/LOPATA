# 0.6.64-dev — первый исполнитель MiniMax H3

На экране H3 работает «Создать видео»: готовые фрагменты или цельный ролик,
предпросмотр, экспорт MP4 и передача в видеоредактор. Контекст продолжения
сохраняется вместе с проектом. Первый запуск готовит отдельную закреплённую
среду с общей проверкой компонентов и лицензий. Доступны пауза и остановка.

Базовый путь: текст/изображения, новый фрагмент и Extend. Для первого теста
оставьте PyTorch, выключите ускорения/LoRA и повышение разрешения. Остальные
ускорения и сложные операции подключаются отдельно; upscale экспериментален.

Физический контроль на RTX 4090: три прохода с двумя продолжениями,
12-секундный H.264/AAC, 416×256, 24 FPS. Проверены: остановка после первого фрагмента, открытие архива и два Extend;
отдельная генерация по изображению (5,167 с); upscale/refine до 640×416 с
сохранением звука и 12 с (окно 1 с / перекрытие 0,25, два шага refinement).
Результат открыт настоящим WPF MediaElement, модельная история при импорте
в видеоредактор сохранена. 72 профильных PASS + 1 проверка реального плеера/
импорта + 19 регрессий редактора; отдельные opt-in проверки без запроса
пользовательских материалов пропущены. Независимые FFprobe и кадры в
`_tmp/h3-generation/physical/`. Python syntax/UTF-8/RU-EN проверены.

Другие GPU и длительная генерация не объявляются проверенными. Подготовка
проекта и существующие пользовательские архивы сохранены. Установщик не
пересобирался; это локальная dev-сборка, публикации не было.

Итог: restore успешен; основная сборка 0 ошибок / 0 предупреждений.
Штатный safe-start открыл ЛОПАТА 0.6.64-dev, PID 2280. Дополнительные
регрессии импорта и редактора: 19 PASS (включая 7 проверок model-history tags).
92 проверки в профильных группах прошли; opt-in пользовательские прогоны
без отдельного запроса пропущены. Установщик не пересобирался.

Финальная проверка интерфейса: кнопка «Создать видео» закреплена под
прокручиваемыми настройками; 11 повторных UI-проверок прошли, включая
открытие настоящего результата. После этой правки штатный стартер снова
собрал приложение без ошибок и предупреждений и открыл 0.6.64-dev
(PID 3696). Программа оставлена открытой для пользовательского испытания.
