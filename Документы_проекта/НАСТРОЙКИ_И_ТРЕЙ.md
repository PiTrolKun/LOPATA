# Настройки и системный трей ЛОПАТЫ

База описания — принятый режим 0.2.55-dev. Ниже сначала описана эта версия;
изменения общего фонового режима 01.10.2026 приведены отдельно в конце и ещё не приняты.
Настройки открываются кнопкой шестерёнки в основном окне. Изменения сохраняются автоматически; существующие значения переносятся без сброса.

Первый пункт слева — **Обновления**. Он открывает прежнее отдельное окно: можно следить за загрузкой и одновременно пользоваться программой. Повторное нажатие возвращает уже открытое окно. Направления обновлений и время установки настраиваются в нём.

Остальные разделы: Общие, Интерфейс, Голос, ИИ и модели, Компоненты, Загрузки, Утилиты, Диагностика, О программе. При первом входе показываются Общие; впоследствии восстанавливается последний раздел. Поле поиска работает локально на выбранном языке. Нажатие результата открывает нужную группу и подводит к настройке. Для возврата к обычному виду очистите поле.

В Общих можно выбрать действие крестика главного окна:

- **Спрашивать каждый раз** — по умолчанию крестик открывает вопрос о полном выходе или сворачивании в трей.
- **Закрывать программу** — сразу перейти к штатному завершению.
- **Сворачивать в трей** — скрыть главное окно, сохранив текущую работу. Загруженные модели продолжают занимать память, выполняющиеся задачи не останавливаются.

В вопросе есть выключенная галочка **Запомнить выбор**. Без неё действие выполняется один раз, настройка не меняется. С галочкой сохраняется выбранный режим в Общих. Крестик вопроса оставляет приложение открытым и ничего не сохраняет. Чтобы вернуть вопрос, выберите **Спрашивать каждый раз**. При недоступном значке трея кнопка скрытия недоступна.

Рядом с часами Windows появляется один значок ЛОПАТЫ. Двойной щелчок возвращает главное окно. Меню значка содержит открытие приложения, настройки, обновления и полный выход. Обычная кнопка сворачивания продолжает сворачивать окно на панель задач.

Открытое окно обновлений остаётся видимым при скрытии главного. Его крестик закрывает только это окно. **Выход** в меню трея и завершение для установки обновления проходят через прежние проверки сохранения и незавершённой работы. Если редактор не разрешил выход, приложение остаётся доступным; установка не запускается. Следующая сессия всегда начинается с видимого окна.

Если значок создать не удалось, скрытие не выполняется: обычный выход остаётся доступным. Пока утилиты и запуск вместе с Windows только обозначены как будущие возможности. Программа не меняет системный автозапуск, не устанавливает службу и не добавляет новые уведомления.

Настройки поведения хранятся в общем settings.json в объекте `behavior`: `askBeforeClosing`, `closeToTray`, `lastSettingsSection` и резервный `launchWithWindows`. Последний сейчас не исполняется. При отсутствии `askBeforeClosing` используется вопрос; прежнее значение `closeToTray` сохраняется. Старые файлы без объекта открывают раздел Общие. Навигация и поиск размещены в отдельных Controls; значок и условия скрытия — в отдельных Services. Настройки используют прежние экземпляры полей и обработчики.

## Общий фоновый режим — в реализации, 01.10.2026

Новое обязательное [правило работы](../Инструкции/AGENTS.md#15-общий-фоновый-режим-ии)
охватывает все сценарии и модельные окна. Их фактическое подключение отмечается
в [реестре операций](ФОНОВЫЕ_ОПЕРАЦИИ.md); пока подключены Studio и подготовка памяти
открытого литературного проекта, полное покрытие ещё не завершено.

Код текущего этапа добавляет рабочие параметры `launchWithWindows` и
`autoResumeBackgroundOperation` (автопродолжение по умолчанию включено),
единую индикацию непросмотренного долгого результата/обновления, паузу,
контрольную точку и 60-секундный отсчёт восстановления. Ручной запуск и автозапуск
должны отличаться только видимостью окна; прежнее утверждение о всегда видимой
следующей сессии относится к принятой базе 0.2.55, не к новому контракту.

В скрытом режиме добавлено расписание автопроверки обоих направлений раз в 10 минут;
выключенная автопроверка его запрещает. Видимая Бета сохраняет 30 минут.
Настройки из трея должны возвращать в прежнюю рабочую страницу через «Назад».
Установленная копия управляет собственной регистрацией автозапуска; dev-копия
не меняет её. Первая установка подготовлена к вопросу, повторная сохраняет выбор.

Общая приёмка, сквозные проверки всех путей, реальный скрытый запуск и выпуск
не завершены. Настоящая регистрация пользователя в Windows в ходе тестов не менялась.
Полный установщик не пересобирался; VERSION остаётся 0.2.57-dev до закрытия ТЗ.

## Принятый этап 0.3.0 — 01.10.2026

Общий фон, трей и автозапуск приняты пользователем. VERSION 0.3.0-dev; [полный/сетевой публичный 0.3.0-beta и подписанный патч опубликованы](https://github.com/PiTrolKun/LOPATA/releases/tag/v0.3.0-beta). Вспомогательные окна сохраняют простое локальное поведение, общий адаптер для них не требуется. Предшествующие записи описывают ход разработки, не текущее состояние приёмки.

На отдельном UPDATE_STAND проверены скрытый запуск, защита от второго экземпляра, восстановление исходного окна ручным запуском, штатный выход; полная/повторная/сетевая установка, восстановление регистрации и удаление с сохранением данных. 933/933 теста. Настоящая запись пользователя в Windows не менялась; перезагрузка Windows и реальное GPU-освобождение не проверялись стендом. [Протокол](Релизы/0.3.0-beta_проверки.md); фактические модельные подключения и ограничения — в реестре ФОНОВЫЕ_ОПЕРАЦИИ.md.
