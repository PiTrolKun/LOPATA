# LOPATA 0.7.77-beta

Новый сценарий «Создание → Vibe Coding → 1С» помогает пользователю с небольшим опытом разбирать и править код: исходник, задача и предложение модели связаны в одном проекте.

- Проекты, сворачиваемая панель, редактор с подсветкой, сравнение и история вариантов.
- Локальные текстовые модели из общей библиотеки и настоящий статический анализ BSL Language Server. Компонент подготавливается отдельно штатным способом.
- Исходники, вставленные или импортированные извне, доступны только для чтения. Сценарий создаёт свои файлы и применяет правки только к ним в пределах проекта.
- Небольшие учебные примеры, подсказки, разбор сообщения об ошибке и справка для самостоятельной доработки сценария.
- Исправлены тёмная тема окна моделей, создание проекта и сброс прокрутки при ручной проверке. Результат проверки показывается явно.

Это открытая рабочая заготовка, не замена Конфигуратора/EDT. Ответ модели требует просмотра; статическая проверка не означает выполнения и корректности в конкретной базе 1С. Интеграция с реальной платформой/базой и выполнение OneScript в этом выпуске отсутствуют.

Доставка: подписанное файловое обновление. Модели и BSL-компонент в него не включены и загружаются отдельно; полный установщик не пересобирался. Настройки, проекты и пользовательские файлы не входят в пакет.
