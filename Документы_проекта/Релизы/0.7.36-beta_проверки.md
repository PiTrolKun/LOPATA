## Границы проверки

Полная аппаратная матрица и физическое прерывание именно нового запроса босса
посреди inference не выполнялись. Checkpoint/повтор/удаление/terminal failure
и освобождение подтверждены профильными проверками. Длительное разнообразие
и художественная оценка остаются исследовательскими свойствами игры.
Полный установщик не пересобирается; готовое обновление не устанавливается
на рабочую пользовательскую копию в рамках выпуска.

## Публикация

Перед публикацией выявлены и устранены два различия подготовки:

- В свежем payload восстановлены 166 неизменённых текстовых файлов прежнего
  выпуска. Для 165 отличались только LF/CRLF; для одного официального
  `song-clip-glitch-libraries.txt` применён явный whitelist CRCRLF. Старые
  байты взяты из ZIP подписанного манифеста и проверены по SHA-256.
  Семь ожидаемых содержательных изменений не подменялись старой версией.
- Git нормализовал 116 из 714 файлов новой библиотеки, для которых записаны
  точные SHA-256. В `.gitattributes` закреплены исходные байты библиотеки,
  игровых лицензий и исходной идеи. Физические файлы и код игры не менялись.
  Все 714 файлов отдельно проверены по размеру/SHA-256 после чистой выгрузки
  из Git index: PASS, различий нет. Исходники отправлены дополнительным
