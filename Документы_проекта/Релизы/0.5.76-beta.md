# ЛОПАТА 0.5.76-beta

Добавлено создание простого музыкального клипа с ретромонитором, матричным
дождём, волнами символов и проекцией текста песни.

- Открытие из музыкального сценария с выбором готового трека сессии либо через
  «Утилиты → Работа с видео → Создание простого клипа» с выбором аудиофайла.
- Предпросмотр, воспроизведение, перемотка и MP4 720p/1080p. Сила эффектов,
  размер текста, палитра, слова песни и дополнительный текст дождя; сохранение
  настроек и возврат к исходному виду.
- Наследование совместимых текстовых метаданных музыки. Происхождение видео
  записывается отдельно, исходный аудиофайл не изменяется.
- Общий фоновый экспорт: пауза, сохранение анализа, продолжение и открытие результата.

Без подходящей разметки строк работает музыкальный визуализатор; новые времена
не выдумываются. Незавершённое кодирование после паузы начинается заново,
готовый анализ используется повторно. Обложка показывается первым кадром;
выбор кадра превью зависит от видеоплощадки.

Проверены 55 целевых/смежных тестов и два длительных прогона экспорта и восстановления,
полный клип, интерфейс RU/EN и отсутствие сдвига звука в контрольных окнах.
Другие видеокарты физически не испытывались. Пользователь принял результат.
Это файловое обновление; полный и миниустановщик не пересобирались.
