# Повторяющиеся ТЗ

Здесь хранятся ТЗ, которые можно снова запускать спустя время по команде пользователя.
После выполнения и приёмки очередного цикла документ остаётся в этой папке.
История прошлых циклов не стирается; текущий статус показывает ожидание нового запуска.
Повторяемость не означает расписание, фоновый мониторинг или автоматический запуск.

## Документы

- [Обновление движков моделей](2026-10-18_Обновление_движков_моделей.md) —
  stable-diffusion.cpp, YuE2 Studio, llama.cpp и повторная проверка chatllm.cpp;
  версионные наборы движков, загрузка прежних наборов через настройки,
  доставка актуального с патчем без удаления старых и без сброса ручного выбора;
  цикл 1 выполнен и принят 18.10.2026 (0.5.79-dev); ожидает повторного запуска.
  [Протокол внедрения](../../Тесты/RuntimeImplementation_20261018/README.md).

По прямому уточнению пользователя обновления этого ТЗ сначала проходят проверку
регрессий на отдельном стенде и только после допуска переносятся в живой код.
После принятого программного цикла сохраняется штатный порядок публикации
исходников и проверенного файлового обновления; сам перенос документа выпуском
не является. Подробности и журнал — в соответствующем ТЗ.

Цикл 1 опубликован в [0.5.79-beta](https://github.com/PiTrolKun/LOPATA/releases/tag/v0.5.79-beta);
подписи, 192 вложения и публичная доставка набора проверены. ТЗ остаётся здесь.
