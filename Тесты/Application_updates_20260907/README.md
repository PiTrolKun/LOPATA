SHA-256: `6fba26186f0fcb8b69e5a26ac259cd31be8264c6d6199c2fd7d43f1d042d32ee`.
Inno Setup 6.7.3, компиляция успешна. `.build.json` подтверждает чистый
исходный коммит и версию payload `0.1.53-beta`; VERSION остаётся dev.

Во временную папку `%LOCALAPPDATA%\Temp\LOPATA_update_install_20260907`
установлена 0.1.52-dev, затем поверх неё 0.1.53-beta. Установка завершилась
успешно без перезагрузки Windows. SHA-256 установленной AIHub.dll совпал
с publish; приложение отвечало с заголовком `ЛОПАТА 0.1.53-beta` и штатно
закрылось. Дополнительный контроль с процессом на 10 секунд подтвердил,
что /WAITFORPID не начинает установку до завершения процесса; итоговый код 0.
Первый замер ожидания старого приложения не засчитан: к измерению процесс
уже завершился. Это не использовано как доказательство сбоя или успеха ожидания.

Для автоматизированного теста применялся /ACCEPTLICENSES=1; рабочий updater
этот флаг не передаёт и открывает обычный лицензионный экран. До теста сделаны
backup регистрации uninstall, пользовательских JSON и записи согласия.
После теста они восстановлены. Регистрация основной установленной копии
снова указывает на исходную 0.1.44-dev в Programs\LOPATA. Основные файлы
этой копии не заменялись. Содержимое двух поставляемых backend-папок
совпало с backup, новых файлов в них нет.

Рекурсивное удаление временной тестовой установки отклонено автоматической
проверкой инструмента (`blocked by policy`, без подробной причины). Папка
оставлена. Не запускать её uninstaller: регистрация основной копии уже
восстановлена. Это остаток теста, не рабочая установка пользователя.
