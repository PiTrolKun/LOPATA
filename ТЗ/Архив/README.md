Это единственная общая архивная папка проекта (решение пользователя 14.10.2026).

Сюда переносятся завершённые ТЗ после подтверждения пользователем и исходные идеи/концепции по его указанию. Отдельный архив внутри `Данные_для_внедрения/Идеи` не создавать.
