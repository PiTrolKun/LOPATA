# Повторы и граница контекста — проверка 0.1.48-dev

Дата: 2026-09-06. Реализация по ТЗ/Архив/2026-09-06_Повторы_и_граница_контекста_Omni.md. Принято пользователем 2026-09-06.

## Поведение

Общий Omni pipeline Альфы и Гаммы повторяет неудачный этап максимум три раза. Ошибка завершённого JSON и завершённый пустой ответ допускают повтор. Успешное наблюдение не пересчитывается при повторе compose; неудачные ответы не добавляются в скрытую беседу. Сырые ответы сохраняются раздельно, версия появляется только после проверки. Отмена, сбой runtime, повреждённый поток и контекст не повторяются автоматически. Процесс сервера при неправильном формате не перезапускается.

Перед запросом применяется порог 95% действующего окна с минимальным резервом 4096 токенов для рассуждений и ответа. При достаточном запасе ответ может использовать оставшийся безопасный бюджет, а не только минимальный резерв. Если модель доходит до этого ограничения без завершения, частичный ответ не становится версией. Округление границы вниз консервативное, не более одного токена. Контекст проверяется на каждом этапе и повторе.

Для Альфы добавлены /apply-template и /tokenize с теми же messages и thinking=true, включая префикс генерации. К текстовому счётчику добавляется безопасная верхняя оценка 4096 токенов за каждое изображение, закреплённая --image-max-tokens 4096 (это прежний default Qwen3VL в b9442). Эта оценка может заблокировать длинную сессию раньше фактических 95%; она не называется точным числом визуальных токенов. Для Гаммы применяется точный размер input_ids после processor, до model.generate. История берётся из конкретного запроса, а не суммируется повторно с каждым обращением. Размер кэша RAM не является размером контекста и этой доработкой не менялся.

ContextBlocked — дополнительное необязательное bool-поле session.json; старые записи читаются с false. Блокировка сохраняется на диск. Ни версии, ни файлы, ни беседа автоматически не удаляются. В блокированной работе с готовым результатом показывается результат с доступными предпросмотром и экспортом, даже при возврате к настройкам. Новых кнопок нет; используется существующая навигация. Невозможные действия отключены, редактура приглушена, предупреждение переносится в пределах окна.

Бета имеет другой pipeline и не переводилась на общий Omni-механизм в этой задаче.
