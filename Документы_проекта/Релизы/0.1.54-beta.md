# ЛОПАТА / LOPATA 0.1.54-beta

- Добавлена компактная кнопка «?» в нижней панели, доступная на всех страницах.
- Новое окно «О программе»: профиль автора, репозиторий и доступ к проверке обновлений.
- Краткий рассказ о проекте и раскрываемое подробное описание его идей простыми словами. Тексты доступны без интернета на русском и английском, в обеих темах.

Публичная тестовая версия Beta. Обновление с 0.1.53-beta доступно через существующее окно обновлений; скачивание и установка выполняются по команде пользователя.
