## Файлы и восстановление

В проекте появляется `chapters/index.json` (версия схемы 1) и нумерованные TXT. Индекс хранит ID, числовые номера, название, завершение, активную часть и интервал. Рабочие TXT содержат только текст UTF-8. Счётчик соответствует длине строки редактора .NET, включая пробелы и CRLF; в интерфейсе только слово «Символов».

При записи сначала сбрасывается на диск временная копия, затем заменяется основной файл с `.bak`. При создании частей/переименовании `pending.json` описывает незавершённую операцию; индекс — точка фиксации. Старые имена после переименования сохраняются в `chapters/recovery` для восстановления предыдущего индекса. Незарегистрированные временные данные не включаются в экспорт. Первоначальный `working-draft.txt` остаётся резервом миграции и повторно не импортируется.

`sample.docx` — искусственный пример из стенда, не пользовательское произведение. Автоматические проверки не оценивают художественное качество, новые запросы модели и реальный внезапный сбой питания. Восстановление не обещает вернуть ещё не записанные символы. Подключение чтения файла моделями, дерево, RAG/желе, пользовательская история версий остаются отдельными этапами.

Установщик не пересобирается и не публикуется без отдельной команды. ТЗ закрыто и архивировано 2026-09-09 по подтверждению пользователя, без публикации.
