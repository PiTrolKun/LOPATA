# ACE-Step 1.5 XL Turbo 4B — первое официальное подключение

Статус: выполнено в 0.4.27-dev, принято пользователем 08.10.2026 после трёх прогонов.
Решение пользователя 08.10.2026.

## Цель

Подключить ACE-Step 1.5 XL Turbo 4B через штатный официальный исполнитель.
Первый этап — проверка обычной генерации песни, без адаптации круга настроек.
Веса пользователь устанавливает через штатную подготовку компонентов ЛОПАТЫ.

## Обязательный объём

- Официальный upstream закрепляется по версии/коммиту. Сохраняются его конвейер,
  настройки и лицензии. Не писать собственную реализацию генерации.
- Отдельные паспорт и идентичность варианта, компоненты и проверяемые загрузки.
  Вспомогательный LM является отдельным компонентом; исходный выбор — 1.7B.
- Рабочее музыкальное окно и переключение установленной модели используют общие
  проекты, тексты, историю попыток, треки, сохранение и метаданные.
- Настройки ACE хранятся отдельно от YuE; исторические проекты и задания читаются.
- Все применимые параметры штатной генерации доступны в экспертном окне по
  смысловым группам, включая строковые поля и переключатели. Неприменимые для
  XL Turbo параметры явно недоступны с объяснением, не имитируют влияние.
- Число вариантов, длительность, формат/битрейт и файлы результата остаются в
  существующих элементах. Круг и рецепты YuE к ACE не применяются: на первом
  этапе скрыты для ACE, существующее поведение YuE сохраняется.
- Пожелания переводятся в caption и lyrics по контракту ACE. Выбранные размер,
  язык и числовой темп (если задан в эксперте) передаются отдельными полями;
  явные экспертные значения приоритетнее автоматического вывода. Противоречия
  и несколько языков/размеров не разрешаются молчаливым случайным выбором.
- Автоматическое переписывание пользовательских слов выключено по умолчанию.
  Переданный запрос и фактические параметры/ответ сохраняются в журнале и файле.
- Контекст YuE не используется как мнимый лимит ACE. Проверка текста ACE следует
  реальным ограничениям его исполнителя; интерфейс не показывает ложные токены.
- Прогресс и логи поступают во время работы; отмена/пауза завершает собственный
  процесс, готовый результат не перезаписывается. Возобновление повторяет только
  незавершённый этап, без обещания продолжения из середины диффузии.
- Сеть для установки запускается только штатной пользовательской командой.
  При генерации скрытое скачивание весов запрещено.
- Аппаратный выбор следует поддержке upstream, без фиксации CUDA0; проверенное
  железо и заявленная upstream совместимость различаются.

## Границы

Не адаптировать круг и простые рецепты. Не добавлять другие варианты ACE.
Режимы cover/repaint показывать только при полной передаче исходного аудио и
интервала; для первой проверки основной режим — text2music. Обучение LoRA и
специальные задачи Base не входят в этот этап.
Не скачивать веса и не проводить музыкальные прогоны вместо пользователя.

## Проверка

Restore/build/test, отдельные контрактные проверки параметров и пожеланий,
сохранения проектов/пресетов/метаданных и ошибок/отмены. Проверка установленного
API без генерации, если компоненты доступны. Проверка кириллицы и RU/EN.
Установщик не пересобирать. Приёмка качества песни — пользовательская проверка.
До приёмки ТЗ остаётся рабочим; публикация выполняется при закрытии по правилам.
