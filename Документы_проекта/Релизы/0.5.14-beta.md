# ЛОПАТА 0.5.14-beta

Песенный чат теперь можно открыть прямо из выбора музыкальных моделей,
внутри основного окна. Панель подсценариев остаётся на месте при прокрутке.
Из музыкального проекта чат открывается отдельным обычным окном.

ИИ± открывает карточки подходящих моделей с оценками и замечаниями из тестов.
Добавлены одна избранная модель и личные комментарии. Избранная выбирается
при входе; без доступной избранной окно выбора открывается через секунду.
Карточки разворачиваются, изначально раскрыта только избранная.
Distill 4B исключена из песенного чата; для остальных сценариев сохранена.
Бета 9B показывается только при уже установленном файле.

Справа появились облачки «Идея песни», «Текст и структура», «Музыка и исполнение».
Памятка оформления по умолчанию свёрнута. Из контекста чата убраны длительность,
аудиоформат, число вариантов и технические настройки музыкального движка.
Старые сессии и шаги сохранены. Три темы используют общую историю параметров.

«Новая сессия» сохраняет выбранного собеседника. Исправлена связь sm54/Qwen3.6-27B
с общим каталогом лицензий исполнителя. Проверка реальных изменений продолжает
отклонять обещания без результата и копии прежнего текста.

Отзывы о моделях — пользовательские оценки, а не гарантия хорошей песни с одного
запроса. Возможны отклонённые и неполные ответы; они сохраняются отдельно.
Проверки интерфейса и контракта: 96 успешных, 4 специальных теста с реальными
моделями пропущены. Предыдущие прогоны и практическая приёмка учтены отдельно.

Это файловое обновление. Для новой установки используется универсальный
миниустановщик из выпуска 0.5.6-beta; полный установщик не пересобирался.
