# 0.9.27-dev — Подготовка H3 и ZIP конвертера

- Окно «Песня → клип» показывает ход фоновой проверки компонентов H3 и сохраняет итоговый статус при отмене или завершении.
- При обращении к отсутствующему помощнику «Песня → клип» скачивает его штатным загрузчиком и продолжает работу с сохранённого этапа.
- Конвертер сохраняет готовые ролики внутри ZIP. Проверенные промежуточные файлы хранятся до записи и проверки архива, а при сбое доступны для повторной упаковки.
