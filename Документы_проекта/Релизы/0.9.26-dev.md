# 0.9.26-dev — Конвертер видео

- Под «Апскейл видео» появилась отдельная утилита для перекодирования и пакетного сжатия. Разрешение можно задать отдельно. Для каждого файла показываются прогноз, результат и время обработки.
- MP4 с AV1 доступен из основной сборки. Для сжатия можно выбрать CPU или поддерживаемую видеокарту. Другие варианты включают H.265, H.264, VP9 и FFV1.
- В Проводнике команда «ЛОПАТА → Перекодировать видео…» открывает очередь. Готовые ролики можно собрать в ZIP. Исходники можно отправить в корзину после проверки и отдельного подтверждения.
- ЛОПАТА сохраняет последние настройки и очередь. После сбоя конвертер подхватывает уже проверенные файлы и продолжает с незавершённого.
- Голосовые уведомления сообщают о начале и завершении перекодирования. Записи входят в стандартные пакеты на русском и английском.
- Конвертер ищет совместимые настройки отдельно для каждого файла и показывает выбранный вариант. Исправлено чтение цветовых параметров AV1. MP4 сохраняет обложки JPEG и PNG. Ограничение частоты кадров учитывает исходную частоту.
- Исправлена поставка трёх скриптов MiniMax H3. При несовпадении скриптов со сборкой упаковщик останавливается до подписания обновления.
- Агент может подготовить очередь с параметрами конвертера для открытия в ЛОПАТЕ. [ТЗ](../../ТЗ/Архив/2026-11-26_Конвертер_видео.md)
