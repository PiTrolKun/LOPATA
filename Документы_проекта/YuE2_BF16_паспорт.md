# YuE2 3B BF16 — отдельный паспорт вариации

08.10.2026. ЛОПАТА 0.4.20-dev. Идентификатор: `music-yue2-bf16`.
Подключён отдельный адаптер. 08.10.2026 завершена первая полная генерация,
пользователь прослушал результат. Устойчивость качества требует дальнейших проверок.
Измерения и примеры Q8 к BF16 не относятся.

## Происхождение и точность

Для официального Python API используется исходная раздельная упаковка Safetensors:

| Компонент | Источник / ревизия | Размер весов |
|---|---|---:|
| Генератор BF16 | [m-a-p/YuE2-3B](https://huggingface.co/m-a-p/YuE2-3B/tree/8f24312f187763b9854adeec87e437e2b03bbff1), `8f24312f187763b9854adeec87e437e2b03bbff1` | 7 261 441 640 байт |
| VAE F32 | [m-a-p/YuE2-Vae](https://huggingface.co/m-a-p/YuE2-Vae/tree/152733a19ad43aa67e367f9b5503ef8075bb5126), `152733a19ad43aa67e367f9b5503ef8075bb5126` | 530 512 720 байт |

Это полная точность генератора, без INT8/FP8. Объединённый checkpoint Comfy-Org
не конвертируется и не подменяет исходный пакет. VAE и основной генератор имеют
собственные ревизии. Точные URL, размеры и SHA-256 всех файлов закреплены в
`Исходники/AIHub/Tools/yue2-bf16-models.json` и в управляемых карточках загрузчика.

Исполнитель `yue2-infer 0.1.5`, адаптер `yue2-infer-0.1.5-lopata-1`.
Windows Python 3.12/PyTorch 2.10 берётся из штатных аппаратных библиотек первого запуска.
Дополнительный изолированный слой: transformers 4.57.6, safetensors 0.7.0,
tiktoken 0.12.0, numpy 2.2.6, soundfile 0.13.1, accelerate 1.13.0 и закреплённые
транзитивные зависимости. pip и глобальная среда не изменяются.
PyTorch повторно не скачивается с весами. Слой проверяется по исходным wheel-архивам;
неожиданные файлы и ссылки запрещены. Лицензии/NOTICE сохранены в каталоге и пакетах.
Условия весов и upstream-исполнителя: CC BY-NC 4.0; зависимости имеют отдельные условия.

## Исполнение и параметры

`torch-eager`, `quantization=none`, `offload_ar=true`, один запрос за раз.
Контекст 24 576, метод ODE midpoint. Один seed для плана, последовательности и звучания.
Два независимых seed и `peak_clip` из native Q8 не применяются к этому API и скрыты
в экспертном окне. Cot, sampling ABC/semantic, steps и CFG передаются явно.
Пожелания и текст передаются существующим сборщиком, без новой интерпретации.

Круг имеет отдельный профиль `YuE2.PyTorch.BF16.Bubble`; общие инженерные траектории
сохранены, но их музыкальная эффективность на BF16 ещё не установлена.
Экспертные и простые пресеты хранятся отдельно от Q8. Перенос другого пресета
доступен только явно, переносит совместимые параметры и сохраняет оригинал.

План фиксируется вместе с точными ABC token IDs. Пауза прекращает собственный процесс;
продолжение повторяет незавершённую стадию, подтверждённый план не создаётся заново.
Планы Q8/BF16 автоматически не переносятся. Работает общий контроллер фоновых операций.
Модель, ревизии, устройство, параметры и seed в тегах берутся из исходного задания.
Проект общий, банк настроек разделён по вариациям; старые шаги остаются неизменными.

## Память и устройства

[Ориентир upstream](https://huggingface.co/m-a-p/YuE2-3B): BF16 NVIDIA,
24 ГБ VRAM и 24 ГиБ свободной RAM. Опубликованные 11,18/14,08 GiB VRAM относятся
к авторскому Linux пути, а не к ЛОПАТЕ. Это рекомендация, не универсальный минимум.

Перед стадией выбирается подготовленный профиль и реальное устройство. Проверяются
операция BF16, свободная RAM и VRAM. Оценка отдельно учитывает веса, KV cache
по длине prefix/ABC и последовательности, удвоенную ветку CFG, буферы и резерв.
CPU дополнительно требует RAM под вычисления. Оценка консервативная, память
не резервирует и не заменяет будущие пиковые замеры реальной песни.

Offload переносит AR и VAE между GPU/RAM по этапам. Частичное распределение слоёв
AR между CPU/GPU этим адаптером не заявлено. Проверка нехватки памяти не включает
скрытое квантование или автоматический переход на Q8. CUDA/ROCm/XPU/CPU выбираются
существующим аппаратным механизмом; конкретное устройство обязано пройти вычисление.
Физические AMD/Intel и полный CPU синтез BF16 пока не испытаны.

## Что подтверждено

На Windows, RTX 4090, подготовленной CUDA 12.6/PyTorch 2.10.0:
импорт официальных классов, отдельного слоя библиотек и вычисление BF16 8×8;
запуск самого адаптера в режиме probe без весов. Пробник завершился за ~8 секунд.
Проверены раздельные проекты/пресеты, снимки seed/параметров и метаданные,
совпадение токенизатора с независимыми reference IDs, совместная распаковка wheel.

## Пользовательская оценка после трёх прогонов — 08.10.2026

сохранение всех строк и их порядка. Это оценка прослушанных результатов,
а не универсальная гарантия для русского языка или отдельный ASR-замер.

Все три задания завершились: d3c125a5acd84455b20856e8629c2ad1,
ef5872b742dc4d4993bf5a7fed9d32e4, c60354e0fd4544e291d2380ede16851f.
Генерация 447,02 / 584,30 / 850,07 с; аудио 220,68 / 131,16 / 154,56 с.

Для комфортной работы по решению пользователя рекомендуется RTX 5090 либо
сопоставимая более мощная совместимая карта. Это рекомендация, не технический
