# Qwen в литературном сценарии — 15 сентября 2026

Версия: **0.1.109-dev**. Внедрение по прямой команде пользователя после исследования. ТЗ остаётся активным до приёмки. Установщик и публикация не выполнялись.

## Что внедрено

- Общая литературная модель заменена на тот же установленный Qwen3.8-27B-Ridge 3.7 bpw из Гаммы. Проверяется SHA256 основного GGUF, проектор не загружается. Старые веса не удаляются; старые проекты продолжают работать с прежним ID основного исполнителя памяти.
- Один физический слот llama.cpp b9442, контекст 16384. Писатель ограничен логическим бюджетом 8192, Советник — 16384. Запросы последовательные, автоматический KV-кэш переписки выключен. При работе основного архивариуса модель не выгружается; механизм переключения на специалистов сохранён.
- Писатель: temperature 0.8; Советник: 0.4. Общие top_k 40, top_p 0.95, min_p 0.05, repeat_penalty 1.05. Свободные ответы используют thinking/medium. Служебные короткие структурированные ответы — без thinking, чтобы обдумывание не съедало их бюджет.
- Скрытое reasoning остаётся в диагностическом SSE, но не попадает в текст, JSON и детектор повторов видимого ответа.
- F1: отдельная кнопка «Обсудить» оставляет пользователя на первом шаге. «Подготовить запрос» выдаёт редактируемое задание Писателю. История обсуждения доступна Советнику; Писатель получает окончательное задание, без прежней беседы. Перенос в рукопись по-прежнему ручной.
- В оба режима добавлено различение темпа событий и подробности описания. Советник помогает обсуждать произведение и готовить задания. Последняя правка автора имеет приоритет, прежние неотменённые условия сохраняются.
- Только для Писателя F1 финальный текст ограничен одним абзацем. Это ограничение формата, а не гарантия правильного смысла. Старый режим сохраняет возможность писать несколько абзацев.
- Для служебного JSON принимается необязательная цельная Markdown-обёртка. Содержимое строго разбирается как JSON; произвольный текст вокруг и повреждённый JSON не принимаются. Исходный ответ сохраняется в диагностике.

## Что не переносилось вслепую

Исследование Runeweaver (331 вызов) не доказывает качество Qwen на всей выборке. W3 с общей формулировкой желательного повествования не стал безусловным победителем; он не подставлен целиком. D3/P18 также не объявлены универсальным решением. Внесены ограничения формы, разделение действий и короткие понятные инструкции по темпу/приоритетам.

## Практические пределы

В старом ответе Писателя остался пространственный огрех «дверь за ним»; в коротком пересказе создатель сделал дополнительный вывод о страхе последствий. Советник отвечает обстоятельнее просьбы «кратко». Это не исправляется гарантированно ограничением формата; автор проверяет результат.

Прежние 12.309 ГиБ VRAM измерены при 8192 на RTX 4090. Здесь физическое окно 16384; прежнюю цифру нельзя выдавать за новый замер или гарантировать работу RTX 4080 с любым фоном. GGUF не уменьшен. Полный корпус исследования на Qwen заново не запускался.
