## Ограничения сборки

Собственный код/обычная .NET сборка не добавили предупреждений. Компиляция
немодифицированных upstream FFmpeg/libvpx/OpenH264 с GCC 16 выводит собственные
диагностики (format-truncation/stringop-overflow/array-bounds и другие);
они не скрывались отключением проверок и не объявляются исправленными.
Полные локальные логи: Runtime/Capture/Minimal-8.1/logs. Native build завершён
без ошибок. Функциональные проверки не доказывают отсутствие всех ошибок upstream.
Патентные права зависят от применения; собственный OpenH264 не подменяет
Cisco prebuilt royalty programme. Оригинальные уведомления сохранены.
