# ЛОПАТА 0.4.1-beta — аппаратная поддержка музыки

Музыкальный сценарий YuE2 автоматически выбирает совместимую видеокарту
по её возможностям, драйверу и свободной памяти.

- CUDA включена для NVIDIA RTX 30/40/50 с SM86/89/120. Vulkan добавлен для
  совместимых Radeon; возможность Intel сохранена, физически не проверена.
- Память проверяется при входе в сценарий и перед каждым этапом генерации.
  Учитываются веса конкретной стадии, KV, текст, длительность и запас буферов.
  Это оценка; другой процесс может занять память после проверки.
- При невозможности GPU выбирается CPU AVX2 с проверкой свободной RAM.
  Распознанный отказ GPU допускает один повтор незавершённого этапа на CPU.
  Если не хватает и RAM, генерация блокируется. Seed и готовые этапы сохраняются.
- В интерфейсе видно «Видеокарта» или «Процессор» с причиной перехода;
  подробности устройства и оценки памяти находятся в журнале.

Собраны общий CUDA/Vulkan/CPU комплект и независимый CPU комплект. Сохранены
SHA-256, оригинальные лицензии, штатный каталог согласий и безопасные результаты.
SDK, компиляторы и веса не входят в обновление; драйверы Windows не изменяются.

Физические проверки выполнены на RTX 4090: CUDA, Vulkan и CPU создали валидный
короткий WAV; отмена остановила собственный процесс. RTX30/RTX50/AMD/Intel
покрыты сборкой и логическими тестами, их физическая работа ещё не подтверждена.
Одинаковые seed на разных backend могут дать отличающийся звук.

Доставка — подписанное файловое обновление. Полный установщик остаётся
0.4.0-beta; после установки доступны обновления из направления «Бета».
Рабочая версия исходников — 0.4.1-dev.
