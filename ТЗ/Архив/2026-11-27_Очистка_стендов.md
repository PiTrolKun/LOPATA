# Очистка стендов

Состояние — принято пользователем 27.11.2026. Утилита собрана, ярлык создан. Проверены общая очередь, предварительный просмотр, групповое удаление, изменённые и занятые файлы, сохранность рабочих копий Git. Подготовлен файловый выпуск 0.9.33-beta. [Команды](../../Инструменты/StandCleanup/README.md)

Рабочая утилита проекта для временных файлов завершённых задач. Ярлык «Очистка стендов» открывает очередь на рабочем столе. Codex пользуется той же очередью из терминала.

- При закрытии ТЗ сохранить результаты и протоколы, проверить принадлежность временных папок задаче, добавить их в очередь и попытаться очистить через штатную проверку. При отказе сохранить запись и сразу сообщить, что нужно сделать вручную.
- Для каждой папки хранить её полный путь, название задачи, объём, проверенный состав и пути к сохранённым материалам. Очередь и история очистки лежат вне `_tmp`.
- При запуске по ярлыку показать объём и состояние ожидающих записей. Пользователь выбирает папки и подтверждает удаление. Команда терминала сначала показывает план. Для удаления требуется отдельный явный запуск.
- Допускать вложенные папки только внутри `_tmp`. Проверять сохранённые пути и оставшееся содержимое, отклонять ссылки, непроверенные файлы и единственные рабочие копии репозиториев. Если часть файлов уже удалена, повторная попытка работает только с проверенным остатком. Очищать запись после подтверждения, что путь исчез.
- Проверить ярлык, общий список, обработку группы записей, ручное удаление через Проводник, повтор после сбоя и сохранность изменённого или постороннего файла. Проверки удаления проводить на отдельных синтетических папках.
