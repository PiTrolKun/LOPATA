# ЛОПАТА 0.5.1-beta

Универсальный миниустановщик выбирает актуальный совместимый опубликованный выпуск,
проверяет подпись и скачивает установочный движок и файлы программы нашим
многопоточным загрузчиком. Работает без предварительной установки .NET или Python.
Поддерживает установку с нуля, обновление зарегистрированной копии, отмену и докачку.
Настройки, проекты, модели и неизвестные файлы сохраняются.

Для обычного файлового релиза больше не нужно собирать большой установщик.
Полный офлайн-комплект выпускается только при смене первой цифры версии или
по отдельной прямой команде. Миниустановщик обновляется при изменении его кода,
ключей или протокола; номер устанавливаемой программы в нём не зашит.

Текущие направления будущих обновлений сохранены: Бета получает файловые патчи,
Стабильная ищет полные офлайн-выпуски. Выбор направления не меняет выпуск,
который уже выбран миниустановщиком.

Это первый выпуск нового установочного протокола. Старые опубликованные пакеты
сохраняются: новые манифесты могут ссылаться на неизменившиеся файлы из них.
Исправлены обрезанные переключатели, переносы текста и размещение кнопок мастера установки. Проверены страницы на русском и английском при масштабе 200%.
