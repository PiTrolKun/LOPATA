# Проверки ЛОПАТЫ 0.9.31-beta

- Установленный Python в отдельном процессе Windows работал с ограничением длины пути. На 0.9.30-beta воспроизвели отказ Transformers на пути в 262 символа. После обновления та же проверка загрузила Transformers и узел дорисовки Deno RTX с путём в 277 символов. Настройки Windows в ходе проверки сохранились.
- В стандартном режиме Deno RTX выполнен весь цикл на RTX 4090. Синтетический шестисекундный тест прошёл анализ песни, планирование, генерацию двух сцен, дорисовку, обработку RTX, монтаж и экспорт H.264 с AAC. Отдельный просмотр контейнера прочитал все 144 кадра 1920 × 1080 и звуковую дорожку. Повторное открытие подтвердило обе контрольные точки и ранее записанный результат.
- Подписанный патч применился к изолированной копии 0.9.30-beta. Проверены 8 018 файлов целевой версии и откат к 0.9.30-beta. Все 8 016 файлов прежней версии сверены по контрольным суммам. Три контрольных пользовательских файла сохранились.
- Прошли 108 профильных тестов и отдельный полный прогон Deno RTX. Проверка полного цикла выполнена в 1080p без опции ускорения. Полный установщик не пересобирался. [Файловое обновление](https://github.com/PiTrolKun/LOPATA/releases/tag/v0.9.31-beta)
- На GitHub подтверждены имена, размеры и SHA-256 всех 24 вложений. Тег указывает на коммит сборки.

Коммит сборки `60d87bfad633e5af2193f445e36ba2678f619919`. SHA-256 переходного манифеста `b2f7e1a4fe443ff37b429265054f23bda7a7a6ca6f7410926a6aaa224ce90203`. SHA-256 манифеста новой установки `954b3eb31bb9f906a8fe1e0d71172dd8bfd76bbba800ae5caf41e76e5df3b0ee`.
