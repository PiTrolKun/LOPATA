# Управляемое чтение RAG — проверка внедрения

11.09.2026, ЛОПАТА 0.1.90-dev. Runeweaver Q4_K_M, действующий `LiteraryChatRuntime`, обе роли, штатные контексты и параметры генерации. Без замены модели, подключения Vikhr или реализации «желе».

## Что изменено

Перед планировщиком отдельный короткий запрос выбирает editor/project/reference/both. Для выбранных корпусов программа выполняет начальное чтение; до получения текста либо исчерпания ограниченных попыток финальный ответ запрещён схемой действий. Каталоги, пустые результаты и редактор не считаются прочитанной историей. Удерживаемые исходные выдержки содержат происхождение, версию и адрес; их удаление из контекста отменяет покрытие корпуса. До трёх попыток на корпус в общем бюджете шести операций. История и первоисточник остаются раздельными.

JSON-схема маршрута допускает только согласованные сочетания области и непустых поисковых запросов; номер части выбирается из зарегистрированной истории и учитывается как прямое чтение только при явном упоминании номера автором. Если номер не указан, используется смысловой поиск. Определение области и релевантности остаётся работой модели: код гарантирует исполнение выбранного требования, а не всеведение.

Повреждение первоисточника возвращается как ошибка его чтения, не прерывая независимый доступ к истории. Отмена, повреждённые источники, пустой поиск, вытеснение, запрет преждевременного answer и актуальный редактор покрыты автоматическими проверками. Полный набор: **540/540**, сборка без предупреждений. Штатный start-aihub.ps1 запустил отвечающее окно «ЛОПАТА 0.1.90-dev»; после проверки оно штатно закрыто. Пользовательские главы и индекс не изменялись. Проверена кириллица исходников; установщик не собирался.

## Воспроизводимый стенд

Запуск из корня репозитория (использует уже установленные компоненты и принятие лицензий приложения):

```powershell
dotnet run --project Тесты/LiteraryReadControl/Probe.csproj -- Тесты/LiteraryReadControl/runs/new-01
```

Новая папка обязательна. Стенд создаёт собственный проект и реальный индекс Giga/Qdrant. Не использует реестр пользовательских проектов. Вторым аргументом можно передать путь к уже созданному **стендовому** проекту для повторного использования индекса. Контроль времени — 10 минут всего, 2 минуты на запрос. Факт готовности — 30 записей summary.json и сообщение COMPLETE; оборванная серия не считается полной. Detailed-логирование включается только в процессе стенда.

Проверка связи результатов с диагностикой:

```powershell
& Тесты/LiteraryReadControl/analyze.ps1 -Run Тесты/LiteraryReadControl/runs/final-01
```

Скрипт сопоставляет время файла результата и журнала, проверяет точное задание, извлекает область, чтение и содержимое последнего запроса. `audit.json` не является автоматической оценкой литературного качества.

Сырые данные находятся локально в runs (не публикуются). Оригинал, эталон и проект — в first-01; повторные серии second-01 и final-01 используют этот индекс. Полные журналы всех серий — в `first-01/ControlledReading/Diagnostics/LiteraryDetailed`.

## Исходные данные

Незнакомая короткая повесть «Сухой мост Лаэны», созданная специально для теста. Эталон записан до запросов к модели:

| Область | Ключ Тавры | Секретный код |
|---|---|---|
| Оригинал | серебряный | ЯНТАРЬ-684 |
| История проекта, часть 001.2 | медный | НЕФРИТ-523 |
| Редактор, несохранённая правка | зелёный / алый / лиловый по повтору | не указан |

Часть 001 тоже существует, но нужного кода там нет. Часть 001.2 — продолжение первой главы, текущая 002. Каждое из пяти заданий повторено трижды для Писателя и Советника: история, оригинал, сравнение двух корпусов, точная часть, только редактор.

## Результаты

Первая серия: 30 попыток, 20 ответов и 10 отказов проверки номера маршрута. Вторая: 30 попыток, 29 ответов и один пустой обязательный поисковый запрос. Эти серии сохранены; ошибки не скрыты. После ограничения схемы выполнена полная финальная серия.

**final-01: 30/30 ответов без транспортных и форматных ошибок; 30/30 точных совпадений области задания.** Во всех 24 запросах к источникам требуемые коды присутствовали в итоговом контексте, missing пуст. Оба корпуса прочитаны во всех шести сравнениях. Во всех шести локальных заданиях — ноль поисковых операций. Актуальный редактор присутствовал в каждом финальном запросе. Диапазон времени одного запроса — 0,84–16,36 с, включая чтение и иногда холодную подготовку; это не отдельный бенчмарк скорости модели.

| Проверяемые факты ответа | Писатель | Советник |
|---|---|---|
| Цвет и код сохранённой истории | 3/3 | 3/3 |
| Цвет и код оригинала без подмешивания редактора | 2/3 однозначно; один ответ смешивает зелёный и серебряный | 3/3 |
| Оба цвета и кода при сравнении корпусов | 0/3: цвет истории заменён цветом редактора | 2/3 |
| Код по прямо указанной части 001.2 | 3/3 | 3/3 |
| Актуальная правка редактора | 3/3 | 3/3 |

Оценка таблицы касается перечисленных основных фактов, не всего текста. Советник также иногда неверно называет продолжение 001.2 второй главой, в одном сравнении выдумал номер 002.2. Это ошибки интерпретации, хотя правильная нумерация и текст были переданы. Писатель особенно склонен переносить текущий цвет из редактора в прошлую историю при сравнении. Чтение исправлено, гарантированное разделение версий в итоговом сочинении **не достигнуто**. Длинная книга, сложный диалог и автоматическая проверка смысла требуют отдельной проверки; короткий стенд их не заменяет.

Внедрение готово к пользовательскому тесту механики. ТЗ не архивировано, публикация не выполнялась.
