# Проверки выпуска 0.2.5-beta

21 сентября 2026. Пользователь принял рабочий быстрый импорт DeepSeek и подтвердил, что литературный сценарий подхватил данные. ТЗ, карта и сопутствующие отчёты архивированы. Сборка и публикация публичного установщика разрешены прямо. Внутренняя версия остаётся **0.2.5-dev**.

## Артефакт и происхождение

- Имя: `LOPATA_Setup_0.2.5-beta.exe`.
- Размер: 506864891 байт.
- SHA-256: `4ba6ed53545eac06a83ee5f83c57b9a96a6b150f97ce5f2be1f61b74a5837837`.
- Исходный коммит: `2d48cffc86394caa2b497dfa4a14511c64a322db`, отправлен в origin/main до публикации.
- Receipt: sourceDirty false, version и payloadVersion — 0.2.5-beta.
- Сборка штатным `build-installer.ps1 -PublicBeta`: свежий self-contained win-x64 payload, Inno Setup. VERSION не переводился на beta.

## Проверки

- Сборки без ошибок и предупреждений; перед выпуском повторены все **655/655** автоматических тестов. Результат: `release-025.trx` в локальных TestResults.
- WPF-проверки текущего кода: **40** для окон импорта и **317** для литературного редактора, включая очистку старых статусов; RU/EN, светлая/тёмная темы. Это синтетические проверки, не дополнительный полный прогон частного чата через модель.
- Словари RU/EN содержат по **2426** ключей, пропусков нет. UTF-8/кириллица, diff --check и ссылки перемещённых документов проверены.
- Публичный состав проверен: 83 файла исходного коммита, 104 текстовых файла с учётом исследовательского ZIP. Пакет исследования содержит синтетические примеры и обезличенную статистику структуры. Личный экспорт, пользовательские проекты, их тексты и сырые модельные результаты не включены. Ранее отложенное перемещение идеи в «Пока не нужно» сохранено как переименование.
- Тест публикации с подменой GitHub CLI проверил preview, продолжение черновика, отклонение неверного хеша и политику хранения; сам тест не менял GitHub.
- Штатный сборщик проверил комплект лицензий. В payload нет весов GGUF/Safetensors, пользовательских баз/сессий, приватного экспорта и ключей.
- Payload запущен: окно «ЛОПАТА 0.2.5-beta», отвечает, штатно закрыто. Установщик запущен без принятия лицензий: отказ InitializeSetup, код 1, установка не началась. Это не полная установка поверх пользовательской копии и не тест чистой машины.
- Preview публикации проверил конкретный EXE и receipt. Скрипт загрузил EXE и файл обновления в черновик, сверил серверные SHA-256 и только затем открыл выпуск.

## Ограничения приёмки

Принята работоспособность текущего быстрого импорта и продолжения литературной работы. Интерфейс требует дальнейшего упрощения, литературный результат остаётся проверяемым черновиком. Доля чатовых артефактов на полном архиве не измерена; пользовательский ориентир 10% не заявляется достигнутым измерением. Другие источники и два дополнительных режима — будущая работа.
