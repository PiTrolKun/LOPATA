# Gemma: прогрев при открытии чата

03.11.2026, версия **0.7.5-dev**. Реализация и проверки завершены; приёмка ожидается.
Рабочий источник требований — раздел 0.4
[единого ТЗ](../../ТЗ/2026-11-02_Разгрузочный_разговор_Набросок.md).

При открытии подготовленного окна «Если накипело» загрузка Gemma начинается
без пользовательской реплики. Поле ввода доступно, отправка ожидает готовности.
После загрузки первый запрос использует тот же процесс. Повторный вход проверяет
готовность и резерв, не создавая второй процесс уже загруженной модели.

Используется тот же аудируемый runtime и выбор GPU/гибрид/CPU, проверка ОЗУ,
резерв VRAM 2 ГиБ и диалог освобождения памяти. Прогрев не вызывает генерацию:
подготовка весов, проверка health и подтверждение размера контекста. Системный
промпт, sampling и контекст не изменены.

Загрузка оформлена как приватная `chat.let_it_out.warmup` в общем контроллере.
Общий STOP, пауза/продолжение и восстановление работают с этим видом задачи.
В checkpoint находятся путь модели и язык, без черновика и реплик разговора.
При занятой очереди загрузка откладывается до её освобождения, пока чат видим.
Незавершённый разговор или ожидающий прогрев автоматически не возобновляются.

Выход из чата отменяет незавершённую загрузку с освобождением процесса и общей
очереди. Быстрый выход/повторный вход ожидает завершения старой отмены.
STOP не запускает новый прогрев немедленно. После ошибки сохранены черновик и
объяснение; продолжение требует явного решения. Готовая модель остаётся резидентной
до переключения общей работы ИИ, штатной отмены либо выхода из приложения.

## Проверки

Окончательный прогон с настоящим GGUF, UI и общими фоновыми проверками:
**106 успешно, 0 ошибок, без пропусков** — [лог](verified-tests.log),
[TRX](verified-tests/). Включена повторная проверка уже загруженной модели:
одинаковый PID сохраняется после второго прогрева, первой и следующей реплик.
Первичный `targeted.log` и промежуточный `final-tests.log` сохранены отдельно.

UI-проверки с управляемым исполнителем охватывают RU/EN, ввод во время прогрева,
отсутствие вымышленных сообщений, повторную конфигурацию, занятую очередь,
быстрый выход/повторный вход, паузу/продолжение, STOP, сбой/нехватку RAM с явным
продолжением и сохранённый разговор, который нельзя возобновлять автоматически.

Native-тест прогревает модель в GPU, гибриде с проекцией бюджета 12 ГиБ и CPU,
повторяет прогрев и две реальные реплики, проверяя неизменность PID. Артефакты
окончательного прогона — `native-final`. Это реальное исполнение на имеющемся ПК;
проекция памяти не является измерением скорости физической 4070.

| Режим | Загрузка до готовности | Первые слова первой реальной реплики |
|---|---:|---:|
| GPU | 10,83 с | 0,56 с |
| Гибрид, проекция бюджета 12 ГиБ | 4,68 с | 3,80 с |
| CPU | 7,98 с | 7,29 с |

Это отдельные замеры на текущем ПК, без гарантий для других устройств. Веса
загружаются заранее; вычисление первого запроса всё ещё требует времени.
