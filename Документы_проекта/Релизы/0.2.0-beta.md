# ЛОПАТА / LOPATA 0.2.0-beta

Новый литературный сценарий: работа над произведением с Советником, Писателем и памятью проекта.

- Создание проекта с обсуждением замысла, калибровкой и маршрутом. Маршрут можно редактировать и дополнять этапами во время работы.
- Рабочий редактор, отдельная отправка Советнику и Писателю, настраиваемые Enter/Ctrl+Enter и Shift+Enter для новой строки. Принятое сообщение сразу освобождает поле ввода; индикатор показывает работу модели.
- Передача задания Писателю с показом ТЗ или напрямую: Советник скрыто готовит задание, пользователь получает результат Писателя.
- Источники из первоисточника и завершённых глав, сюжетные якоря, поиск RAG и подтверждаемая память произведения. Ошибочные поля при проверке фактов выделяются с пояснением.
- Стандартные и пользовательские наборы промптов, отдельное управление наборами и редактор со сворачиваемыми группами.
- Улучшены тёмная тема редактора источников, прокрутка, плавающая панель, копирование отдельного ответа и компактный экран выбора проекта.
- Ускорена повторная проверка установленных литературных компонентов: в локальном замере с 22,2 до 9,3 секунды. Первая проверка и кнопка «Проверить снова» сохраняют проверку содержимого; скорость зависит от компьютера.

Это публичная тестовая версия для Windows x64. Существующий сценарий анализа изображений сохранён. Внутренняя версия разработки остаётся 0.2.0-dev.

Веса моделей не включены в установщик: необходимые компоненты подготавливаются через приложение с показом условий лицензий. Перед обновлением рекомендуется сохранить текущую работу. Модельные тексты и предлагаемые факты требуют проверки пользователем.

Пользователь принял литературный сценарий и три завершающих пункта полировки. Перед выпуском пройдены 631 автотест; результаты отдельных проверок интерфейса и сценария сохранены в документации проекта.
