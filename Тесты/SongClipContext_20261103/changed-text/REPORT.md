# «Песня → клип»: контекст монтажных сцен

03.11.2026, исправление **0.7.4-dev**. Реализация и проверки завершены;
пользовательская приёмка ожидается.

## Подтверждённая причина

Исходный проект: «LOPATA — Коты не с Земли!», попытка
`49bf8852ebfb40149280c3045355d4bf`. Источники: snapshot, montage-analysis,
visual-references, visual-story, фоновое задание
`a3069bf914b940a2ba2bc129999b086c` и журнал LlamaStartup.

Ритм успешно разобран: 195,638667 с, 26 интервалов. Роли референса и смысловой
якорь подготовлены Qwen3.6-27B. Модель загружена на GPU с окном 8192, нативного
падения в этой попытке нет. До отправки первого монтажного запроса общий
preflight отклонил размер контекста с `VideoPrep.AiContextLimit`.

В каждый пакет передавались полный текст песни, все 63 LRC-маркера и обязательные
строки текущих сцен. Реальный токенизатор подтвердил для первого пакета из шести
сцен: вход **3848**, резерв ответа **4096**, запас **256**, всего **8200 > 8192**.
То есть отказ вызван превышением на восемь токенов. Три сцены дали 3597 входных
токенов, одна — 3464. [Исходные замеры](before/budgets.json).

## Исправление

`SongClipMontageProtocol.Input` сохраняет полный текст песни, разделы, смысловой
якорь, пожелания и роли референсов. В `knownTimingCues` попадают маркеры только
переданных интервалов. Полный LRC остаётся в неизменном snapshot; хост связывает
его с каждым пакетом. В запросе явно указана область действия таймингов.

Пограничный маркер относится к следующему интервалу; интервалы без вокала получают
пустой список маркеров и якорей. Тексты исходников, лимит ответа, окно модели,
число сцен, тайминги, валидация и завершённые checkpoint не сокращаются.
При реальном переполнении общий preflight по-прежнему останавливает работу;
добавлена диагностическая запись с входом, окном и резервом без текста пользователя.

## Границы проверки

Испытание выполняется на копии четырёх JSON-файлов; пользовательская попытка
используется только для чтения. [Сверка SHA-256](source-hashes.json).
Реальная модель запускается через общие аудит, лицензии и механизм освобождения.
Лицензии принимаются только при уже существующей соответствующей квитанции.
Видеорендер H3 не входит в этот повтор; проверяется именно планирование сцен.

Новый opt-in тест сохраняет запросы и сравнивает исходный формат с текущим на
одном токенизаторе и одном окне. Исходный формат восстанавливается заменой только
двух полей (`knownTimingCues`, `timingCoverage`), без изменения остального запроса.
Обычные тесты дополнены проверкой полного текста во всех пакетах, границ таймингов
и инструментального интервала.

Резервная копия: `H:\AI_HUB\_backups\songclip_context_20261103_043100`.
Первый запуск сборки упёрся в открытый AIHub.exe; проверки перенесены в отдельный
каталог `build`, без закрытия работающей программы на время диагностики.
Установщик, публикация и архивирование в этот этап не входят.

Итоговый [манифест изменений](changes.json) включает только правки этого этапа;
backup хранит прежнее содержимое, включая имевшиеся до работы изменения.
