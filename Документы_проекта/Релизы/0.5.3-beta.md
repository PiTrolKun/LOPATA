# ЛОПАТА 0.5.3-beta

В окне «О программе и справка» (кнопка «?») появился значок ВКонтакте рядом
с кнопкой автора. Он открывает сообщество ЛОПАТЫ: https://vk.ru/lopata_ai_localhub.
Значок векторный, с прозрачным фоном; подсказка доступна на русском и английском.

Универсальный миниустановщик получает этот выпуск автоматически. Его код
не менялся; используется опубликованный миниустановщик из выпуска 0.5.2-beta.
Полный офлайн-установщик для этого патча не пересобирается.

## English

The About and help window (the “?” button) now has a VK icon next to the author
button. It opens the LOPATA community at https://vk.ru/lopata_ai_localhub.
The vector icon has a transparent background and a localized tooltip.

The existing universal mini installer from 0.5.2-beta automatically selects this
release. The installer code is unchanged; no full offline installer was rebuilt.
