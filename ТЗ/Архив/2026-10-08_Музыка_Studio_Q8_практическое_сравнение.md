# YuE2 Studio на Q8: подключение и практическое сравнение

Дата: 08.10.2026. Статус: выполнено и принято пользователем; архивировано в 0.4.25-dev. Основание: прямая команда пользователя.

## Цель

Подключить YuE2 Studio к уже установленной Q8, чтобы пользователь мог сравнить
результат с нынешним исполнителем. Не объявлять улучшение до прослушивания.
При значительной разнице отдельно определить дальнейшее направление по результатам.

## Состав первого этапа

- Отдельная вариация «YuE2 Studio · Q8» в существующем выборе моделей и ИИ±.
- Существующий интерфейс ЛОПАТЫ, общий проект, история отправок, тексты,
  пожелания, круг, экспертные настройки, экспорт и метаданные сохраняются.
- Параметры и паспорт Studio отдельные от нынешней Q8 и PyTorch BF16.
- Закрепить Studio v3.4.0 и её yue2.cpp; сначала использовать headless
  music-server, если техническая проверка подтвердит пригодность минимального комплекта.
- Использовать прежние Q8/VAE из штатного хранилища без повторного скачивания.
  Новые runtime и decoder companion готовить штатным механизмом компонентов,
  с проверкой размеров, SHA256, лицензий и аппаратной совместимости.
- Подключить реальные журналы, этапы, отмену и общий фоновый режим/паузу.
  На паузе завершаются только собственные процессы, готовые этапы сохраняются.
- В файлах результатов сохранять движок/версии, фактический запрос, настройки,
  seed, стадии и дополнительные адаптеры. Сравнение должно различать смену
  движка и добавление штатного companion; одинаковый seed не гарантирует одинаковый звук.
- Keep/Words, редактор партитуры, каверы, обучение LoRA, stems и дополнительные
  модели не входят в первый этап; неподключённые возможности не изображать рабочими.

## Проверки

Проверить подготовку, целостность компонентов, общий проект и раздельные настройки,
передачу параметров без молчаливой потери, запрос → WAV → штатный экспорт,
логи/ошибки, отмену, паузу/продолжение и отсутствие осиротевших процессов.
Использовать небольшую техническую генерацию для проверки пути; реальные сравнения
песен выполняются пользователем. Старые проекты, результаты и runtime не удалять.
В протоколе отмечать текст, Style, параметры, версии, companion, длительность,
полноту/порядок текста и произношение отдельно; оценку качества не подменять автотестом.

## Приёмка

Studio Q8 доступна для запуска из ЛОПАТЫ; текущая Q8 остаётся доступной.
Технические проверки пройдены, пользователь может провести практическое сравнение.
Приёмка и публикация — после подтверждения пользователем; полный установщик
при обычной правке не пересобирается.
