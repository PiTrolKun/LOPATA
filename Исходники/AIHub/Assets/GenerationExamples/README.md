# Встроенные примеры генерации

Четыре результата собственных тестов пользователя, выбранные им 03.10.2026
для включения в ЛОПАТУ. Это результаты локальной генерации, а не оригинальная
фотография Sean Archer и не облачный образец OpenAI.

Krea 2 Turbo Q6_K: №019 (студийный портрет), №021 (тёмное фэнтези).
Z-Image Turbo Q6_K: №033 (тёмное фэнтези), №032 (студийный портрет).
Все оригиналы 2048×2048 сохранены без изменений. SHA-256, request ID, seed,
исходный язык, оригинальный промпт и перевод находятся в
`../../Content/ImageGenerationExamples.json`. Отчёт пользователя:
`Тесты/Тест рисования/Референсы и отчёт пользователя/LOPATA_итог_тестов_Z-Image_Turbo_и_Krea_2_Turbo.md`.

Для миниатюр код накладывает локальное размытие в отмеченных областях груди.
Оригинальные PNG и отдельный просмотр не изменяются. Переводы служат только
для показа/копирования примера и не подменяют исходный пользовательский ввод
в runtime. Это отдельные выбранные примеры, а не гарантия качества модели.

каталоге (Z-Image: Apache-2.0; Krea: Community License/AUP). Изображения не
объявляются автоматически лицензированными на условиях программного кода.
