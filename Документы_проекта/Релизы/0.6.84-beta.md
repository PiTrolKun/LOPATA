# ЛОПАТА 0.6.84-beta

В Видеомастерскую добавлен облегчённый экспериментальный MiniMax H3
W4A8 + Qwen3-VL-4B + ClipProj. Он использует общую подготовку проекта,
создаёт видео с референсами и продолжает предыдущие участки с сохранением
контекста. Настройки и результаты старшего H3 хранятся отдельно.

- Встроенные скачивание/докачка,лицензии,аудит и восстановление готовых участков.
- Крупный индикатор прогрева помощника и исправленные переходы подготовки.
- Надёжное сохранение большой истории визуального мира без удаления версий.
- Согласованная раскадровка,ручные действия в ленте и проверка новых сцен.
- Карточки моделей показывают реальные измерения RAM/VRAM с условиями теста.

На RTX4090,480×864,5,17с,8шагов,Auto:старший H3 —20,1ГБ видеопамяти
и27,9ГБ физической памяти процесса;W4A8 —18,6/17,6ГБ. Это измеренные пики,
не универсальные минимумы. Windows,фон и виртуальная память учитываются отдельно.
Полный GPU на16ГБ VRAM/32ГБ RAM не подтверждён. Ускорение не обещается.
Другие GPU физически не испытаны;длинная нейродоработка ограничена памятью.
Редакторская проверка Qwen остаётся вероятностной.

LTX/VACE исключены из выбора;исторические проекты сохраняют совместимость.
Архивы schema1–3 читаются,новые сохраняются как schema4 со сжатой историей;
старые версии программы schema4 не читают. Крупные веса скачиваются отдельно.
Полный/миниустановщик не пересобирался;это файловое обновление.
