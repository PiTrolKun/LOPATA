# Полировка утилиты обработки изображений

Дата: 04.10.2026.
Статус: выполнено и принято пользователем 04.10.2026 в 0.3.31-dev.
База: принятая утилита в 0.3.30-dev / опубликованная 0.3.30-beta.

## 1. Кнопки управления очередью

Перенести шесть кнопок из горизонтального ряда под списком файлов
в узкую вертикальную колонку справа от списка, перед панелью процесса и журнала.
Вместо постоянных текстовых надписей использовать значки:

- ▶ — начать обработку;
- ⏸ — пауза / продолжение;
- ■ — остановить;
- ↻ — повторить неудачные;
- − — убрать выбранные из списка;
- 🗑 — очистить список.

Названия действий показывать при наведении. Сохранить доступные названия
для средств доступности и текущую логику доступности кнопок по состоянию очереди.
Окончательное начертание значков подобрать в общем стиле приложения.

## 2. Освободившееся место

Растянуть список файлов вниз на место бывшего горизонтального ряда кнопок,
до нижней границы рабочей области. Левую панель «Источники» также продлить
до нижней границы. Стандартная верхняя шапка приложения сохраняется.
Панель с человечком, статусом и журналом остаётся справа.

## 3. Изменение размеров областей

Пользователь может перетаскиванием менять компоновку во всех направлениях:

- влево / вправо — ширину списка файлов и правой панели;
- вверх / вниз — границу между верхними настройками и нижней рабочей зоной.

В месте пересечения разделителей, примерно как на пользовательском наброске,
разместить небольшой видимый намёк на перетаскивание — значок с четырьмя стрелками.
При наведении подсвечивать его, менять курсор и показывать подсказку:
«Потяните, чтобы изменить размеры областей».

Ограничить минимальные размеры, чтобы элементы оставались пригодны для работы.
Запоминать выбранное положение разделителей. При изменении размера окна
приводить сохранённое положение к допустимым границам.

## 4. Границы текущего этапа

Это новый этап визуальной полировки, отдельный от закрытого функционального ТЗ.
Другие части пользователь будет обсуждать далее; дополнять этот документ
по мере согласования. Пользователь разрешил реализацию и локальную проверку.
Публикация и архивирование ожидают отдельной приёмки.

## 5. Приёмка согласованного слоя

- Все шесть действий доступны в вертикальной колонке значков с подсказками.
- Под списком нет прежнего горизонтального ряда; список занимает освободившуюся высоту.
- Левая панель источников доходит до нижней границы рабочей области.
- Разделители меняют ширину и высоту соответствующих областей; их назначение видно пользователю.
- Компоновка сохраняется и остаётся пригодной при уменьшении окна.
- Проверить оформление в светлой и тёмной темах, RU/EN и на обычном экране.

## 6. Компактный блок общих настроек

Согласовано пользователем после текстового наброска:

- Кнопка выбора технологии занимает ширину самого длинного названия,
  не растягивается на всю панель и сохраняет существующее отдельное окно выбора.
- Разрешение и формат экспорта — компактные элементы рядом в одной строке.
- Переключатели находятся рядом с подписями.
- Путь экспорта занимает доступную строку; справа — кнопка-значок папки с подсказкой.
- Уменьшить пустые промежутки и лишний скроллинг, сохраняя читаемые пояснения.
- Если хватает ширины, кнопки и настройки располагаются в несколько столбцов.
  При сужении области переходят на следующие строки. Подписи и описания
  остаются со своими элементами, текст не обрезается.

Набросок:

```text
Обработка изображений
[ Детальный · Lanczos3 ▾ ]   Только сменить формат [○]

Разрешение                  Формат экспорта
[ 8K ▾ ]                    [ WebP ▾ ]
Длинная сторона.             Формат выходных файлов.
Пропорции сохраняются.

Место экспорта
[ C:\Users\...\Результаты                    ] [📁]

Имена файлов
[ Своё название + номер ▾ ]  [ Название серии      ]
Пример: Пейзаж_0001.webp

Включать вложенные папки [○]
```

## 7. Полноценный выбор способа именования

Заменить нынешнее необязательное текстовое поле на настройку «Имена файлов»:

1. Сохранить исходные — по умолчанию.
2. Исходное имя + способ обработки.
3. Своё название + порядковый номер.
4. Дата и время + порядковый номер.

Поле названия серии появляется только в третьем режиме.
Под выбором показывать пример итогового имени с выбранным расширением.
При совпадении имён добавлять номер, не перезаписывать результаты.
Правило отдельной папки для многофайлового процесса и сохранение исходников
в полноценной утилите продолжают действовать.

## 8. Общие правила элементов настройки технологии

Настройки технологии также уплотнить и раскладывать в несколько столбцов
при достаточной ширине. Описания сохраняются прямо под своим элементом,
без необходимости открывать подсказку или выпадающее описание.

- Числовые диапазоны — ползунки с видимым текущим значением и допустимым шагом.
- Несколько текстовых значений — компактная кнопка со всплывающим выбором.
- Два состояния функции — переключатель.
- Единственное допустимое значение — отображение без бессмысленного выбора.
- Не скрывать возможности и предупреждения об экспериментальных результатах.
- Названия настроек и вариантов понятны человеку; внутренние параметры не требуют ввода.
- Параметры зависимы: неподдерживаемые сочетания недоступны сразу,
  а не обнаруживаются только после запуска обработки.
- Сохранить возврат к рекомендуемым настройкам.

Ниже фиксируются настройки, сверенные с текущими каталогом и реализацией.
Вид элементов меняется; набор функций не сокращается.
Конкретные безопасные границы и шаг больших числовых диапазонов выбрать
при реализации по ограничениям текущих обработчиков, без выдуманных значений.

## 9. Настройки всей десятки

### 9.1. Real-ESRGAN — фото и восстановление

- Характер обработки: фотографии / рисунки / анимация — всплывающий выбор.
- Увеличение: для фото и рисунков фиксированное ×4;
  для анимации выбор ×2 / ×3 / ×4.
- Размер части: «Автоматически»; при отключении — ползунок.
  Меньшая часть уменьшает расход видеопамяти.
- Устройство: автоматическое или доступная видеокарта — всплывающий выбор.
- Дополнительные проходы с поворотами и отражениями — переключатель;
  пояснение о замедлении и возможном изменении деталей.
- Потоки чтения / обработки / записи — три числовых ползунка,
  рекомендуемые значения 1 / 2 / 2; больше потоков повышает нагрузку и расход памяти.

### 9.2. Real-CUGAN — рисунки и аниме

- Характер восстановления: обычный SE / усиленный PRO / без согласования NOSE.
- Увеличение: ×2 / ×3 / ×4 с ограничениями выбранного варианта.
- Очистка от шума: бережная / выключена / слабая / средняя / сильная;
  соответствует −1 / 0 / 1 / 2 / 3. Пояснение о возможной потере деталей.
- Согласование частей: выключено / точное / приблизительное / быстрое;
  соответствует 0 / 1 / 2 / 3. Пояснение о стыках и деталях.
- Размер части, выбор устройства, дополнительные проходы и три группы потоков
  устроены как у Real-ESRGAN; процессор доступен там, где поддерживается Real-CUGAN.
- NOSE: только ×2, шумоподавление выключено, согласование выключено.
- PRO: ×2 / ×3; уровни очистки 1 и 2 недоступны.
- У SE уровни очистки 1 и 2 доступны только при ×2.

### 9.3. SwinIR — бережное увеличение

- Увеличение: ×2 / ×3 / ×4 / ×8; пояснение о памяти и времени,
  множитель ×8 не означает пресет 8K.
- Устройство: автоматически / доступная NVIDIA / процессор — всплывающий выбор.
  На процессоре работа существенно медленнее.
- Размер части — ползунок, рекомендуемое 256 пикселей, шаг 8.
- Перекрытие частей — ползунок, рекомендуемое 32 пикселя;
  всегда меньше размера части. Слишком малое оставляет стыки, большое замедляет.
- «Обрабатывать целиком» — переключатель, соответствует размеру части 0;
  предупреждение о возможном большом расходе видеопамяти.

### 9.4. Lanczos3 — детальный

- Охват мелких деталей: ползунок 1–8, целочисленный, рекомендуется 3.
  Большие значения могут добавить обводки и замедлить работу.
- Дополнительная резкость: ползунок 0–3, по умолчанию 0 (выключена).
  Может подчеркнуть шум и контрастные границы.

### 9.5. Catmull–Rom — чёткий

- Сглаживание контуров: ползунок −2…2, рекомендуется 0.
- Выраженность контуров: ползунок −2…2, рекомендуется 0,5.
- Обе настройки экспериментальные: меняют профиль фильтра,
  могут добавить обводки и искажения.
- Дополнительная резкость: ползунок 0–3, по умолчанию 0.

### 9.6. Mitchell — сбалансированный

- Сглаживание контуров и выраженность контуров: ползунки −2…2,
  рекомендуемые значения 1/3 и 1/3, отображать компактно как 0,33.
  Сохранить точность рекомендуемых значений при хранении.
- Обе настройки экспериментальные, с пояснениями о возможных обводках и искажениях.
- Дополнительная резкость: ползунок 0–3, по умолчанию 0.

### 9.7. HQ2x — пиксельная графика

- Проходы: один / два. Один увеличивает ×2, два — ×4;
  затем результат подгоняется под выбранное разрешение.
- Пояснение: повторный проход может упростить детали.
- Дополнительная резкость: ползунок 0–3, по умолчанию 0;
  может менять вид пиксельных границ.

### 9.8. Bilinear — быстрый мягкий

- Дополнительная резкость: ползунок 0–3, по умолчанию 0.
- Пояснение: масштабирование смягчает детали, резкость подчёркивает границы.

### 9.9. Nearest Neighbor — без сглаживания

- Способ увеличения: по разрешению или целый множитель ×2…×16.
  При выборе множителя он определяет итоговый размер вместо пресета.
- Дополнительная резкость: ползунок 0–3, по умолчанию 0;
  может изменить пиксельные блоки.

### 9.10. Area — уменьшение

- Дополнительная резкость: ползунок 0–3, по умолчанию 0.
- Пояснение: усреднение пикселей при уменьшении; увеличение недоступно.

## 10. Общие настройки экспорта для всех методов

Показывать только параметры, относящиеся к выбранному формату:

- Качество: целочисленный ползунок 1–100, рекомендуемое 95.
- Сохранять прозрачность: переключатель для поддерживаемых форматов.
- Без потери качества: переключатель WebP / JXL / AVIF;
  настройку качества с потерями при этом не показывать.
- Цвет фона: образец цвета с выбором цвета, если прозрачность не сохраняется.
- Сжатие PNG: целочисленный ползунок 0–9, рекомендуемое 6;
  описание влияния на размер файла и скорость, без изменения качества пикселей.
- Сжатие TIFF: всплывающий выбор — без сжатия / LZW / ZIP / JPEG / Zstandard / WebP,
  с понятными названиями и пояснениями. По умолчанию LZW.
- Кнопка «Вернуть рекомендуемые настройки» сохраняет своё назначение.

Несколько видеокарт настраивать отдельными строками выбранных устройств
с собственными параметрами частей и потоков обработки вместо ручного ввода
сложных строк вроде 1:2,2:2. Сохранить возможности существующего обработчика.
