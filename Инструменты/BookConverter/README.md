# Встроенные книжные компоненты — 0.5.85-dev

Оба комплекта входят в стандартный build/publish ЛОПАТЫ. Python и msiexec нужны
только сопровождающему для подготовки исходной поставки. Приложение не скачивает
calibre/LibreOffice и не выполняет их системную установку.

## Подготовка сопровождающим

- `python Инструменты/BookConverter/prepare.py --prepare` — calibre 9.16.0,
  официальный portable, соответствующий исходный tar.xz, LICENSE/COPYRIGHT.
- `python Инструменты/BookConverter/prepare-office.py --prepare` — LibreOffice
  26.2.4.2 Windows x64 из закреплённого официального MSI. Административный образ
  проверяется по прежнему provenance; создаётся `Tools/book-office-files.json`.
  При намеренной смене манифеста сначала сделать backup, затем `--refresh-manifest`.

URL/SHA/размеры закреплены в скриптах. Уже проверенные локальные архивы используются
повторно; скачивание возможно только при явном запуске подготовительного скрипта
сопровождающим. MSI внутри административного образа преобразован Windows Installer:
для проверки исходного пакета используется оригинал из `downloads`, а не этот MSI.

## Состав и доставка

`AIHub.csproj` переносит полный calibre в `BookConverterRuntime`, полный офисный
образ в `BookOfficeRuntime` (без административного MSI, который не нужен при запуске).
Оригинальные файлы и лицензии не вырезаются. Дополнительно десять оригинальных DLL
из System64 копируются рядом с soffice в program для app-local VC runtime;
установка redistributable в Windows не нужна. Эти копии тоже включены в манифест.
Проверка целостности офиса выполняется один раз при первом использовании процесса,
а не при запуске приложения. Отдельный пользовательский загрузчик убран.

Build останавливается, если закреплённые комплекты/манифест отсутствуют. Стандартные
установщик и файловый updater включают всё дерево publish; отдельного пакета для
книжных компонентов нет. Их версии не меняют наборы музыкальных/графических движков.

Оригинальные licence.txt/NOTICE и сведения о получении соответствующих исходников
включены в лицензии программы. calibre имеет GPL-3.0 и собственные условия вложений;
LibreOffice — MPL-2.0 и условия вложений. Общее подтверждение условий сохраняется;
тихий ПКМ использует уже принятые условия и не показывает диалогов. Полный отдельный
транзитивный аудит upstream бинарников не объявляется завершённым.
