## Возможность и размер внедрения

Есть готовый [C# API sherpa-onnx](https://k2-fsa.github.io/sherpa/onnx/csharp-api/index.html),
поэтому можно обойтись без тестового Python-окружения. Этот продуктовый путь
ещё нужно реализовать и испытать; пока готов только отдельный стенд.

Четыре файла модели: **670478772 байта** (670.48МБ / 639.42МиБ).
Измерен официальный Windows x64 CPU NuGet runtime 1.13.8: onnxruntime.dll 17799168
и sherpa-onnx-c-api.dll 4605952 байта, вместе 22.41МБ. Сумма с моделью —
**692883892 байта**, около 693МБ / 661МиБ. Практический ориентир установленной
добавки с managed API/лицензиями/обвязкой — **700–750МБ**; точный размер даст сборка.
Это размер на диске, не обещание размера сжатого скачивания. При отдельной загрузке
компонента базовый установщик не обязан содержать веса.

Размеры: `_tmp/voice-input-stand/native-package-size.json`;
[Windows runtime](https://www.nuget.org/packages/org.k2fsa.sherpa.onnx.runtime.win-x64/1.13.8).
NVIDIA model — CC BY 4.0, sherpa-onnx — Apache-2.0; при внедрении обязательны
атрибуция, исходные условия, общий каталог, лицензионный шлюз и ComponentAudit.
