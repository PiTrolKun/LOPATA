# ТЗ — управление рассуждениями моделей в песенном чате

Дата:13.10.2026. Статус: поэтапная реализация; кнопка и on/off ядра выполнены. Потоковое отображение реализуется по отдельному ТЗ 2026-10-13_Отображение_рассуждений_в_музыкальном_чате.md. Сейчас не подстраивать интерфейс под все модели, вариативность предусмотреть в ТЗ.

## Согласованные правила

Визуальный ориентир — приложенный пользователем интерфейс ChatGPT: компактная кнопка у поля ввода; позднее всплывающая панель с названием текущего уровня и ступенчатым ползунком. Место в ЛОПАТЕ — слева от «Сборки песни» под полем ввода центрального чата. Название — «Рассуждения». На первом шаге без отображения «Выкл.» или другого неподтверждённого уровня.

Настройки привязаны к конкретной чат-модели. Программа запоминает последнее выбранное человеком состояние и возвращает его при повторном выборе этой модели/перезапуске. Нельзя самостоятельно включать, выключать, повышать, понижать или сбрасывать режим. Значения по умолчанию для каждой модели определяет пользовательская проверка; протестированный default применяется только при отсутствии сохранённого выбора, а не перезаписывает его. Если сохранённый вариант временно недоступен, предпочтение сохраняется; явно сообщить проблему, не подменять выбор другим режимом.

Количество ступеней НЕ фиксировать общими пятью. У разных моделей возможны разные списки допустимых режимов, их названия, порядок и количество; могут появляться дополнительные тумблеры в той же всплывающей панели. Предусмотреть режимы только on/off, только фиксированный режим или отсутствие поддержки. Набор определяется проверенными возможностями конкретной модели и исполнителя; внешний вид не должен обещать отсутствующее управление. Возможные дополнительные тумблеры пока не названы и не вводятся самовольно.

- При отсутствии сохранённого выбора ядра начальный режим включён. Явное выключение сохраняется и никогда не заменяется default. Не менять sampling по собственной инициативе.

- Во время генерации выбор заблокирован. Запрос, повтор после проверки и сборка песни используют один выбранный режим. Другие чат-модели и другие сценарии сохраняют прежнее поведение.

Поддержка у разных моделей неодинакова; не выводить её только из имени модели/семейства. Первичные источники для последующих обсуждений: Qwen/Qwen3-8B, Qwen/Qwen3-4B-Instruct-2507 на Hugging Face и README llama.cpp tools/server закреплённого d4c8e2c29ce2fb9a251a0a4a16d6c857b4f70f8c. Переключатель режима, ограничение токенов и отделение reasoning_content — разные механизмы, проверять на установленном runtime.
