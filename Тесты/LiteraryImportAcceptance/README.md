# Проверка окон импорта

Синтетический WPF-сценарий для RU/EN и светлой/тёмной темы. Не читает приватный экспорт и не запускает модель. Проверяет объединение названий, редактирование пометок, удаление выделенного, сохранение, красную ошибочную цитату и применение выделения исходника.

Сборка: `dotnet build Тесты/LiteraryImportAcceptance/Probe.csproj`.
Запуск на Windows: `dotnet Тесты/LiteraryImportAcceptance/bin/Debug/net10.0-windows/Probe.dll`.
Временно открывает тестовые окна; результаты и снимки сохраняет в `runs` рядом с проектом. Прогон 20260921_035605: 40 проверок, PASS. Все тексты вымышленные.
