# Runtime / RAG

Постоянное место runtime-библиотек ЛОПАТЫ.

Штатная база стихосложения: `rhyme-ru-en/`. Паспорт, происхождение,
лицензии, описание индексации и независимого чтения:
[LOPATA Rhyme RU/EN](../../Каталоги/RAG/rhyme-ru-en/README.md).
Большие SQLite публикуются вложением отдельного выпуска данных; в Git
хранятся паспорт и документация. Версии и хеши указаны в `corpus.json`.
Частные рабочие библиотеки пользователя этим каталогом не заменяются.

Каждая будущая запись должна иметь паспорт происхождения:

- кто внёс запись;
- какой инструмент или модель;
- при каких обстоятельствах;
- источники;
- уровень доверия;
- тип записи;
- может ли запись влиять на будущие решения.

Модели могут предлагать записи, но не должны молча менять фундаментальные правила.
