# Выравнивание текста русских и английских песен

Дата:14.10.2026. Статус: исследование первичных источников и предложение стенда. Новые модели не устанавливались, физические прогоны не выполнялись, механизм приложения не менялся. Русский — основной язык, английский — дополнительный по прямому решению пользователя. Связано с рабочим ТЗ автоматической синхронизации текста песни.

## Что требуется заменить

Сейчас Whisper small распознаёт готовый микс, после чего exact ordered matching связывает услышанные слова с исходником. Ошибки распознавания и первого/последнего слова оставляют строку без времен. История, хранение и UI отдельно проверены. У последней Studio2d79 записаны13/34строк, начало41.24s; это недостаточный результат.

Задача нового стенда — давать выравнивателю исходный текст как вход, а не ждать, что ASR повторит его без ошибок. При этом выравнивание не доказывает, что все заданные слова действительно спеты: отсутствующие строки и дополнительные повторы могут получить ложные времена. Полное покрытие без проверки по звуку не считается успехом.

## Кандидаты

### 1. Qwen3-ForcedAligner-0.6B

Официальная отдельная модель принимает аудио, заданный текст и язык и возвращает временные позиции слов/символов; предварительный запуск Qwen ASR не обязателен. Russian и English явно перечислены в11языках. Лицензия модели и toolkit Apache-2.0. Указанный предел — до5минут речи; более длинная песня требует отдельной проверки разбиения и повторений.

Критичное различие документации: поддержка Singing Voice/Songs with BGM заявлена для Qwen3-ASR, тогда как для ForcedAligner в таблице указано Speech. Поэтому качество выравнивания русского пения неизвестно. Название0.6B не является оценкой загрузки: официальный HF-checkpoint содержит model.safetensors около1.84GB, весь каталог около1.85GB; RAM/VRAM больше веса на диске и измеряются отдельно.

Официальные пути запуска: qwen-asr toolkit через Transformers и отдельный Transformers-native checkpoint `-hf`. В карточке native ещё указан исходный Transformers вместо гарантированного стабильного релиза; перед тестом нужно проверить конкретные закреплённые версии. vLLM/FlashAttention не являются обязательным выбором для одиночного стенда. Windows/CPU/GPU пригодность здесь не испытана; PyTorch-путь является кандидатом, а не подтверждённой поставкой для всех устройств.

Первичные источники: [Qwen toolkit](https://github.com/QwenLM/Qwen3-ASR), [карточка native aligner](https://huggingface.co/Qwen/Qwen3-ForcedAligner-0.6B-hf), [файлы модели](https://huggingface.co/Qwen/Qwen3-ForcedAligner-0.6B-hf/tree/main), [официальный wrapper](https://raw.githubusercontent.com/QwenLM/Qwen3-ASR/main/qwen_asr/inference/qwen3_forced_aligner.py).

Вывод исследования: приоритетный независимый кандидат. Это выбор для проверки, не доказанное превосходство над Whisper.

### 2. stable-ts: выравнивание заданного текста через Whisper

`model.align(audio, text, language=...)` принимает готовый текст напрямую. Это отличается от нашего whisper.cpp→LCS. Есть сохранение исходных переносов `original_split`, обработка длительности слов, refine и диагностика нулевых интервалов. Для языков используются Whisper tokenizer/models: английский и русский присутствуют. Пакет stable-ts MIT; набор лицензий конкретных весов/дополнительных инструментов фиксировать отдельно.

Авторы дают рекомендации для музыки с Demucs/VAD и CPU dynamic quantization. Это основание для отдельного контролируемого испытания, а не обещание точности на наших песнях. При растянутом пении нельзя слепо применять речевой максимум длительности слова или VAD, который может отбросить тихий вокал. Пропущенные слова/нулевые интервалы и перенесённые времена должны быть отмечены отдельно.

Запуск через Python/PyTorch или поддержанный faster-whisper backend; наши имеющиеся whisper.cpp GGML веса нельзя объявлять напрямую совместимыми с Python загрузчиком. Может потребоваться другой файл того же семейства и отдельная среда. Новую загрузку здесь не выполняли.

Источники: [API Alignment и рекомендации для музыки](https://github.com/jianfch/stable-ts), [реализация align](https://raw.githubusercontent.com/jianfch/stable-ts/main/stable_whisper/alignment.py), [MIT](https://raw.githubusercontent.com/jianfch/stable-ts/main/LICENSE), [языки Whisper](https://raw.githubusercontent.com/openai/whisper/main/whisper/tokenizer.py).

Вывод: второй приоритетный кандидат, ближайший к существующему семейству моделей, но меняющий способ использования текста.

### 3. WhisperX / Wav2Vec2 CTC

В official alignment.py английский по умолчанию использует `WAV2VEC2_ASR_BASE_960H`, русский — `jonatasgrosman/wav2vec2-large-xlsr-53-russian`. Это разные языковые акустические модели под одним механизмом. Russian model обучена на Common Voice/CSS10 speech, принимает16kHz, карточка объявляет Apache-2.0. Один PyTorch weight file около1.26GB; весь HF-репозиторий около4.05GB содержит дополнительные представления/LM, всё скачивать не требуется. Английский checkpoint также отдельно проверять по лицензии.

Код WhisperX BSD-2-Clause. Текущий pyproject main объявляет Python>=3.10,<3.14, torch/torchaudio~=2.8 и дополнительные зависимости; их нельзя ставить поверх существующих музыкальных runtime. Изолированная среда обязательна для стенда. Исходники содержат варианты CPU/CUDA и Windows dependency markers; на нашей Windows ещё не запускалось.

API принимает текстовые segments с start/end. Для работы именно с известным исходником нельзя снова строить только те segments, которые не пропустил старый ASR; нужен проверенный способ задавать окна. Русские распевы, длинные паузы и целая песня в одном окне могут требовать отдельного разбиения. В alignment.py имеется интерполяция отсутствующих времен: в нашем тесте такие значения надо сохранять как оценочные/неподтверждённые, не выдавать за услышанные границы.

Источники: [alignment.py](https://raw.githubusercontent.com/m-bain/whisperX/main/whisperx/alignment.py), [pyproject](https://raw.githubusercontent.com/m-bain/whisperX/main/pyproject.toml), [русская модель](https://huggingface.co/jonatasgrosman/wav2vec2-large-xlsr-53-russian), [файлы русской модели](https://huggingface.co/jonatasgrosman/wav2vec2-large-xlsr-53-russian/tree/main), [английская модель](https://huggingface.co/facebook/wav2vec2-base-960h).

Вывод: запасной независимый CTC-кандидат, если первые два не дадут достаточного качества или нужно сравнение иной акустической модели.

### 4. Montreal Forced Aligner

Имеются official `russian_mfa` и `english_mfa`, акустические модели и словари произношений. Российская карточка описывает alignment речи, лицензию CC-BY4.0, модель HMM-GMM; подтверждённых показателей для русского пения в ней нет. Программный MFA имеет отдельную MIT-лицензию. Использует аудио, transcript, dictionary и acoustic model; необходимо учитывать неизвестные словарю слова и произношение.

В official installation есть Windows-путь Conda/Kaldi. Это дополнительное окружение, не простая замена нашего CLI. Выбор для резервного стенда, если компактнее организованные нейронные варианты не подходят. Не приписывать речи гарантированное качество распевов.

Источники: [russian_mfa](https://huggingface.co/MontrealCorpusTools/russian_mfa), [english_mfa](https://huggingface.co/MontrealCorpusTools/english_mfa), [installation](https://montreal-forced-aligner.readthedocs.io/en/latest/installation.html), [MIT кода](https://github.com/MontrealCorpusTools/Montreal-Forced-Aligner/blob/main/LICENSE).

### MMS_FA — исследовательский, не основной продуктовый кандидат

MMS предлагает multilingual forced-alignment tooling и веса. Однако official README объявляет CC-BY-NC4.0 для MMS code/weights. Это ограничение нельзя потерять, используя API из разрешительной лицензии TorchAudio. Кроме того, описанные в старом TorchAudio tutorial alignment APIs удаляются в2.9; текущий проектный2.10 нельзя считать совместимым с примером. Для базового продукта при наличии вариантов выше приоритет не давать. Ограничение относится к конкретным MMS весам, а не всем Wav2Vec2/CTC моделям.

Источники: [MMS license/tooling](https://raw.githubusercontent.com/facebookresearch/fairseq/main/examples/mms/README.md), [MMS multilingual alignment](https://raw.githubusercontent.com/facebookresearch/fairseq/main/examples/mms/data_prep/README.md), [TorchAudio warning](https://docs.pytorch.org/audio/stable/tutorials/forced_alignment_for_multilingual_data_tutorial.html).

## Предлагаемый ограниченный стенд

Не устанавливать всё сразу. Первый раунд: текущая разметка как контроль, Qwen ForcedAligner и stable-ts.align. Тестовые песни остаются прежними, повторная музыкальная генерация не нужна. Основные входы — несколько русских песен Studio/ACE, включая old001 с пропущенным началом и new2d79 с13/34; английский —1–2реальные песни с известным исходником, после проверки материалов. Если подходящего английского файла нет, это пробел покрытия, не основание объявлять EN испытанным.

Перед запуском закрепить версии/revisions/weights SHA, изолировать среды и сохранять фактические входы/выходы/logs. Для каждого метода сначала использовать один и тот же микс и точный поющийся текст без жанрового brief/секционных пометок, сохраняя обратную связь с индексами исходного документа. Не исправлять оригинальные Lyrics.

Разделение вокала, если понадобится, испытать как один дополнительный фактор на том же методе и том же аудио. Сохранять длину и начало сигнала, иначе времена нельзя непосредственно переносить в исходную песню. Оно не объявляется обязательным заранее. Авторы stable-ts упоминают Demucs; лицензии конкретных separator weights и компоненты проверяются перед тестом.

Оценивать не только число выданных времен: ошибку начала/конца по слышимому вокалу на проверяемых фрагментах, пропуски первого куплета, неверную подсветку в инструментале, повторные припевы, реакцию на неисполненные строки, общее время от старта до сохранения результата, cold/warm отдельно, RAM/VRAM/backend. Не сравнивать аудио одной версии с текстом другой. Измеренный допустимый предел установить после проверки, не назначать обещание точности заранее.

Поставщика выбирать после физического результата; общий UI/cache/timing contract можно сохранить, поменяв провайдера и его версию. Отказ от старого matcher не означает переработку проигрывателя/истории. Пока ни один новый кандидат не принят в продукт, обязательный каталог/реестр компонентов не пополнялся, приложение остаётся0.5.45-dev, ТЗ открыто.
