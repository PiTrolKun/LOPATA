# Поставка штатной RAG-базы

Поручение пользователя 15.10.2026: перенести готовую базу в постоянное место,
сделать отдельный push с базой и самостоятельный README для других пользователей.

Это исправление пропуска поставки в принятой серии RAG. Публикация 0.5.55-beta
содержала утилиту, но не штатную базу. Исходная договорённость о поставке базы
с программой сохраняется; подготовка частной библиотеки не закрывала этот пункт.

- Постоянное относительное место: `Runtime/RAG/rhyme-ru-en`.
- Публикуется отдельный переносимый набор данных; версия приложения не меняется.
- Крупные SQLite — вложение отдельного выпуска GitHub, паспорт и документация — Git.
- Две совместимые с существующими readers версии: книжная и словарная.
- Удалить локальные абсолютные пути; сохранить SHA256, источники, атрибуцию,
  точные тексты лицензий, изменения и исключения. Не включать профили и переписку.
- Публиковать проверенный словарный слой и допущенные исторические фрагменты;
  нечитаемый скан, рекламные/служебные страницы, сомнительные примеры исключать.
- README должен объяснять состав, индексацию, модель/протокол, SQLite-схему,
  получение архива, проверку хешей и независимое использование.
- Проверить целостность, происхождение записей, неизменность принятых векторов,
  открытие после переноса, ZIP и опубликованные размеры/SHA256.
- Источник испытаний оставить как материал отката, не использовать как runtime.

Подключение мастерской рифмы к этому пути остаётся её отдельным этапом.
Этот выпуск данных сам по себе не добавляет её интерфейс и автоматическую установку
базы в существующую 0.5.55-beta. Установщики не пересобираются.
