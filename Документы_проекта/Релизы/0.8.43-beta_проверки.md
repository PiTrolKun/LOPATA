# Проверки ЛОПАТЫ 0.8.43-beta

Подписанное файловое обновление [0.8.43-beta](https://github.com/PiTrolKun/LOPATA/releases/tag/v0.8.43-beta) опубликовано. Видеоредактор получил карточку Mini с пробами RU и EN, а в глобальных настройках Mini стала голосом ядра по умолчанию. Исходники и принятое ТЗ отправлены в GitHub.

В чистой копии прошли 75 профильных проверок, 35 пропущены по условиям запуска. Обновлятор прошёл 105 проверок. Размеры и SHA-256 всех 31 вложений сверены с GitHub. Полный установщик не пересобирался.

- Исходный коммит тега `10034bf3c36556a19460edbd13dea08c02a4061f`.
- В переходном комплекте 7717 файлов. Сохранены все 7712 путей 0.8.41-beta. В комплекте для новой установки 6550 файлов.
- Проверено содержимое 27 новых архивов, 4870 записей ZIP.
- SHA-256 переходного манифеста `c68d9fad15a2d7c66a1c8e49da764f9b100120c26870f4b01dc955d38fb2672c`.
- SHA-256 манифеста новой установки `d2b3983a1b8b4886a313f8b036b8bdc2f5352706dd9c923d0bb54c6c3b165671`.
- Пробы Iris для русского и английского сверены по SHA-256 с исходными WAV. В dev-сборке пройдены реальное озвучивание ядра и воспроизведение для обоих языков.
