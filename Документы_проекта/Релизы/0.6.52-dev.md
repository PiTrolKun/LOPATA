# 0.6.52-dev — сцены и планы

При первом переходе к сценам Qwen сам составляет черновик из замысла, развития, описаний визуального мира и выбранных референсов. Круговой индикатор, текущий этап, фактический поток рассуждений поддерживающей его модели, пауза и отмена. Сначала последовательность сцен, затем отдельные запросы планов; готовые части сохраняются.

Слева сцены и планы, справа редактирование. Названия, начало/конец действия и референсы доступны напрямую; камера, свет, композиция, функция, длительность, участники и ограничения находятся в подробностях. Добавление, удаление и перестановка, история версий, улучшение отдельного плана и три независимые альтернативы с ранним выбором. Повторный вход не заменяет готовую работу.

Следующий экран — рабочая английская версия. Перевод запускается автоматически, допускает ручную правку и историю. ID, порядок, длительности и связи сохраняются; названия и реплики защищены от перевода. Большая сцена переводится по одному плану с сохранением ответов для продолжения. Дальше остаётся заглушка раскадровки.

Общий резидентный исполнитель сохраняет GPU-first размещение и прежний выбор из трёх Qwen. Для совместимых моделей допускается ограниченное мышление без перезагрузки весов между шагами; обычные улучшения и переводы явно отключают его в запросе. Новых весов, зависимостей и установщика нет.

Это черновая режиссёрская разработка для проверки человеком. Модель получает описания/назначения/заметки/промты референсов, не пиксели изображений. Большой отдельный исходный фрагмент, который не помещается в фактический контекст, останавливается с пояснением без обрезания текста. Видеогенерация не подключалась.

Проверка завершена: 65 профильных тестов успешны (модельный протокол/поток, ссылки, частичное продолжение, общий pause/resume, поздний ответ, версии, перевод, прежний архив, WPF и затронутые прежние шаги). Обычная сборка и safe-start — 0 ошибок/0 предупреждений; в тестовом проекте остаются прежние NU1902/NU1903/CS4014/MSTEST0040. RU/EN по 7680 ключей без дублей, UTF-8 scanner по 34 текстовым файлам и git diff --check успешны. Реальный прогон и native UI описаны выше; результаты _tmp/video-shots/validation.json. Проверка на других видеокартах и повторный физический прогон всей тройки в этом инкременте не заявляются. Установщик не пересобирался.

Справка для реализации раздельного потока reasoning/content: [штатный сервер llama.cpp](https://github.com/ggml-org/llama.cpp/blob/master/tools/server/README.md). Совместимость подтверждалась реальным запуском локального набора 002.

Финальный native-контроль основной сборки: повторное открытие готового диагностического проекта автоматически прогрело выбранную Qwen27B на полном GPU (65 слоёв); «+» виден над списком сцен. Ручная версия и рабочий перевод сохранились. Штатный повторный запуск safe-start-final.log успешен.
