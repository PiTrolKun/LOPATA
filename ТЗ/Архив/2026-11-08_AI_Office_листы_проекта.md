# AI Office — листы проекта и журналы

**08.11.2026 · Рабочее ТЗ.** [Карта AI Office](../2026-11-07_AI_Office.md). Основа — текстовый редактор 0.7.47-dev.

## Реализация в 0.7.48-dev

Чистый запуск открывает выбор из пяти типов. После выбора созданы первый лист и «Журнал действий». Кнопка «+» на нижней полосе создаёт ещё один материал или импортирует готовый файл. Для обычного файла команда «Файл → Создать проект» предлагает сохранить .LOPATAdoxAI рядом с исходником. Полоса появляется после успешной записи и доступна в том же окне при чтении материала проекта.

Книга XLSX занимает один лист проекта. Внутри неё переключаются собственные листы и есть отдельная кнопка «+» для нового рабочего листа. Доступны базовая правка значений и формул, переход к ячейке по адресу и сохранение XLSX. Встроенная сетка показывает данные, для полноценного оформления и диаграмм есть просмотр через «Читать». В 0.7.48-dev после правки до внешнего пересчёта показывались выражения. Начиная с 0.7.51-dev [редактор пересчитывает поддерживаемые формулы при вводе](2026-11-08_AI_Office_пересчёт_формул.md). Для XLS, XLSM и ODS сохраняется исходный файл. Собственный черновик книги состоит из глав, черновик презентации — из слайдов с заголовками и текстом. С версии 0.7.52-dev в импортированных EPUB, FB2, PPTX и ODP можно править текст и добавлять главы или слайды. Рабочая версия хранится отдельно от вложенного оригинала. [Редакторы книг и презентаций](2026-11-08_AI_Office_книги_и_презентации.md). Архив допускает любые расширения. Общие ограничения контейнера составляют 512 МиБ распакованных данных и 512 записей ZIP, включая служебные.

Журнал программы перечисляет создание и сохранение проекта, сохранённые правки материала, добавления листов и файлов, использование ИИ. Журнал ИИ хранит данные фактических вызовов. Для перевода в режиме чтения записаны отправленные текст и системная инструкция, ответ исполнителя и версия модели. При озвучке результатом служит воспроизводимый аудиофайл. При диктовке сохраняются контрольная сумма и длительность входного звука и распознанный текст. Для голоса системная инструкция отсутствует. Реальные вызовы привязаны к своему материалу. При экспорте одного листа в него включаются сведения о моделях, относящиеся к этому листу.

## Пользовательский сценарий

При создании с нуля пользователь выбирает тип первого листа. Доступны текст, книга, таблица, презентация и архив файлов. Отмена закрывает выбор без нового рабочего файла. После выбора создаётся временный проект. При создании из существующего файла его содержимое становится первым листом без повторного выбора типа.

В нижней части окна проекта видны именованные листы и кнопка «+». Выбор типа через «+» добавляет самостоятельный материал. После первого материала идёт доступный для чтения журнал действий программы. При фактическом вызове ИИ появляется отдельный лист с журналом ИИ. Для каждого вызова доступны время, материал, операция, фактическая модель и известная версия, запрос, отправленный системный промпт и результат либо состояние ошибки. Системный промпт по умолчанию свёрнут. Если операция не принимает системный промпт или исходная запись старая, это явно обозначается. Архив принимает произвольные файлы, включая файлы с одинаковыми именами, и позволяет извлечь точную копию.

У обычного файла полоса листов проекта скрыта. Временный файл восстановления и появление уведомления после вызова ИИ этого не меняют. Полоса появляется после успешного создания проекта, видна у нового проекта с выбранным типом и при повторном открытии существующего проекта. Отмена сохранения и частичная запись в исходный формат сохраняют прежний режим.

У книги XLSX есть отдельная навигация по её родным листам. Обычная книга сохраняет эту навигацию при скрытой полосе проекта. В проекте одна книга занимает один лист проекта, при её выборе открываются собственные листы книги. Названия, порядок, формулы и неотредактированные части исходной книги должны сохраняться.

## Приёмочные сценарии

- Новый проект каждого типа, отмена выбора, тихое закрытие пустого временного проекта.
- Обычный файл, создание проекта из него, отмена или успешное сохранение. Проверить видимость полосы и порядок листов в каждом случае.
- Изменить разные листы, перейти между ними, сохранить, восстановить черновик и повторно открыть постоянный файл. Проверить совместимость со старыми проектами и сохранность вложений по SHA-256.
- Открыть XLSX с несколькими собственными листами. Проверить выбор листа, внесённую правку, сохранение и повторное открытие внутри и вне проекта.
- Ручные действия видны в журнале программы. Открытие настроек ИИ само по себе не создаёт журнал ИИ. После фактического вызова проверить запрос, доступный результат, модель и состояние свёрнутого промпта.

Полные специализированные редакторы электронных таблиц, вёрстки книг и презентаций развиваются по карте направления. Объём проверенной работы с форматами фиксируется по результатам испытаний.
