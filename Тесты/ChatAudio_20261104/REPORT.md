# Звуковые вложения «Если накипело» — 04.11.2026, 0.7.19-dev

Статус: реализовано, приёмка пользователя ожидается. Без commit/push, публикации
обновления и пересборки установщика. Существующий единый ТЗ расширен (0.22).

## Поведение

Скрепка, drop и Ctrl+V файлов принимают WAV, MP3, M4A/AAC, FLAC, OGG/Opus, WebM.
Общий импорт показывает один информационный диалог на выбранную пачку с аудио,
до сохранения копий. В нём прямо сказано: автоматическое распознавание речи,
возможны ошибки; музыка, шумы, эмоции по голосу и произвольные звуки не анализируются.
Карточка помечена как распознавание речи. При необходимости используется стандартная
подготовка компонентов. Отказ/отмена подготовки оставляет текст и вложения черновика.

Gemma получает расшифровку, её происхождение и ограничения. Не получает сырые
аудиобайты и не должна утверждать, что слышала запись. Говорящий не приравнивается
автоматически к пользователю. Пустое распознавание сообщается явно, без вывода,
будто в файле заведомо нет речи. Лимиты прежние: 16 вложений по 128 МиБ.

Оригиналы — точные локальные копии, прежние SHA/ID/topic/source-message сохраняются.
SQLite attachment_audio хранит производную расшифровку и завершённые части,
привязанные к SHA/ревизии ASR. Текст доступен прежним read/search внутри своей темы;
превью речи попадает в метаданные памяти, названия и дерева. Полную запись модель
не обязана получать за один запрос: есть постраничное чтение и ограниченный поиск.

## Исполнитель и жизненный цикл

Существующий Parakeet TDT v3 INT8 / sherpa-onnx CPU, потоки из настроек диктовки.
Новые зависимости/модели не добавлены. Контроль RAM 2 ГиБ; Gemma выгружается до ASR,
затем запускается для ответа. VRAM-резерв 2 ГиБ не менялся. Компоненты проверяются
по общим ComponentAudit/LicenseGate, без отдельного обхода политики. Файлы модели
при отсутствии подготавливаются стандартным окном. Пользовательские лицензии
не сбрасывались, микрофон не включался.

FFmpeg — существующий VideoEditorRuntime 8.1.3-video-editor-1 (CPU). Облегчённый
MusicAudioRuntime не подошёл: ограниченный набор демультиплексоров/декодеров.
ASR использует WAV PCM16 mono 16 kHz, окна 12 секунд с перекрытием 1 секунду,
временный WAV текущего окна удаляется в finally. Готовые части записываются в SQLite;
пауза сохраняет прогресс, незавершённое окно повторится. Дедупликация перекрытия
сравнивает до 8 слов; это автоматическая расшифровка, не дословная гарантия.

Распознавание входит в chat.let_it_out. Worker LetItOut.Audio подчиняется общему
STOP, не использует исключение аварийной остановки для VoiceInput.*. Микрофонная
диктовка сохраняет старые имена и поведение. Нативные процессы зарегистрированы;
отмена, тайм-аут FFmpeg 5 минут и завершение освобождают исполнителей. В общие логи
не пишется распознанная речь; приватные тестовые результаты лежат в этом стенде.

универсального определения звуков и диаризации нет. Отдельный ASR worker на CPU
не равен испытанию всех ПК; малый объём RAM блокируется общей политикой резерва.
