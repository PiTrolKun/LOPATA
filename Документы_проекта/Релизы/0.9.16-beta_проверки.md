# Приёмка внешних агентов в 0.9.16

24 ноября 2026 года пользователь принял ТЗ после проверки в рабочем окне ЛОПАТЫ. [Архив ТЗ](../../ТЗ/Архив/2026-11-24_Подключение_внешних_ИИ-агентов.md) · [Проверка подключения в установленной 0.9.14-beta](0.9.14-beta_проверки.md)

В dev прошёл 41 профильный тест. Прямой запрос из чата Codex без указания имени клиента вернул список сценариев. Слева от STOP появился значок приложения из Windows с подсказкой «Codex запрашивает сведения о сценариях». Через три секунды после ответа значок исчез. Тестовый клиент без своего изображения получил отдельную пиктограмму монитора.

На этом ПК при запуске обнаружены Codex, ChatGPT Classic и DeepSeek Harness. После связи с Codex кнопка предложила подключить две оставшиеся программы. Наличие GitHub Copilot проверяется отдельно от Microsoft 365 Copilot. Распознавание названий из списка проверено автотестами. Прямое подключение через интерфейс каждого из остальных клиентов отдельно не испытывалось.

Полный установщик не пересобирался. Выпуск поставляется через штатное файловое обновление.

## Выпуск и установленная копия

Изолированная копия исходников прошла 41 профильный тест и 107 тестов обновлятора. Исходный коммит `261ac3489e4e9c7069d8589c7fa60d88084db494`. Проверены подписи манифестов предыдущего и нового выпуска, размеры и SHA-256 всех 29 вложений на GitHub и файлов внутри новых ZIP. [Файловое обновление](https://github.com/PiTrolKun/LOPATA/releases/tag/v0.9.16-beta)

Установленная ЛОПАТА штатно обновилась с 0.9.14-beta до 0.9.16-beta и подтвердила исправный запуск. В её окне проверены значок Codex слева от STOP, исчезновение индикатора в простое, отдельная пиктограмма неизвестного клиента и свёрнутый при открытии список сценариев. При запуске появилась подсказка о доступных для подключения программах.

Действующее соединение открытого чата после обновления ещё отвечало от версии 0.9.14-beta. При новом соединении Codex через тот же установленный плагин получил ответ от 0.9.16-beta и список из 17 сценариев. Переустановка плагина и изменение его настроек не потребовались.

SHA-256 переходного манифеста `2a7b5fdfb84ddebe6db176d738c7424aa55dbd570793b510befd5a8792bbc82e`. SHA-256 манифеста новой установки `b859f52eabed9b303dafead4d7efd6f63d1ba1ab2e446b375dc274f3500a6870`.
