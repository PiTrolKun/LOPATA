## Версии и выпуск

Внутренний VERSION: 0.1.53-dev. Публичный первый выпуск: 0.1.53-beta. Никаких дополнительных цифр после beta. Публичная программа, установщик и Release имеют одну версию; внутренняя сборка остаётся dev. Стабильный канал исключает prerelease; beta-сборка по умолчанию получает тестовые обновления, пользователь может отключить их. Dev никогда не публикуется.

Сборка и публикация — разные скрипты. Публикация только отдельной командой с конкретным проверенным артефактом и заметками. Сборщик создаёт метаданные с хешем, версией и исходным коммитом; публикация сначала создаёт черновик, загружает и проверяет файлы, затем открывает выпуск. Не заменять опубликованный файл молча. Перед первой публикацией синхронизировать исходники и привязать выпуск к коммиту реализации.

Хранить первый опубликованный установщик текущей линии X.Y и два последних установщика; совпадающие позиции не дублировать. Скрипт показывает план очистки и выполняет её отдельным явным флагом. Удалять только установочные assets старых управляемых выпусков, не историю исходников и теги.
