## Штатный загрузчик: найденный поток

`MainWindow.xaml.cs`, `PrimaryActionButton_Click`: после basic license gate проверяет основную модель и показывает CoreModelPrompt при её отсутствии. `StartCoreModelDownloadAsync` (около строки 2267) использует общий экран прогресса, затем вызывает CoreModelManager.DownloadAsync и ToolModelManager.EnsureRerankerDownloadedAsync. Отмена различает уже скачанное ядро и недостающий reranker.

`CoreModelManager` отвечает за GGUF, storage/свободный диск, .part, HTTP Range, манифест и проверку SHA-256. Нельзя превращать аппаратные DLL в часть core-model.json. Для зависимостей есть ComponentManager.DownloadAndInstallAsync, упорядочивание компонентов и ComponentLicenseGate. Новый план аппаратных библиотек должен связать эти механизмы с прежним экраном, сохранив отдельные состояния моделей и зависимостей.

Особый случай для проверки: ядро уже установлено, а подходящих DLL нет либо оборудование сменилось. Текущий ранний переход к рабочему окну не должен пропускать новый план. Основное скачивание весов повторять не нужно.

## Что ещё не установлено этой сверкой

Upstream-возможности, поддержка отдельных операций на Windows, выбранные архивы/хеши, лицензии и размеры новых комплектов ещё не исследованы. Vulkan/HIP/SYCL/DirectML/OpenCL — кандидаты из аудита, а не подтверждённые варианты для каждого исполнителя. Названия устройства или библиотеки недостаточно для обещания запуска.

Kimi Medium, Giga Embeddings, Real-ESRGAN/Real-CUGAN и SwinIR в исходном аудите описаны как менее проблемные. Их полный транзитивный контур в этом проходе не проверялся; не присваивать им статус полной аппаратной независимости по этой записи.

Следующая матрица должна для каждой строки содержать pinned revision, доступные Windows backend, ограничения модели/операций, состав компонентов/лицензий/байтов, память/OOM/fallback и отдельные четыре статуса: upstream, внедрение, поставка/догрузка, физические испытания.

Код не менялся, загрузки/сборки/запуски для нового направления не начинались. Временный порог безопасной паузы — 1% остатка лимита. На подготовительном проходе было 7%; checkpoint позволяет продолжить без повторного обследования уже перечисленных точек.
