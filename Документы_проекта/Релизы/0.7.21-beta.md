# ЛОПАТА 0.7.21-beta

В «Эксперименты → Чаты» добавлен сценарий «Если накипело» — локальный разговор с Gemma 4 26B A4B Instruct QAT. Модель прогревается при входе. Работа на видеокарте, в гибридном режиме или на процессоре выбирается по доступной памяти с резервом видеопамяти; при возможности сначала предлагается закрыть тяжёлые программы.

Есть история тем, избранное, переименование и автоматические названия. Память сохраняет сводки и исходные реплики, активный контекст подбирается по ресурсам. Общая шкала показывает его заполнение; кнопка мозга освобождает дополнительный запас. Отключаемая карта темы открывается отдельным окном с детализацией и источниками, по умолчанию выключена.

Поддерживаются общая диктовка, прослушивание сообщений и автоматическое чтение ответов с выбором доступного диктора. Изображения, документы и аудиозаписи можно прикрепить кнопкой, перетаскиванием или вставкой. Для аудио выполняется распознавание речи, а не анализ любых звуков.

Gemma может искать относящиеся к разговору воспоминания в других сохранённых темах. Найденные источники можно открыть; иногда для поиска требуется подсказка. Через ПКМ по теме доступен экспорт переписки, сохранённых сводки/карты и вложений в ZIP с HTML и JSON.

Уточнено восстановление указателя мыши при открытии лицензии из поля чата.

Исправлено превышение контекста при планировании монтажного клипа: пакет сцен получает относящиеся к нему тайминги, исходные материалы сохраняются полностью.

Это тестовое файловое обновление. Ответы, сводки и карта могут содержать ошибки; проверяйте первоисточники. Скорость и доступный контекст зависят от оборудования. Веса моделей и пользовательские данные в обновление не входят. Полный и сетевой установщики не пересобирались.
