# Шкала контекста и запасной ручной сброс · 0.7.10-dev

03.11.2026. Дополнение 0.16 существующего ТЗ «Если накипело».
Без публикации, новых зависимостей, моделей и загрузок; установщик не собирался.

## Поведение

Существующая общая шкала показывает активный пакет следующего запроса Gemma,
а не размер полной библиотеки и не прежний предел Qwen. Токены считаются через
тот же backend (`props`, `apply-template`, `tokenize`): системные правила,
адрес оглавления, последние обмены и текущий черновик. Отдельно указан резерв
ответа 2048 токенов. Служебные запросы заголовков/сводок не подменяют показания.
Перед генерацией передаётся точный подсчёт окончательного пакета, в том числе
выборочно прочитанной памяти; после ответа шкала пересчитывается.

Нажатие на мозг убирает старые целые обмены до освобождения примерно 10% полной
ёмкости окна. Последний завершённый обмен, текущий ввод, системные правила и
адрес оглавления сохраняются. Если старых частей меньше, освобождается доступный
объём, а не последний обмен. Во время ответа/прогрева/сводки кнопка заблокирована.
Кнопка доступна через UI Automation и клавиатуру; внешний вид общего индикатора
сохранён. При уходе из чата прежний debug-источник возвращается.

Пользователь заметил белую подложку именно в пустом чате. Причина — штатный
Windows-template отключённой кнопки. У мозга теперь собственный прозрачный
template с тонкой рамкой только при клавиатурном фокусе; в пустом чате кнопка
по-прежнему недоступна, но системная заливка больше не используется.

Ручная граница — отдельный `context_cursor` в библиотеке, связанный с постоянным
номером исходной пары. Она сохраняется при повторном открытии; полный исходный
пакет/восстановительный checkpoint её не отменяет. Оригиналы, черновики, названия,
избранное и оглавление не удаляются. Поиск по старым оригиналам разрешён, когда
они нужны для ответа. Отмена до записи границы не меняет её; запись сравнивает
ожидаемое состояние и не возвращает удалённый чат.

Это сокращение активного входа. Размер выделенного KV-буфера и веса модели
не уменьшаются: освобождение VRAM кнопкой не обещается. Короткая операция не
генерирует новый ответ; использует штатный вспомогательный gate и отмену.

## Проверки

Baseline: 102 PASS / 4 opt-in SKIP. Итог: 109 PASS / 5 opt-in SKIP, ошибок нет.
Новый native-тест выполняется отдельно; остальные старые opt-in не запускались
повторно в этом этапе. Проверены:

- 10% именно ёмкости окна и округление до целого обмена;
- короткая история, один большой текущий ввод, штатный резерв ответа;
- сохранение границы, несколько сдвигов, отказ удаления последней пары;
- изоляция разных чатов и каскадное удаление служебной границы;
- сохранение черновика и полной истории;
- блокировка кнопки во время ответа;
- запоздавший результат измерения старой темы после открытия новой.
