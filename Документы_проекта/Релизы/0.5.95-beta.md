# LOPATA 0.5.95-beta — личная библиотека стихов

- Персональный каталог песенных текстов с поиском по словам и по смыслу.
- Импорт в музыкальный редактор и сохранение из него в базу через кнопку 🎳.
- Примеры из личной базы для музыкального чата и мастерской рифмы.
- Подбор по точному имени исполнителя использует его тексты; если примеров
  нет, программа сообщает об этом. Использованные фрагменты доступны по значку
  документа с лупой рядом с переключателем базы.
- При сохранении из редактора подставляются сведения песни. Внешний импорт
  открывает окно проверки исполнителя, автора, жанра, стиля, языка и других
  данных перед добавлением. В пакете можно заполнить пустые общие поля.
- Переносимая копия каталога, защита от текстовых дублей и сохранение известных
  сведений о происхождении. Исходные файлы не перезаписываются.

База персональная: тексты пользователей, тестовая коллекция и векторы не входят
в выпуск. Для смыслового поиска используются уже поддерживаемые локальные
компоненты, подготовка открывается при необходимости. Новых моделей и облачных
сервисов не добавлено. Примеры направляют подачу, но не гарантируют качество
стихов и не обучают модель. Это тестовая бета. Файловое обновление сохраняет
модели, проекты, настройки, прежние наборы движков и ручной выбор.
